# 工程數學互動講義

以課堂手寫筆記為準，把抽象的數學觀念做成可操作的互動網頁。

```
engineering-math/
  index.html            科目首頁：**單元選單**
  laplace.html          拉普拉斯轉換（9/17 – 9/20 筆記）
  ode.html              常係數 ODE 與特徵方程（9/23 Exercise 1–3）
  assets/laplace.js     7 個互動模組 + 12 題中英對照測驗
  assets/ode.js         3 個互動模組 + 可改數字的完整解題 + 12 題測驗
  docs/CONTENT_MAP.md   單元分類、核心公式、筆記勘誤與作業批改紀錄
```

導覽是三層：**主頁（選科目）→ 工程數學首頁（選單元）→ 單元頁**。一個單元一頁。

引擎共用根目錄的 [`shared/`](../shared/)，與電子學、電路學是同一套。

## 目前已完成：拉普拉斯轉換（9/17 – 9/20 筆記）

因為這個主題特別抽象，互動的比重比其他兩科更高：

| # | 模組 | 你可以做什麼 |
|---|------|-------------|
| 01 | 轉換機器 | 點原料丟進機器看它變成什麼；切到 ℒ 模式看 f(t) 變成 F(s) |
| 02 | 複變數函數視覺化 | 左邊拖曳 z，右邊即時看 w = f(z)，附逐步拆解成 Re + i·Im |
| 03 | 為什麼乘 e⁻ˢᵗ | 三層曲線疊看，拉 s 看面積怎麼變成 F(s)；s 太小會示範積分發散 |
| 04 | 轉換對照表 | 點開任一條看完整積分過程 |
| 05 | 微分性質推導 | 9 個步驟一步一步按，每步都說明為什麼 |
| 06 | 為什麼多了 −f(0) | 三個例子對照「漏寫」與「正確」的答案差異 |
| 07 | 用 ℒ 解 ODE | 三步驟流程圖，跟著走完一整圈 |

## 常係數 ODE 與特徵方程（9/23 Exercise 1–3）

這個單元的核心是**一張可以拖的圖**：把特徵根 λ 拖到複平面的不同位置，右邊的解 y(t)
立刻改變形狀。抽象的「實部管衰減、虛部管振盪」就這樣變成看得見的東西。

| # | 模組 | 你可以做什麼 |
|---|------|-------------|
| 01 | 特徵根實驗室 | 左邊拖曳 λ（或直接拉 a、b、初始條件），右邊解即時變形；左半平面標為穩定區 |
| 02 | 三種根對照 | 相異實根 / 重根 / 共軛複根三條解疊在同一張圖，對應 Exercise 2 三小題 |
| 03 | 完整解題（可改數字） | a、b、y(0)、y′(0) 都是滑桿，6 個步驟的算式與結論即時重算 |

另有「為什麼可以猜 e^(λt)」「重根為什麼多一個 t」「複根為什麼變成 cos/sin」三段逐步推導，
以及**作業逐題批改**（Exercise 1–3）。
