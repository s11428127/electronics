10/2 板書01 · Higher derivatives

高階導數：ℒ(f″)、ℒ(f‴) 到 ℒ(f⁽ⁿ⁾)LAPLACE OF f⁽ⁿ⁾

上一章只證明了一次微分：ℒ(f′) = sF(s) − f(0)。二次、三次、n 次微分怎麼辦？老師的招式是：不要重新積分，把舊公式一層一層套上去。像爬樓梯：每往上爬一階（多微分一次），就多乘一個 s、多扣一個初始值。

ℒ( f″(t) ) = s²F(s) − s f(0) − f′(0)

板書推導

  1. ℒ(f″(t)) = ℒ( (f′(t))′ )
    二次微分 = 「一次微分的一次微分」。這樣就能用手上唯一的定理。
  2. = s ℒ(f′(t)) − f′(0)
    把定理 ℒ(g′) = sℒ(g) − g(0) 裡的 g 換成 f′。注意尾巴是 g(0) = f′(0)，不是 f(0)。
  3. = s [ s ℒ(f(t)) − f(0) ] − f′(0)
    ℒ(f′(t)) 又是一次微分，再套一次定理。
  4. = s² ℒ(f(t)) − s f(0) − f′(0)
    把中括號乘開：s 乘進去，f(0) 前面就多了一個 s。
  5. = s²F(s) − s f(0) − f′(0)
    ℒ(f(t)) 本來就叫 F(s)，換回簡寫。

高階導數的標準招式

  1. 把 f⁽ⁿ⁾ 寫成 (f⁽ⁿ⁻¹⁾)′。
  2. 套一次定理：s·ℒ(f⁽ⁿ⁻¹⁾) − f⁽ⁿ⁻¹⁾(0)。
  3. ℒ(f⁽ⁿ⁻¹⁾) 用上一階的結果代進去，乘開。
ℒ( f‴(t) ) = s³F(s) − s² f(0) − s f′(0) − f″(0)

板書推導

  1. ℒ(f‴(t)) = ℒ( (f″(t))′ )
    三次微分 = 二次微分再微一次。
  2. = s ℒ(f″(t)) − f″(0)
    套定理，尾巴是 f″(0)。
  3. = s ( s²F(s) − s f(0) − f′(0) ) − f″(0)
    ℒ(f″) 上面剛算好，直接整串代進來（板書那條長箭頭就是在指這件事）。
  4. = s³F(s) − s² f(0) − s f′(0) − f″(0)
    乘開：每一項都多一個 s。

Exercise 1（板書只出題，答案是補的）補

  1. 1.　ℒ(f⁽⁵⁾(t)) = s⁵F(s) − s⁴f(0) − s³f′(0) − s²f″(0) − s f‴(0) − f⁽⁴⁾(0)
    5 階 → 第一項 s⁵F(s)，後面扣 5 項：s 的次方 4、3、2、1、0，f 的階數 0、1、2、3、4。
  2. 2.　ℒ(f⁽⁷⁾(t)) = s⁷F(s) − s⁶f(0) − s⁵f′(0) − s⁴f″(0) − s³f‴(0) − s²f⁽⁴⁾(0) − s f⁽⁵⁾(0) − f⁽⁶⁾(0)
    7 階 → 扣 7 項。每一項「s 的次方 + f 的階數」都等於 6（= n − 1），可以拿來自我檢查。
ℒ( f⁽ⁿ⁾(t) ) = sⁿF(s) − sn−1f(0) − sn−2f′(0) − … − s f(n−2)(0) − f(n−1)(0)

板書 To Sum Up

  1. 1.　ℒ(f′(t)) = sF(s) − f(0)
    扣 1 項。
  2. 2.　ℒ(f″(t)) = s²F(s) − s f(0) − f′(0)
    扣 2 項。
  3. 3.　ℒ(f‴(t)) = s³F(s) − s²f(0) − s f′(0) − f″(0)
    扣 3 項。
  4. 4.　ℒ(f⁽⁴⁾(t)) = s⁴F(s) − s³f(0) − s²f′(0) − s f″(0) − f‴(0)
    扣 4 項。
  5. 5.　ℒ(f⁽ⁿ⁾(t)) = sⁿF(s) − sn−1f(0) − sn−2f′(0) − … − s f(n−2)(0) − f(n−1)(0)
    扣 n 項。可以用數學歸納法證：假設 n 階成立，對 f⁽ⁿ⁺¹⁾ = (f⁽ⁿ⁾)′ 套一次定理，整串乘 s 再扣 f⁽ⁿ⁾(0)，剛好就是 n+1 階的樣子。

板書 Ex.（老師當場解，已驗算 ✓）

  1. 1.　ℒ(f⁽⁶⁾(t)) = s⁶F(s) − s⁵f(0) − s⁴f′(0) − s³f″(0) − s²f⁽³⁾(0) − s f⁽⁴⁾(0) − f⁽⁵⁾(0)
    扣 6 項，每項「次方 + 階數」= 5 ✓。
  2. 2.　ℒ(f⁽¹⁰⁾(t)) = s¹⁰F(s) − s⁹f(0) − s⁸f′(0) − s⁷f″(0) − s⁶f⁽³⁾(0) − s⁵f⁽⁴⁾(0) − s⁴f⁽⁵⁾(0) − s³f⁽⁶⁾(0) − s²f⁽⁷⁾(0) − s f⁽⁸⁾(0) − f⁽⁹⁾(0)
    扣 10 項，每項「次方 + 階數」= 9 ✓。

寫 ℒ(f⁽ⁿ⁾) 的步驟

  1. 先寫 sⁿF(s)。
  2. 後面接 n 個減號（全部都是減）。
  3. s 的次方從 n−1 往下數到 0；f 的階數從 0 往上數到 n−1。
  4. 檢查：每一項「s 的次方 + f 的階數」都要等於 n−1。

常見錯誤

  • ✗ 扣 n−1 項或 n+1 項。✓ n 階就扣 n 項，數一下減號。
  • ✗ 最後一項寫成 s·f(n−1)(0)。✓ 最後一項 s 的次方是 0，沒有 s。
  • ✗ 寫成 F(0) 或 f(s)。✓ 尾巴是小寫 f 在 t = 0 的值（初始條件），大寫 F(s) 只出現在第一項。
  • ✗ 中間有項變成加號。✓ 每一次套定理都是「減」掉初始值，所以全部都是減。
10/2 板書02 · Proof of ℒ(f′)

證明 ℒ(f′) = sF(s) − f(0)PROOF BY INTEGRATION BY PARTS

整堂課都在用這條定理，這裡補上它的證明。工具只有一個：。想法是把「f′ 的積分」換成「f 的積分」，而 f 的積分就是 F(s)。

∫ f dg = f·g − ∫ g df　　（分部積分）

板書推導

  1. ℒ(f′(t)) = ∫₀∞ f′(t) e−st dt
    定義：把 f′ 丟進拉普拉斯的積分。
  2. = ∫₀∞ (df(t)/dt) e−st dt = ∫₀∞ e−st df(t)
    f′ = df/dt，dt 約掉，變成「對 f 積分」，形狀就是 ∫ (某函數) d(某函數)，可以分部積分。
  3. = e−st f(t) |₀∞ − ∫₀∞ f(t) d(e−st)
    分部積分，這裡的「f」是 e−st、「g」是 f(t)。
  4. d(e−st) = (−s) e−st dt
    對 t 微分，連鎖律帶出 −s（s 對 t 來說是常數）。
  5. = limt→∞ e−st f(t) − e0 f(0) + s ∫₀∞ f(t) e−st dt
    上限代 ∞（用極限）、下限代 0；後面「減掉 (−s)」變成加 s。
  6. = 0 − f(0) + s F(s) = sF(s) − f(0)
    第一項的極限是 0（老師標「待證」，第 03 節證明）；e0 = 1；最後那個積分正好是 F(s)。
請確認：板書倒數第二行看起來是「− s∫₀∞ f(t)e−stdt」。 正確應該是 + s∫…（「減去 (−s)」= 加 s），不然最後得不到 sF(s)。可能是粉筆字看不清楚，或老師寫的時候少一個負號；最後一行答案 sF(s) − f(0) 是對的。
10/2 板書03 · Existence

ℒ 什麼時候存在：e−σt 跟 f(t) 拔河EXISTENCE CONDITION

上一節最後偷用了「e−stf(t) 在 t → ∞ 時是 0」。這一節分三步把它講清楚：① 先用看懂 e−jωt 只會轉圈；② 取絕對值把轉圈的部分丟掉，只剩實數 σ；③ 看 e−σt 拉不拉得住 f(t) —— 這就是 ℒ 存在的條件。

老師在旁邊框起來的兩條。為什麼現在講？因為等一下（第 06、08 節）要處理 ejβt、e−jωt 這種「指數上有 j」的東西，就是把它翻譯成 cos 和 sin 的字典。

ejθ = cos θ + j sin θ　　e−jθ = cos θ − j sin θ

e−jθ 怎麼來（板書）

  1. e−jθ = ej(−θ) = cos(−θ) + j sin(−θ)
    −jθ 就是 j·(−θ)。把第一條公式的 θ 全部換成 −θ。
  2. = cos θ − j sin θ
    cos 是偶函數 cos(−θ) = cos θ；sin 是奇函數 sin(−θ) = −sin θ。

單位圓（拖曳圓上的點）

兩個點永遠上下對稱（互為共軛），而且永遠在半徑 1 的圓上 —— 不管 θ 多少，長度都是 1。下面證明極限的關鍵就是這個「長度永遠是 1」。

回到那個極限。麻煩在 s 是複數，e−st 不是一條普通的曲線。老師的做法：取，把會轉圈圈的 e−jωt 消掉，只剩實數的部分。

| e−st f(t) | = | e−σt f(t) |　（因為 | e−jωt | = 1）

板書推導（s = σ + jω）

  1. lim | e−st f(t) | = lim | e−(σ+jω)t f(t) |
    一個複數是 0 ⇔ 它的長度是 0，所以證「絕對值 → 0」就夠了。s 拆成實部 + 虛部。
  2. = lim | e−σt f(t) | · | e−jωt |
    指數拆開；複數相乘的長度 = 長度相乘。
  3. = lim | e−σt f(t) | · | cos ωt − j sin ωt |
    尤拉公式（上面的 e−jθ，θ = ωt）。
  4. = lim | e−σt f(t) | · √( cos²ωt + (−sin ωt)² ) = lim | e−σt f(t) | · 1
    複數 a + jb 的長度是 √(a² + b²)，而 cos² + sin² = 1。就是單位圓上的點，長度永遠 1。
  5. = limt→∞ | e−σt f(t) | = 0
    剩下全部是實數。最後這個「= 0」不是自動成立的 —— 要 f(t) 長得不要太快、σ 夠大，這就是下面的「存在的條件」。

e−σt 像一個往下拉的力量，f(t) 是往上衝的力量。只要 e−σt 拉得贏，乘起來就趨近 0，ℒ 就存在。拉不拉得贏，看 f(t) 長得多快 —— 這就是的意思。

ℒ(f(t)) 存在的條件：limt→∞ f(t) e−σt = 0，　σ > a，　a ∈ ℝ

板書：limt→∞ f(t) e−σt 的三種情況（σ > 0）

  1. lim f(t) < ∞（f 不會衝到無限大）　⇒　0
    有限的數 × 趨近 0 的數 = 0。例：f(t) = 5、sin t。
  2. lim f(t) = ∞，但 f 長得比 eσt 慢　⇒　0
    兩個都衝無限大，比誰快。例：t²、e2t（σ > 2 時）。
  3. lim f(t) = ∞，而且 f 長得比 eσt 快　⇒　∞
    拉不住，ℒ 不存在。例：et²。
板書的 Q：什麼條件下 ① lim f(t)e−σt = 0 但 lim f(t) = ∞？② lim f(t)e−σt = ∞ 且 lim f(t) = ∞？
答補：看 f(t) 跟 eσt 誰長得快。① f 最多像某個指數 eat 那樣長（多項式、eat 都算），只要取 σ > a 就壓得住；② f 長得比任何指數都快（像 et²），再大的 σ 都沒用。這就是條件裡「σ > a」的意思。

板書 Ex. 三題

  1. 1.　lim e−σt·t² = lim t² / eσt = lim 2t / (σeσt) = lim 2 / (σ²eσt) = 0　（σ > 0）
    先看 lim t² = ∞，t² 往上衝。改寫成 ∞/∞ 型，用上下各微分，做兩次 t² 就被微掉了，分母還是 ∞。板書結論：ℒ(t²) 存在，σ > 0。
  2. 2.　lim e−σt·e2t = lim e2t / eσt = lim e−(σ−2)t = 0，σ > 2
    指數合併，只看指數的正負：σ > 2 時 −(σ−2) 是負的 → 0（σ = 2 時是 1、σ < 2 時是 ∞）。板書結論：ℒ(e2t) 存在，σ > 2。
  3. 3.　lim e−σt·et² = lim et² / eσt = lim et²−σt = lim et(t−σ) = ∞
    t 一超過 σ，指數就變正而且越來越大，不管 σ 多大。板書結論：ℒ(et²) 不存在。
請確認：① 第 1 題第二次羅必達後分母應該是 σ²eσt（板書看起來只寫 σ，不影響答案 0）。② 第 3 題最後一行看起來像「= 0」，正確是 = ∞，旁邊的結論「ℒ(et²) 不存在」是對的，應該是 ∞ 寫得像 0。

判斷 ℒ(f) 存不存在

  1. 寫出 f(t)e−σt，能合併的指數先合併。
  2. 是 ∞/∞ 型就用羅必達，或直接比「誰長得快」：常數 < 多項式 < eat < et²。
  3. 找得到一個 a，讓 σ > a 時極限 = 0 → 存在，收斂範圍就是 σ > a。

常見錯誤

  • ✗ 看到 lim f(t) = ∞ 就說 ℒ 不存在。✓ t²、e2t 都衝到 ∞，但 ℒ 都存在 —— 要比的是速度。
  • ✗ 忘了寫 σ 的範圍。✓ ℒ(e2t) = 1/(s−2) 要附上 σ > 2。
  • ✗ 直接對複數 s 取極限。✓ 先取絕對值，把 e−jωt 消掉（長度 1），只剩實數 σ。
10/2 板書04 · Basic transforms

基本函數：ℒ(1) = 1/s、ℒ(eat) = 1/(s − a)BASIC LAPLACE TRANSFORMS

前面都在講「怎麼轉」和「什麼時候能轉」，這裡終於開始真的算。先算最簡單的兩個：常數 1 和指數 eat。它們是之後查表的地基 —— 幾乎所有題目最後都會拆成這幾塊。

ℒ(u(t)) = ℒ(1) = 1/s，σ > 0　　ℒ(eat) = 1/(s − a)，σ > a

先認識 u(t)：

  1. u(t) = 1（t ≥ 0）；0（t < 0）　　f(t) = 1（所有 t）
    u(t) 像一個開關：t = 0 那一刻打開，之後一直是 1；f(t) = 1 則是從頭到尾都是 1。
  2. ℒ 只看 t ≥ 0 那一段　⇒　ℒ(u(t)) 跟 ℒ(1) 一定一樣
    積分從 0 積到 ∞，t < 0 的部分根本不會被看到，而 t ≥ 0 時兩個函數都是 1。

ℒ(u(t)) = ℒ(1)

  1. ℒ(u(t)) = ∫₀∞ u(t) e−st dt = ∫₀∞ e−st dt，　ℒ(1) = ∫₀∞ 1·e−st dt = ∫₀∞ e−st dt
    定義直接代。t ≥ 0 時 u(t) = 1，兩個積分長得一模一樣。
  2. = (1/(−s)) e−st |₀∞
    ekt 的反導函數是 (1/k)ekt，這裡 k = −s。
  3. = −(1/s) ( limt→∞ e−st − limt→0 e−st ) = −(1/s)(0 − 1)
    上限的極限是 0（老師標「待證」，下面證）；下限 e0 = 1。
  4. = 1/s　⇒　ℒ(u(t)) = ℒ(1) = 1/s，σ > 0（s > 0）
    負負得正。條件 σ > 0 來自下面的證明。

待證：limt→∞ |e−st| = 0

  1. lim |e−st| = lim |e−(σ+jω)t| = lim |e−σt·e−jωt|
    跟第 03 節同一招：s 拆成實部、虛部。
  2. = lim |e−σt(cos ωt − j sin ωt)| = lim e−σt |cos ωt − j sin ωt|
    尤拉公式；e−σt 是正的實數，可以直接拿出絕對值。
  3. = lim e−σt √(cos²ωt + (−sin ωt)²) = lim e−σt = 0，　σ > 0
    根號裡是 1。e−σt 要趨近 0，指數必須是負的 → σ > 0。這就是收斂條件的來源。

ℒ(eat)

  1. ℒ(eat) = ∫₀∞ eat e−st dt = ∫₀∞ e−(s−a)t dt
    兩個指數合併：at − st = −(s − a)t。
  2. = (1/(−(s−a))) e−(s−a)t |₀∞
    跟上面一樣的反導函數，只是 s 換成 s − a。
  3. = −(1/(s−a)) ( limt→∞ e−(s−a)t − limt→0 e−(s−a)t ) = −(1/(s−a))(0 − 1)
    上限 0（待證，下面證）、下限 1。
  4. = 1/(s − a)　⇒　ℒ(eat) = 1/(s − a)，σ > a（s > a）
    其實就是把 ℒ(1) = 1/s 的 s 換成 s − a。a = 0 時 e0 = 1，剛好回到 1/s ✓。

10/2 板書05 · Linearity & inverse

線性與 ℒ⁻¹：拆開、查表、加回來LINEARITY · INVERSE TRANSFORM

老師先用了「拆開來各自算」，後來才補證明為什麼可以這樣做。這裡先講道理、再拿來用。的意思很生活：果汁機打一顆蘋果得到一杯，打一根香蕉得到一杯；那「2 顆蘋果 + 3 根香蕉」一起打，就是 2 杯蘋果汁 + 3 杯香蕉汁，不會多出奇怪的東西。

若 T(x₁) = y₁、T(x₂) = y₂，則 T(ax₁ + bx₂) = ay₁ + by₂

定義

  1. A transform / operator T is called linear if T satisfies the principle of superposition（疊加原理）
    一個「轉換／運算子」T 就是一台機器：丟東西進去、吐東西出來。它若滿足疊加原理，就叫線性。
  2. i.e.（that is）：if T(x₁) = y₁, T(x₂) = y₂, then T(ax₁ + bx₂) = ay₁ + by₂
    輸入先「放大再相加」，等於輸出各自「放大再相加」。順序對調結果一樣。

疊加機（板書的方塊圖）

這裡拿 f(t) = 1、g(t) = e2t 當例子。調 a、b，最下面那一列的輸出永遠等於「上面兩列的輸出各乘 a、b 再相加」—— 這就是線性。

Thm. Laplace Transform is linear

  1. 要證：ℒ(af(t) + bg(t)) = aF(s) + bG(s)
    把定義裡的 T 換成 ℒ、x 換成 f 和 g。
  2. ℒ(af(t) + bg(t)) = ∫₀∞ (af(t) + bg(t)) e−st dt
    定義：整坨丟進積分。
  3. = ∫₀∞ ( af(t)e−st + bg(t)e−st ) dt
    e−st 乘進括號（分配律）。
  4. = ∫₀∞ af(t)e−st dt + ∫₀∞ bg(t)e−st dt
    積分本身就是線性的：和的積分 = 積分的和。
  5. = a∫₀∞ f(t)e−st dt + b∫₀∞ g(t)e−st dt
    常數 a、b 跟 t 無關，可以提到積分外面。
  6. = aF(s) + bG(s)　　Q.E.D.
    兩個積分正好就是 ℒ(f) = F(s)、ℒ(g) = G(s) 的定義。Q.E.D. = 證明完畢。

常見錯誤

  • ✗ 以為乘法也能拆：ℒ(f·g) = F(s)·G(s)。✓ 線性只管加法和乘常數，兩個函數相乘不能這樣拆。
  • ✗ 常數被當成函數轉換：ℒ(3f) = ℒ(3)·ℒ(f)。✓ 常數直接提出去：ℒ(3f) = 3F(s)。

有了 1/s 和 1/(s − a) 兩張「查表卡」，遇到一長串加減的函數，就拆開、各自查表、再加回來。反過來從 F(s) 找回 f(t)，叫做 ℒ⁻¹。這一招能用，靠的就是上面的「線性」。

f(t) ──ℒ──→ F(s)　　　f(t) ←──ℒ⁻¹── F(s)

Ex. 1　ℒ(2u(t) + 4 + e2t)

  1. = 2ℒ(u(t)) + 4ℒ(1) + ℒ(e2t)
    線性：加號拆開、常數提出去（上面證明過）。
  2. = 2/s + 4/s + 1/(s − 2)
    查表：ℒ(u) = ℒ(1) = 1/s；ℒ(e2t) 是 a = 2。
  3. = 6/s + 1/(s − 2)
    同分母合併。收斂條件取兩個都成立的範圍：σ > 0 且 σ > 2 → σ > 2補。

Ex. 2　ℒ(⅓u(t) − ¼e−t/5)

  1. = ⅓ℒ(u(t)) − ¼ℒ(e−t/5)
    一樣拆開、常數提出。
  2. = ⅓·(1/s) − ¼·1/(s + ⅕)
    e−t/5 的 a = −⅕，所以 s − a = s + ⅕。

Ex.（ℒ⁻¹）1　ℒ⁻¹(2/s − 4/(s − 2))

  1. = 2ℒ⁻¹(1/s) − 4ℒ⁻¹(1/(s − 2))
    ℒ⁻¹ 也是線性的：拆開、常數提出。目標是把每一塊湊成表上的樣子。
  2. = 2u(t) − 4e2t
    查表倒著用：1/s ← u(t)；1/(s − 2) ← e2t。

Ex.（ℒ⁻¹）2　ℒ⁻¹(¼·(1/s) + 1/(s + 1) − 2/(s − ½))

  1. = ¼ℒ⁻¹(1/s) + ℒ⁻¹(1/(s + 1)) − 2ℒ⁻¹(1/(s − ½))
    拆開。注意 s + 1 = s − (−1)，所以 a = −1。
  2. = ¼u(t) + e−t − 2et/2
    1/(s + 1) ← e−t；1/(s − ½) ← et/2。

Exercise 2（板書只出題，答案是補的）補

  1. 1.　ℒ(4 + 2e−2t − ¼e(3/5)t) = 4/s + 2/(s + 2) − ¼·1/(s − 3/5)，σ > 3/5
    三塊各自查表：4 → 4/s；e−2t 的 a = −2；e(3/5)t 的 a = 3/5。收斂區取最嚴的 σ > 3/5。
  2. 2.　ℒ⁻¹( (½)/s − 3/(s + 5) + (5/4)·1/(s − 4/5) ) = ½u(t) − 3e−5t + (5/4)e(4/5)t
    1/s ← u(t)；1/(s + 5) ← e−5t；1/(s − 4/5) ← e(4/5)t。

ℒ⁻¹ 的標準流程

  1. 用線性把 F(s) 拆成一塊一塊，常數提到 ℒ⁻¹ 外面。
  2. 每一塊湊成 1/s 或 1/(s − a) 的樣子（s + 3 要看成 s − (−3)）。
  3. 查表倒著翻：1/s → u(t)、1/(s − a) → eat，再把常數乘回去。

常見錯誤

  • ✗ 1/(s + 1) 翻成 et。✓ s + 1 = s − (−1)，a = −1 → e−t。
  • ✗ 2/(s − ½) 翻成 et/2，把 2 弄丟。✓ 常數先提出去：2·ℒ⁻¹(1/(s − ½)) = 2et/2。
  • ✗ 把 ℒ(2u + 4) 寫成 2/s + 4（常數沒轉換）。✓ 常數 4 = 4·1，ℒ(4) = 4/s。
10/2 板書06 · The smart way

聰明方法：ℒ(cos ωt)、ℒ(sin ωt)、ℒ(tⁿ)THE SMART WAY

直接算 ∫₀∞ cos ωt·e−st dt 要分部積分兩次再移項，很煩（老師說「分部積分：不要做」）。聰明的方法是利用 cos 的特性：微分兩次會變回自己（乘上 −ω²）。再配合第 01 節的 ℒ(f″) 公式，一行代數就解出來。同一招也能算 sin ωt 和 tⁿ（微 n 次變成常數 n!）。

ℒ(cos ωt) = s / (s² + ω²)　　ℒ(sin ωt) = ω / (s² + ω²)　（σ > 0）

板書推導

  1. f(t) = cos ωt，　f(0) = 1
    先把初始值準備好，等一下 ℒ(f″) 公式要用。cos 0 = 1。
  2. f′(t) = −ω sin ωt，　f′(0) = 0
    微分一次（連鎖律帶出 ω）。sin 0 = 0。
  3. f″(t) = −ω² cos ωt = −ω² f(t)　…… (1)
    再微一次，又變回 cos，只是多了 −ω²。這就是「聰明」的關鍵。
  4. 對 (1) 取 ℒ：ℒ(f″(t)) = ℒ(−ω² f(t)) = −ω² ℒ(f(t)) = −ω² F(s)
    右邊用線性，把常數 −ω² 提出去。
  5. s²F(s) − s f(0) − f′(0) = −ω² F(s)
    左邊用第 01 節的 ℒ(f″) 公式。
  6. s²F(s) − s = −ω² F(s)
    代 f(0) = 1、f′(0) = 0。
  7. (s² + ω²) F(s) = s　⇒　F(s) = ℒ(cos ωt) = s / (s² + ω²)
    F(s) 的項移到同一邊、提出來，再除過去。完全沒有積分。

ℒ(sin ωt)：同一招（板書）

  1. g(t) = sin ωt，g(0) = 0；g′(t) = ω cos ωt，g′(0) = ω；g″(t) = −ω² g(t)
    sin 也是微兩次變回自己乘 −ω²，只是初始值換成 0 和 ω。
  2. s²G(s) − s·0 − ω = −ω² G(s)　⇒　(s² + ω²) G(s) = ω
    兩邊取 ℒ，代初始值。
  3. G(s) = ℒ(sin ωt) = ω / (s² + ω²)
    cos 的分子是 s、sin 的分子是 ω。收斂條件跟 1 一樣是 σ > 0（cos、sin 不會長大）。

ℒ(tⁿ)：微 n 次就變成常數 n!（板書）

  1. f(t) = tⁿ，f(0) = 0；f⁽¹⁾(t) = n tn−1，f⁽¹⁾(0) = 0；f⁽²⁾(t) = n(n−1) tn−2，f⁽²⁾(0) = 0；⋯
    每微一次，次方少 1、前面多乘一個係數。只要還有 t，代 t = 0 就是 0。
  2. f(n−1)(t) = n(n−1)⋯2·t，f(n−1)(0) = 0
    微到第 n−1 次，只剩一個 t。
  3. f⁽ⁿ⁾(t) = n(n−1)(n−2)⋯2×1 = n!　…… (3)
    再微一次，t 不見了，剩下一個常數 n!（）。這就是聰明方法要的「微到變簡單」。
  4. 對 (3) 取 ℒ：ℒ(f⁽ⁿ⁾(t)) = ℒ(n!) = n!ℒ(1) = n!/s
    右邊是常數，用線性提出來，ℒ(1) = 1/s 查表。
  5. sⁿF(s) − sn−1f(0) − ⋯ − f(n−1)(0) = n!/s　⇒　sⁿF(s) = n!/s
    左邊用 ℒ(f⁽ⁿ⁾) 通式（第 01 節）。所有初始值都是 0，尾巴全部消失。
  6. F(s) = ℒ(tⁿ) = n! / sn+1，σ > 0
    兩邊除以 sⁿ。檢查：n = 0 時 t⁰ = 1，0!/s = 1/s ✓；n = 1 時 ℒ(t) = 1/s² ✓。

「聰明方法」的適用時機

  1. 看 f 微分幾次會不會變回自己的倍數（cos、sin、eat 都會）。
  2. 寫下那條關係式，例如 f″ = −ω²f，兩邊取 ℒ。
  3. 左邊用 ℒ(f⁽ⁿ⁾) 公式、代初始值；右邊用線性。
  4. 把 F(s) 移到同一邊解出來 —— 變成解一元一次方程。

常見錯誤

  • ✗ cos、sin 的分子搞反。✓ cos → s、sin → ω。檢查法：ω → 0 時 cos ωt → 1，s/s² = 1/s ✓。
  • ✗ 分母寫成 s² − ω²。✓ 是 s² + ω²（來自 −ω² 移項）。s² − ω² 是雙曲函數 cosh、sinh 的。
  • ✗ 初始值代錯：sin 的 g′(0) 寫成 1。✓ g′(t) = ω cos ωt，所以 g′(0) = ω。
