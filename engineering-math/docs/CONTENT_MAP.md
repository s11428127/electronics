## 拉普拉斯核心公式

```
定義          ℒ(f(t)) = F(s) = ∫₀^∞ f(t) e^(−st) dt
定義域→值域    { f(t) | t ∈ ℝ } 實變數函數  →  { F(s) | s = σ+jω ∈ ℂ } 複變數函數
尤拉公式       e^(iθ) = cos θ + i sin θ   ⟹  e^(−iy) = cos y − i sin y   ← 注意減號
微分性質       ℒ(f′)  = sF(s) − f(0)
              ℒ(f″)  = s²F(s) − s f(0) − f′(0)
轉換對         1        ↔ 1/s           (s > 0)
              t        ↔ 1/s²          (s > 0)
              e^(at)   ↔ 1/(s−a)       (s > a)   ← ROC
              cos ωt   ↔ s/(s²+ω²)     (s > 0)
              sin ωt   ↔ ω/(s²+ω²)     (s > 0)
解 ODE 流程    t 域 ODE →(ℒ)→ s 域代數 → 解出 Y(s) →(ℒ⁻¹)→ y(t)
```

## 筆記勘誤紀錄（9/17–9/20）

1. **e⁻ᶻ 的展開符號錯誤**：筆記寫 `e⁻ˣ(cos y + i sin y)`，應為 `e⁻ˣ(cos y − i sin y)`，
   故 `Im = −e⁻ˣ sin y`。驗證：x=0, y=π/2 時 e^(−iπ/2) = −i。
2. **Theorem 下方方框筆誤**：寫成 `sF(s) = f(0)`，應為 `sF(s) − f(0)`。
   （上一行 Theorem 本身是對的，判斷為手寫筆誤。）
3. **待確認**：`∫t²dt = ⅓t?+C` 手寫不清，正確為 `⅓t³+C`。
   （其下 `∫₁² t²dt = 7/3` 正確。）

## 常係數 ODE 核心公式

```
方程          y″ + a y′ + b y = 0        （二階、線性、齊次、常係數）
猜法          y = e^(λt) ⟹ y′ = λy, y″ = λ²y
特徵方程      λ² + aλ + b = 0
判別式        D = a² − 4b
  D > 0  相異實根 λ₁ ≠ λ₂    y = C₁e^(λ₁t) + C₂e^(λ₂t)
  D = 0  重根   λ = −a/2     y = (C₁ + C₂t)e^(λt)      ← 少了 t 就只剩一個自由度
  D < 0  共軛複根 λ = α ± βi  y = e^(αt)(A cos βt + B sin βt)
                              α = −a/2（管衰減）、β = √(4b−a²)/2（管振盪）
穩定條件      所有根的實部 < 0（複平面左半邊）
定係數        代 y(0) 與 y′(0) 解聯立 → 特解；最後一定要代回驗算
與 ℒ 的關係   特徵方程法＝先求通解再代初始條件；拉普拉斯＝轉換當下就吃進初始條件
```

## 作業批改紀錄（9/23 Exercise 1–3）

1. **Exercise 1 解錯（唯一的錯）**：y″ + 3y′ + 2y = 0、y(0) = y′(0) = 1。
   根 λ = −1, −2 正確，聯立式 `C₁ + C₂ = 1`、`−C₁ − 2C₂ = 1` 也列對了，
   但解成 C₁ = 0、C₂ = 1（即 y = e^(−x)）。驗算 y′(0) = −1 ≠ 1 ✗。
   **正解：C₁ = 3、C₂ = −2，y(t) = 3e^(−t) − 2e^(−2t)**（y(0) = 1 ✓、y′(0) = −3 + 4 = 1 ✓）。
   另兩個小問題：(a) 寫下來的特徵方程看起來像 λ² + 2λ + 2 = 0 卻因式分解成 (λ+2)(λ+1)，
   應為 λ² + 3λ + 2 = 0 —— 手寫不清，**請自行確認**；(b) 變數中途從 t 換成 x。
   抄錄的〈老師解〉（初始條件不同：y(0) = 1、y′(0) = 2）最終答案 y = 4e^(−t) − 3e^(−2t) 正確，
   但中間那行「C₁ = −3、C₂ = 4」標號對調了，應為 C₁ = 4、C₂ = −3。
2. **Exercise 2 三小題全對**，包含重根補 te^(−2t)、複根轉成 e^(−2t)(A cos t + B sin t)。
3. **Exercise 3 證明正確**；唯一缺的是沒有說明 lim(t→∞) e^(−st)f(t) = 0 需要 f 為指數階。
