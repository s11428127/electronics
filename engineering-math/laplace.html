拉普拉斯轉換

這一章最難的不是計算，是「它到底在幹嘛」。一個長得莫名其妙的積分，為什麼能拿來解微分方程？下面 7 個模組會把每一個符號的來歷拆給你看 —— 先看得懂，再去算。

Big picture

一句話說明這章在幹嘛

微分方程很難解。但代數方程很好解。拉普拉斯轉換就是一條捷徑：把難解的微分方程搬到另一個世界（s 域），在那裡它會變成一次方程，解完再搬回來。

整章的骨架就這四步

  1. t 域：y′ + 3y = 0，y(0) = 2　← 微分方程，難
    直接在 t 域解，你得會分離變數、積分因子、特徵方程那一套。
  2. 做 ℒ：sY(s) − 2 + 3Y(s) = 0　← 微分不見了！
    關鍵魔術：ℒ 把「微分」變成「乘以 s」。而且初始值 y(0) 會自動被吃進式子裡。
  3. s 域解代數：Y(s)(s+3) = 2　⟹　Y(s) = 2/(s+3)
    這一步是國中程度的移項。整章的價值就在這裡。
  4. 做 ℒ⁻¹ 搬回來：y(t) = 2e⁻³ᵗ
    查表反轉換。繞這一大圈，只是為了避開在 t 域硬解微分方程。

所以讀這章時，每看到一個新東西就問自己：「這是為了讓那條捷徑走得通嗎？」答案幾乎都是「是」。e⁻ˢᵗ 是為了讓積分收斂；−f(0) 是為了把初始條件帶進去；收斂區是為了保證這條捷徑存在。

01 · What is a Transform

什麼是「轉換」

筆記上那張 A —T→ B，B = T(A) 看起來很空泛，其實意思非常簡單：轉換就是一台機器。東西從 A 進去，變成另一種東西從 B 出來。重點是「進去的和出來的不是同一種東西」。

轉換機器

點一個東西丟進機器

把筆記那張圖填滿

  1. A ——ℒ——▸ B　，　B = ℒ(A)
    筆記上 A、B 底下打了問號。答案是：
  2. A = { f(t) | t ∈ ℝ }　實變數函數（real functions）

    輸入是以時間 t 為變數的實數函數，例如 f(t) = cos 4t、f(t) = e⁻⁵ᵗ、f(t) = t²+t+1。這些你在微積分早就看熟了。

  3. B = { F(s) | s = σ + jω ∈ ℂ }　複變數函數（complex functions）

    輸出是以複數 s 為變數的函數。注意 s 不是實數，它是 σ + jω 這種複數。所以下一節要先搞懂「複變數函數」是什麼。

轉換的核心不是公式，而是「換一個世界做事」。就像把中文翻成英文去跟外國人溝通，講完再翻回中文 —— 語言不同，但講的是同一件事。

02 · Real vs Complex Functions

實變數函數 vs 複變數函數

這是筆記裡最容易卡住的地方，因為「複變數函數」聽起來很玄。其實它只是：把輸入從一個數字，換成一個「有兩個座標的點」。輸出也是一個點。所以它畫不出一般的函數圖形 —— 要用兩個平面來看。

實變數函數 real function輸入一個實數 → 輸出一個實數。例：f(t) = cos 4t
實雙變數函數輸入兩個實數 → 輸出一個實數。例：f(x,y) = x² + y²
複變數函數 complex function輸入一個複數 → 輸出一個複數。例：f(z) = z² + 2

複變數函數怎麼拆成「實部 + 虛部」

  1. f(z) = z² + 2，　z = x + iy
    先把 z 換成 x + iy，然後硬乘開。
  2. (x+iy)² + 2 = x² + 2ixy + (iy)² + 2

    注意 (iy)² = i²y² = −y²，因為 i² = −1。

  3. = (x² − y² + 2) + i(2xy)　⟹　Re = x²−y²+2，Im = 2xy

    把「沒有 i 的」集中成實部，「有 i 的」集中成虛部。任何複變數函數都可以這樣拆成 f(z) = u(x,y) + i·v(x,y)，而 u、v 各自都是實雙變數函數 —— 所以筆記旁邊才會補充「實雙變數函數」。

e⁻ᶻ 的拆解（這裡有一個很容易抄錯的負號）

  1. e⁻ᶻ = e⁻⁽ˣ⁺ⁱʸ⁾ = e⁻ˣ · e⁻ⁱʸ
    指數相加 = 底數相乘，先把實數部分 e⁻ˣ 分出來（它是純實數，不影響 Re/Im 的分配）。
  2. 尤拉公式：e^(iθ) = cos θ + i·sin θ
    這是唯一要記的工具。現在要代入的是 θ = −y。
  3. e⁻ⁱʸ = cos(−y) + i·sin(−y)

    cos 是偶函數：cos(−y) = cos y。
    sin 是奇函數：sin(−y) = −sin y。

  4. e⁻ⁱʸ = cos y − i·sin y　← 是減號

    所以 e⁻ᶻ = e⁻ˣcos y − i·e⁻ˣsin y，也就是 Re = e⁻ˣcos y、Im = −e⁻ˣsin y。

你的筆記這裡寫錯了

  • ✗ 筆記上寫 e⁻ᶻ = e⁻ˣ(cos y + i sin y)，這是錯的。
  • ✓ 正確是 e⁻ᶻ = e⁻ˣ(cos y − i sin y)，因此 Im = −e⁻ˣ sin y（筆記標的 Im = e⁻ˣ sin y 少了負號）。
  • 怎麼一秒檢查：取 x = 0、y = π/2，則 e⁻ᶻ = e^(−iπ/2) = −i。用正確版：cos(π/2) − i·sin(π/2) = 0 − i = −i ✓。用筆記版會得到 +i ✗。
  • 記憶法：指數上的 i 前面是什麼符號，sin 前面就是什麼符號。e^(+iθ) → cos θ + i sin θ；e^(−iθ) → cos θ − i sin θ。cos 永遠不變號。
03 · Why e⁻ˢᵗ

為什麼公式長這樣：乘 e⁻ˢᵗ 再積分

筆記上這個問題問得很好。答案分兩層：「積分」是為了把 t 消掉，「乘 e⁻ˢᵗ」是為了讓積分收斂、順便把 s 帶進來。下面這個模組把三條曲線疊給你看。

ℒ( f(t) ) = F(s) = ∫₀^∞ f(t) · e⁻ˢᵗ dt

第一層：為什麼是「定積分」而不是不定積分

  1. 不定積分：∫ t² dt = ⅓t³ + C　← 結果還是一個「函數」（有 t）
    這正是筆記上那兩行小字的意思。不定積分之後 t 還在。
  2. 定積分：∫₁² t² dt = [⅓t³]₁² = 8/3 − 1/3 = 7/3　← 結果是一個「數字」（沒有 t）
    上下限一代，t 就被消掉了。
  3. ∫₀^∞ f(t)e⁻ˢᵗ dt　⟹　t 被積掉，只剩下 s　⟹　F(s)

    所以轉換之後，函數的變數從 t 換成了 s。這就是「換一個世界」在數學上的實際意思。

第二層：為什麼偏偏是 e⁻ˢᵗ

  1. 理由一：它在 o.d.e. 裡本來就出現過。常係數線性微分方程的解永遠長成 e^(λt) 的形式（λ = α + jβ 是複數）。而 s = σ + jω 也是複數 —— 同一種東西。用 e⁻ˢᵗ 當探針，等於用 ODE 自己的語言去問它問題。

  2. 理由二：e⁻ˢᵗ 是「衰減因子」，負責把 f(t) 壓下去
    ∫₀^∞ 的上限是無限大。如果被積函數不衰減，積分就發散、根本算不出數字。乘上 e⁻ˢᵗ 之後，只要 s 夠大就能把 f(t) 的成長壓過去。
  3. 理由三：每換一個 s，就得到一個不同的面積 ⟹ 這些面積接起來就是 F(s)

    這是最關鍵的一點。F(s) 不是憑空出現的函數，它是「面積隨 s 變化」的紀錄。下面的模組把 s 拉一拉就看得很清楚。

cos 與 sin 那兩條不必硬背積分：用尤拉公式拆成兩個指數，再套 1/(s−a) 就好。這也是為什麼要先弄懂複數 —— 它讓三角函數和指數變成同一件事。

05 · Derivative Property

微分性質：ℒ(f′) = sF(s) − f(0)

這是整章最重要的一條，因為它就是「微分方程變代數方程」的那道門。筆記上先猜 ℒ(f′) = sF(s)（打了三個問號），推導完才發現後面還跟著一個 −f(0)。下面一步一步按給你看。

先說筆記上那個表格的直覺：在 o.d.e. 裡，若 f(t) = e^(st)，則 f′(t) = s·f(t)、f″(t) = s²·f(t) —— 微分就是乘 s。 所以會猜 ℒ(f′) = sF(s)、ℒ(f″) = s²F(s)。方向是對的，但漏掉了初始值。

二階怎麼辦：ℒ(f″) = s²F(s) − s·f(0) − f′(0)

  1. 把 f″ 看成 (f′)′，對 f′ 套一次同一條性質： ℒ(f″) = s·ℒ(f′) − f′(0)
    注意這裡減的是 f′(0)，因為現在被微分的對象是 f′。
  2. ℒ(f′) 已經知道了 = sF(s) − f(0)，代進去： = s[ sF(s) − f(0) ] − f′(0)
  3. = s²F(s) − s·f(0) − f′(0)

    注意 f(0) 前面帶著一個 s，f′(0) 沒有。這個順序常被寫反 —— 記法：階數越高的初始值，s 的次方越低。

筆記上的小筆誤

  • 最下面那個藍框寫 f′(t) —ℒ→ sF(s) = f(0)，中間應該是減號不是等號：f′(t) —ℒ→ sF(s) − f(0)。上面的 Theorem 那行你寫對了，所以應該只是手寫的筆誤，但抄到考卷上會很傷。
  • lim(t→∞) e⁻ˢᵗf(t) = 0 不是白送的。筆記寫「下次說明」是對的 —— 這需要 f(t) 是指數階（exponential order），也就是存在 M、a 使 |f(t)| ≤ M·e^(at)，而且 s > a。若 f(t) 長得比任何指數都快（例如 e^(t²)），拉普拉斯轉換根本不存在。
06 · Why the −f(0)

為什麼會多一個 −f(0)

推導看懂了，但「為什麼非要有它不可」還是會卡。最快的辦法是直接用一個具體函數對算一次：漏掉它，答案就是錯的。

漏掉 −f(0) 會怎樣

−f(0) 的來源很具體：它來自積分下限 t = 0。分部積分產生的邊界項 [e⁻ˢᵗf(t)]₀^∞ 在 t = 0 那端留下 e⁰·f(0) = f(0)，前面帶著減號。拉普拉斯積分從 0 開始，所以初始值一定會被帶進來 —— 這不是缺陷，這正是它能一次解決「微分方程 + 初始條件」的原因。

用 ℒ 解 ODE 時的檢查點

  1. 每出現一個 y′，就寫 sY(s) − y(0)；每出現一個 y″，就寫 s²Y(s) − s·y(0) − y′(0)。初始值永遠跟著微分項一起進場。
  2. 題目若沒給初始條件，就把 y(0) 留成符號不要自己設成 0。
  3. 整理成 Y(s)·(某個多項式) = (其他東西) 再移項，不要急著約分。
  4. 反轉換前先看分母：能不能湊成表上的 1/(s−a) 或 ω/(s²+ω²) 的形狀。

Errata · 筆記檢查結果

你的筆記勘誤

我把三頁筆記逐行驗算過。整體推導是正確的，尤其 ℒ(f′) 那段分部積分做得完全對。下面是需要改的地方。

① 尤拉公式的符號（要改）

  • 位置：第一頁「What is complex function?」的 f(z) = e⁻ᶻ 展開。
  • 筆記寫：e⁻ᶻ = e⁻ˣ(cos y + i sin y)
  • 應該是：e⁻ᶻ = e⁻ˣ(cos y − i sin y)，所以 Im = −e⁻ˣ sin y。
  • 驗證：取 x=0、y=π/2，e^(−iπ/2) 應該是 −i。正確版給 0 − i = −i ✓；筆記版給 +i ✗。

② Theorem 下方藍框的減號寫成等號（筆誤）

  • 位置：最後一頁，Theorem 下面那個方框。
  • 筆記寫：f′(t) —ℒ→ sF(s) = f(0)
  • 應該是：f′(t) —ℒ→ sF(s) − f(0)
  • 方框上一行的 Theorem 你寫對了（sℒ(f(t)) − f(0) = sF(s) − f(0)），所以判斷是手寫筆誤。
③ 請自己確認一下（手寫看不清楚）：第二頁寫 ∫t²dt = ⅓t?+C。 正確是 ∫t²dt = ⅓t³ + C（次方要 +1）。如果你寫的是 t² 就要改成 t³。 下面那行 ∫₁² t²dt = ⅓t³|₁² = 7/3 是正確的（8/3 − 1/3 = 7/3）。
寫得好的地方： ℒ(f′) 的分部積分推導完全正確，包含 d(e⁻ˢᵗ) = −s·e⁻ˢᵗdt 那個關鍵代換、以及 t→0 時 e⁰ = 1 所以只剩 f(0)。 另外你在 lim(t→∞) 那項旁邊註明「下次說明」也很到位 —— 那一項要為 0 確實需要額外條件（指數階），不是理所當然。 表格裡先寫猜測值 sF(s) 再打三個問號、最後修正成 sF(s) − f(0)，這種記法很好，把「錯誤的直覺」也記下來了。
