常係數 ODE 與特徵方程

這單元抽象的地方在於：一堆 λ、C₁、C₂ 跑出來，但你看不到它們長什麼樣子。這頁的核心是一張圖 —— 把 λ 拖到複平面的不同位置，右邊的解立刻改變形狀。看過一次就很難忘。

Big picture

一句話說完這單元

把變成一個二次方程，解出兩個 λ，答案的形狀就決定了。剩下的只是用把兩個係數算出來。

整個流程只有四步

  1. y″ + ay′ + by = 0　（、、二）
    未知的是一個函數 y(t)，不是一個數字。這是它跟你熟悉的方程式最大的差別。
  2. 猜 y = e^(λt)　⟹　λ² + aλ + b = 0　（，好解）
    微分方程直接變成國中的一元二次方程。這就是整個方法的價值。
  3. 解出 λ₁、λ₂　⟹　通解的「形狀」就定了
    兩根是相異實根、、還是，會給出三種不同形狀的解。由 D = a² − 4b 判斷。
  4. 用 y(0)、y′(0) 解聯立，定出 C₁、C₂　⟹　唯一解
    裡有兩個自由參數，剛好需要兩個初始條件把它們釘死，得到唯一的。

跟拉普拉斯轉換的關係：兩者都是在解同一類問題。特徵方程法是先求通解再代初始條件；拉普拉斯則是把初始條件在轉換當下就吃進去。方程越複雜（高階、有外加輸入），拉普拉斯越占優勢。

01 · 為什麼是這個猜法

為什麼可以「猜」y = eλt

這不是亂猜，是式子的結構逼出來的。你的筆記上老師那段推理寫得很好，這裡把它講細一點。

結構決定了答案只能長那樣

  1. 令 y(t) 是函數，y′(t) = h(t)，y″(t) = g(t)
    先承認它們是三個不同的函數，然後看方程在要求什麼。
  2. 方程說：g(t) + a·h(t) + b·y(t) = 0　對所有 t 都成立

    三個函數線性組合後恆為零，這是很強的限制 —— 它們必須是「同一種東西」的倍數， 否則不可能處處抵銷。

  3. 所以要找一種函數：微分之後還是自己的倍數
    滿足這個性質的函數只有指數函數。這就是 e^(λt) 出場的理由 —— 不是猜，是唯一的候選。
  4. y = e^(λt)　⟹　y′ = λ·y　，　y″ = λ²·y

    微分變成「乘 λ」。代回原式，每一項都有 y 可以提出來：

    (λ² + aλ + b)·y = 0，而 y = e^(λt) ≠ 0　⟹　λ² + aλ + b = 0

注意 e^(λt) 永遠不等於 0（指數函數恆正），所以才能安心把它除掉。這一步在你的筆記上有寫 y(t) ≠ 0，很好，那不是廢話，是必要條件。

04 · 最容易被當成「硬背」的地方

重根為什麼要多一個 t

大家都背過「重根要乘 t」，但為什麼？因為重根只給你一個解，不夠用 —— 二階方程需要兩個的解。

缺一個解，所以要補一個

  1. 二階微分方程需要兩個線性獨立的解
    因為有兩個初始條件（y(0) 和 y′(0)）要滿足，就需要兩個自由係數 C₁、C₂。
  2. 相異實根時：e^(λ₁t) 和 e^(λ₂t) 是兩個不同的函數 ✓ 夠用
  3. 重根時：λ₁ = λ₂ = λ　⟹　兩個解變成同一個 e^(λt)　✗ 只有一個

    C₁e^(λt) + C₂e^(λt) = (C₁+C₂)e^(λt)，兩個係數合併成一個，自由度掉了一半， 沒辦法同時滿足兩個初始條件。

  4. 補上 t·e^(λt)　⟹　y = (C₁ + C₂t)e^(λt)

    可以直接驗證它確實是解：令 y = t·e^(λt)，代入 y″ + ay′ + by（其中 a = −2λ、b = λ²）， 展開後會完全抵銷為 0。而且它跟 e^(λt) 線性獨立（一個有 t 一個沒有），自由度補回來了。

在上面的疊圖裡切到「重根」：曲線前期會被那個 t 稍微頂高一點，之後才被指數壓下去。 這就是 t·e^(λt) 的形狀 —— 先升後降，跟純指數的單調下降不一樣。

05 · 從複數回到實數

共軛複根為什麼會變成 cos 和 sin

根算出來是複數，但 y(t) 是實際存在的物理量，不可能是複數。負責把它翻譯回實數。

翻譯過程

  1. λ = α ± βi　⟹　y = C₁e^((α+βi)t) + C₂e^((α−βi)t)
    兩個複根各給一個解。現在要把它整理成實數形式。
  2. 把共同的 e^(αt) 提出來：y = e^(αt)·[ C₁e^(iβt) + C₂e^(−iβt) ]
    指數相加 = 底數相乘，先分離出純實數的部分。
  3. 尤拉公式：e^(iθ) = cos θ + i sin θ，　e^(−iθ) = cos θ − i sin θ

    代進去展開，虛部在適當選 C₁、C₂ 時會互相抵銷（因為 y 必須是實數）：

  4. y = e^(αt)·( A cos βt + B sin βt )

    結構非常好記：α（實部）變成前面的指數包絡，β（虛部）變成裡面的振盪頻率。

  5. 物理意義：e^(αt) 是「振幅怎麼變」，cos/sin 是「怎麼晃」
    α < 0 → 愈晃愈小（衰減振盪）；α = 0 → 永遠等幅晃（純振盪）； α > 0 → 愈晃愈大（發散振盪）。β 越大晃得越快。

回到上面那張根平面圖：共軛複根一定成對出現、對稱於實軸。 往左拖（α 更負）→ 衰減更快；往上下拖（β 更大）→ 晃得更快。兩個效果互相獨立。

06 · 完整解題流程

跟著走一遍（數字可以自己改）

解常係數齊次 ODE 的標準流程

  1. 寫特徵方程：把 y″→λ²、y′→λ、y→1，直接照抄係數。
  2. 算判別式 D = a² − 4b，決定是哪一種根 → 通解形式跟著決定。
  3. 寫通解：D>0 → C₁e^(λ₁t)+C₂e^(λ₂t)；D=0 → (C₁+C₂t)e^(λt)；D<0 → e^(αt)(A cos βt+B sin βt)。
  4. 微分一次得 y′(t)，代入 y(0) 與 y′(0) 解兩元一次聯立。
  5. 驗算：把 C 代回去，檢查 y(0) 和 y′(0) 對不對。這一步只要十秒，卻能救回整題。

這單元最常見的錯誤

  • ✗ 解聯立時符號弄錯。這是最高頻的失分點（你這次就是栽在這裡）。 y′ 的每一項都會多一個 λ 係數，代 0 進去時負號很容易漏。 ✓ 解完一定要代回去驗算。
  • ✗ 重根忘記乘 t，只寫 C₁e^(λt)。自由度不夠，一定滿足不了兩個初始條件。
  • ✗ 複根答案留著 i。物理量是實數，要用尤拉公式整理成 cos/sin 形式。
  • ✗ 變數混用 x 和 t。題目用 t 就整題用 t，不要中途變成 x。
