Overview

整張考卷只有五種題FIVE QUESTION TYPES

基本題、進階題是同樣五種，進階題只是多了「位移」和「配方」。③ 和 ④ 算到最後都會變成 ②，所以 ② 練最多。

題型基本題進階題拿到題目先做什麼
① ℒ 正轉換一-1一-1拆開 → 查表 → 有 eat 就 s 換 s − a；有 u(t − a) 就乘 e−as
② ℒ−1 反轉換一-2一-2分母能分解 → 部分分式；不能 → 配方、分子湊成同一個括號 → 查表
③ 解 ODE二二兩邊取 ℒ、代初值 → 解出 Y(s) → 走 ②
④ RLC 電路三三-1元件換成 s 域（L 串 Li₀、C 串 v₀/s）→ KVL → 解出 I(s) → 走 ②
⑤ 摺積四三-2翻一個、滑過去，分「進場、全重疊、離場」三段

Type ① · 基本題一-1、進階題一-1

ℒ 正轉換LAPLACE TRANSFORM

純查表。基本題只要表；進階題多了兩種位移，分清楚「乘 eat」和「後面跟著 u(t − a)」就好。

Type ② · 基本題一-2、進階題一-2

ℒ−1 反轉換INVERSE TRANSFORM

反過來查表。卡關的地方永遠是分母：先試著分解，不行就配方，再把分子湊成跟括號一樣。

Type ③ · 基本題二、進階題二

用 ℒ 解微分方程SOLVING ODEs

固定五步：取 ℒ → 代初值 → 解出 Y(s) → 部分分式或配方 → 反轉換。最後代 t = 0 驗初值。

Type ④ · 基本題三、進階題三-1

用 ℒ 解 RLC 電路RLC CIRCUITS

把每個元件換成 s 域，電感、電容的初值變成一顆小電池，然後就是一條 KVL。

Type ⑤ · 基本題四、進階題三-2

摺積 f ∗ gCONVOLUTION

把 g 翻過來從左邊滑進 f，每個時刻的重疊面積就是答案。方塊碰方塊，答案永遠是斜坡、平台、下坡。

勘誤CORRECTIONS

  • ✗ 考卷進階一-2 旁邊寫 s² − 2s − 4 = (s − 1)² − 3　✓ (s − 1)² − 5
  • ✗ 考卷進階一-2 旁邊寫 s² + 4s + 8 = (s + 1)² + 4　✓ (s + 2)² + 4，分子 2s + 1 = 2(s + 2) − 3
  • ✗ 朋友筆記摺積例 2：g(t − τ) 左邊界寫 −5 − t　✓ t − 5
  • 朋友筆記 (1)～(8) 的其他公式、摺積例 1～4 的數字（30、18、60 − 6t、48 − 6t）都驗算過，是對的。
  • 請確認：基本一-2 第一項是 1/4 還是 1/s（看不太清楚）。1/4 → ¼δ(t)；1/s → u(t)。
