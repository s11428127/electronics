開頭複習：上週講到哪REVIEW

老師一開始把前兩週的重點串成六點。主線只有一條：微分方程難解 → 用 把它搬去 s 的世界 → 微分變成乘 s。今天整堂課就是在把這條主線補完整。

ℒ( f(t) ) = F(s) = ∫₀∞ f(t) e−st dt

六點複習（已更正）

  1. 1.　ℒ(f(t)) = F(s) = ∫₀∞ f(t) e−st dt，　t ∈ ℝ，　s = σ + jω ∈ ℂ
    t 是時間，一定是實數；s 是我們自己發明的新變數，可以是複數。σ 是實部、ω 是虛部。
  2. 2.　f(t) ──ℒ──→ F(s)：　實數函數（real function）──→ 複數函數（complex function）
    輸入是實數 t 的函數，輸出變成複數 s 的函數 —— 這就是「搬到另一個世界」。
  3. 3.　s = σ + jω，　λ = α + jβ ∈ ℂ，　z = a + jb
    三個都是複數的寫法，只是用在不同地方：s 給拉普拉斯、λ 給特徵根、z 是一般的複數。實部＋j·虛部，格式都一樣。
  4. 4.　y″ + 3y′ + 2y = 0（ODE）──猜 y = eλt──→ λ² + 3λ + 2 = 0（代數方程）
    猜指數函數，是因為它微分完還是自己的倍數，整條式子可以提出 eλt，剩下 λ 的二次方程。三種根對應三種解： ① 相異實根 λ₁、λ₂：y = C₁eλ₁t + C₂eλ₂t； ② λ₁ = λ₂ = λ：y = C₁eλt + C₂t eλt； ③ α ± jβ：y = C₁e(α+jβ)t + C₂e(α−jβ)t = eαt(A cos βt + B sin βt)（③ 的推導在第 06 節）。
  5. 5.　ODE 用 est：f′ = s f、f″ = s² f　｜　拉普拉斯：ℒ(f′) = sF(s) − f(0)、ℒ(f″) = s²F(s) − s f(0) − f′(0)
    左右兩欄是同一件事的兩種版本：「微分一次 ≈ 乘一次 s」。拉普拉斯版多了 −f(0) 那些尾巴，那是被自動吃進去。
  6. 6.　Thm：ℒ(f′(t)) = s ℒ(f(t)) − f(0) = sF(s) − f(0)
    今天所有東西都從這一條長出來。它的證明在第 07 節。

ℒ(f″) 怎麼來：把 f″ 看成「f′ 的導數」LAPLACE OF f″

我們只證明過一次微分的公式。老師的招式是：不要重新積分，把舊公式套兩次。f″ 就是 (f′)′，所以把 f′ 當成新的「f」丟進定理就好。

ℒ( f″(t) ) = s²F(s) − s f(0) − f′(0)

板書推導（照片 2 中間那塊）

  1. ℒ(f″(t)) = ℒ( (f′(t))′ )
    二次微分 = 「一次微分的一次微分」。這樣就能用手上唯一的定理。
  2. = s ℒ(f′(t)) − f′(0)
    把定理 ℒ(g′) = sℒ(g) − g(0) 裡的 g 換成 f′。注意尾巴是 g(0) = f′(0)，不是 f(0)。
  3. = s [ s ℒ(f(t)) − f(0) ] − f′(0)
    ℒ(f′(t)) 又是一次微分，再套一次定理。
  4. = s² ℒ(f(t)) − s f(0) − f′(0)
    把中括號乘開：s 乘進去，f(0) 前面就多了一個 s。
  5. = s²F(s) − s f(0) − f′(0)
    ℒ(f(t)) 本來就叫 F(s)，換回簡寫。

高階導數的標準招式

  1. 把 f⁽ⁿ⁾ 寫成 (f⁽ⁿ⁻¹⁾)′。
  2. 套一次定理：s·ℒ(f⁽ⁿ⁻¹⁾) − f⁽ⁿ⁻¹⁾(0)。
  3. ℒ(f⁽ⁿ⁻¹⁾) 用上一階的結果代進去，乘開。

照片 3 · 黑板05 · To sum up

總整理：ℒ(f⁽ⁿ⁾) 的通式TO SUM UP

把 1～4 階排在一起看，規律就跳出來了：一個 sⁿF(s)，後面扣 n 項，s 的次方一路往下降、f 的階數一路往上升。像翹翹板：一邊少 1，另一邊就多 1。

ℒ( f⁽ⁿ⁾(t) ) = sⁿF(s) − sn−1f(0) − sn−2f′(0) − … − s f(n−2)(0) − f(n−1)(0)

板書 To Sum Up

  1. 1.　ℒ(f′(t)) = sF(s) − f(0)
    扣 1 項。
  2. 2.　ℒ(f″(t)) = s²F(s) − s f(0) − f′(0)
    扣 2 項。
  3. 3.　ℒ(f‴(t)) = s³F(s) − s²f(0) − s f′(0) − f″(0)
    扣 3 項。
  4. 4.　ℒ(f⁽⁴⁾(t)) = s⁴F(s) − s³f(0) − s²f′(0) − s f″(0) − f‴(0)
    扣 4 項。
  5. 5.　ℒ(f⁽ⁿ⁾(t)) = sⁿF(s) − sn−1f(0) − sn−2f′(0) − … − s f(n−2)(0) − f(n−1)(0)
    扣 n 項。可以用數學歸納法證：假設 n 階成立，對 f⁽ⁿ⁺¹⁾ = (f⁽ⁿ⁾)′ 套一次定理，整串乘 s 再扣 f⁽ⁿ⁾(0)，剛好就是 n+1 階的樣子。

板書 Ex.（老師當場解，已驗算 ✓）

  1. 1.　ℒ(f⁽⁶⁾(t)) = s⁶F(s) − s⁵f(0) − s⁴f′(0) − s³f″(0) − s²f⁽³⁾(0) − s f⁽⁴⁾(0) − f⁽⁵⁾(0)
    扣 6 項，每項「次方 + 階數」= 5 ✓。
  2. 2.　ℒ(f⁽¹⁰⁾(t)) = s¹⁰F(s) − s⁹f(0) − s⁸f′(0) − s⁷f″(0) − s⁶f⁽³⁾(0) − s⁵f⁽⁴⁾(0) − s⁴f⁽⁵⁾(0) − s³f⁽⁶⁾(0) − s²f⁽⁷⁾(0) − s f⁽⁸⁾(0) − f⁽⁹⁾(0)
    扣 10 項，每項「次方 + 階數」= 9 ✓。

寫 ℒ(f⁽ⁿ⁾) 的步驟

  1. 先寫 sⁿF(s)。
  2. 後面接 n 個減號（全部都是減）。
  3. s 的次方從 n−1 往下數到 0；f 的階數從 0 往上數到 n−1。
  4. 檢查：每一項「s 的次方 + f 的階數」都要等於 n−1。

常見錯誤

  • ✗ 扣 n−1 項或 n+1 項。✓ n 階就扣 n 項，數一下減號。
  • ✗ 最後一項寫成 s·f(n−1)(0)。✓ 最後一項 s 的次方是 0，沒有 s。
  • ✗ 寫成 F(0) 或 f(s)。✓ 尾巴是小寫 f 在 t = 0 的值（初始條件），大寫 F(s) 只出現在第一項。
  • ✗ 中間有項變成加號。✓ 每一次套定理都是「減」掉初始值，所以全部都是減。
照片 4 · 黑板06 · Supplement 1

補充一：共軛複根怎麼變成 cos、sinCOMPLEX CONJUGATE ROOTS

複習第 4 點 ③ 直接給了答案 eαt(A cos βt + B sin βt)。老師在這裡補上中間的過程：先把指數拆成「實部那半」和「虛部那半」，虛部那半丟給尤拉公式翻成 cos、sin。

λ = α ± jβ　⇒　y(t) = eαt( A cos βt + B sin βt )

板書推導

  1. y(t) = C₁e(α+jβ)t + C₂e(α−jβ)t
    兩個根各給一個指數解，加起來就是通解（跟相異實根一樣的寫法）。
  2. = C₁eαt·ejβt + C₂eαt·e−jβt
    指數律 ea+b = ea·eb，把實部和虛部拆開。
  3. = eαt( C₁ejβt + C₂e−jβt )
    兩項都有 eαt，提出來。它就是「包絡線」：α < 0 衰減、α > 0 發散。
  4. = eαt[ C₁(cos βt + j sin βt) + C₂(cos βt − j sin βt) ]
    尤拉公式，θ = βt。
  5. = eαt[ (C₁+C₂) cos βt + j(C₁−C₂) sin βt ]
    cos 的放一起、sin 的放一起。
  6. = eαt( A cos βt + B sin βt )，　A = C₁ + C₂，　B = j(C₁ − C₂)
    把兩坨常數重新取名字。A、B 是新的兩個任意常數，個數沒變（還是兩個）。
板書沒寫、但值得知道的一句補：B = j(C₁ − C₂) 裡有 j，那 B 不就是虛數？ 不會 —— y(t) 是實際的物理量，所以 C₁、C₂ 本身會是一對共軛複數（C₂ = C₁ 的共軛）。 例如 C₁ = 1 − 2j、C₂ = 1 + 2j：A = 2，B = j(−4j) = 4，兩個都是實數。

常見錯誤

  • ✗ α、β 放反，寫成 eβt(A cos αt + …)。✓ 實部 α 在外面管大小，虛部 β 在 cos/sin 裡管振盪。
  • ✗ 第二個根的尤拉公式忘了變號。✓ e−jβt = cos βt − j sin βt。
照片 4 · 黑板07 · Supplement 2

補充二：證明 ℒ(f′) = sF(s) − f(0)PROOF BY INTEGRATION BY PARTS

整堂課都在用這條定理，這裡補上它的證明。工具只有一個：。想法是把「f′ 的積分」換成「f 的積分」，而 f 的積分就是 F(s)。

∫ f dg = f·g − ∫ g df　　（分部積分）

板書推導

  1. ℒ(f′(t)) = ∫₀∞ f′(t) e−st dt
    定義：把 f′ 丟進拉普拉斯的積分。
  2. = ∫₀∞ (df(t)/dt) e−st dt = ∫₀∞ e−st df(t)
    f′ = df/dt，dt 約掉，變成「對 f 積分」，形狀就是 ∫ (某函數) d(某函數)，可以分部積分。
  3. = e−st f(t) |₀∞ − ∫₀∞ f(t) d(e−st)
    分部積分，這裡的「f」是 e−st、「g」是 f(t)。
  4. d(e−st) = (−s) e−st dt
    對 t 微分，連鎖律帶出 −s（s 對 t 來說是常數）。
  5. = limt→∞ e−st f(t) − e0 f(0) + s ∫₀∞ f(t) e−st dt
    上限代 ∞（用極限）、下限代 0；後面「減掉 (−s)」變成加 s。
  6. = 0 − f(0) + s F(s) = sF(s) − f(0)
    第一項的極限是 0（老師標「待證」，第 08 節證明）；e0 = 1；最後那個積分正好是 F(s)。
請確認：照片裡倒數第二行看起來是「− s∫₀∞ f(t)e−stdt」。 正確應該是 + s∫…（「減去 (−s)」= 加 s），不然最後得不到 sF(s)。可能是粉筆字看不清楚，或老師寫的時候少一個負號；最後一行答案 sF(s) − f(0) 是對的。
照片 5 · 黑板08 · Proof of the limit

證明 limt→∞ e−st f(t) = 0WHY THE BOUNDARY TERM VANISHES

上一節偷用了「e−stf(t) 在 t → ∞ 時是 0」。麻煩在 s 是複數，e−st 不是一條普通的曲線。老師的做法：取，把會轉圈圈的 e−jωt 消掉，只剩實數的部分。

| e−st f(t) | = | e−σt f(t) |　（因為 | e−jωt | = 1）

板書推導（s = σ + jω）

  1. lim | e−st f(t) | = lim | e−(σ+jω)t f(t) |
    一個複數是 0 ⇔ 它的長度是 0，所以證「絕對值 → 0」就夠了。s 拆成實部 + 虛部。
  2. = lim | e−σt f(t) | · | e−jωt |
    指數拆開；複數相乘的長度 = 長度相乘。
  3. = lim | e−σt f(t) | · | cos ωt − j sin ωt |
    尤拉公式（第 03 節的 e−jθ，θ = ωt）。
  4. = lim | e−σt f(t) | · √( cos²ωt + (−sin ωt)² ) = lim | e−σt f(t) | · 1
    複數 a + jb 的長度是 √(a² + b²)，而 cos² + sin² = 1。就是單位圓上的點，長度永遠 1。
  5. = limt→∞ | e−σt f(t) | = 0
    剩下全部是實數。最後這個「= 0」不是自動成立的 —— 要 f(t) 長得不要太快、σ 夠大，這就是下一節「存在的條件」。
照片 5、6 · 黑板09 · Existence

拉普拉斯轉換什麼時候存在EXISTENCE CONDITION

e−σt 像一個往下拉的力量，f(t) 是往上衝的力量。只要 e−σt 拉得贏，乘起來就趨近 0，ℒ 就存在。拉不拉得贏，看 f(t) 長得多快 —— 這就是的意思。

ℒ(f(t)) 存在的條件：limt→∞ f(t) e−σt = 0，　σ > a，　a ∈ ℝ

板書：limt→∞ f(t) e−σt 的三種情況（σ > 0）

  1. lim f(t) < ∞（f 不會衝到無限大）　⇒　0
    有限的數 × 趨近 0 的數 = 0。例：f(t) = 5、sin t。
  2. lim f(t) = ∞，但 f 長得比 eσt 慢　⇒　0
    兩個都衝無限大，比誰快。例：t²、e2t（σ > 2 時）。
  3. lim f(t) = ∞，而且 f 長得比 eσt 快　⇒　∞
    拉不住，ℒ 不存在。例：et²。
板書的 Q：什麼條件下 ① lim f(t)e−σt = 0 但 lim f(t) = ∞？② lim f(t)e−σt = ∞ 且 lim f(t) = ∞？
答補：看 f(t) 跟 eσt 誰長得快。① f 最多像某個指數 eat 那樣長（多項式、eat 都算），只要取 σ > a 就壓得住；② f 長得比任何指數都快（像 et²），再大的 σ 都沒用。這就是條件裡「σ > a」的意思。

板書 Ex. 三題（照片 6 的完整解）

  1. 1.　lim e−σt·t² = lim t² / eσt = lim 2t / (σeσt) = lim 2 / (σ²eσt) = 0　（σ > 0）
    先看 lim t² = ∞，t² 往上衝。改寫成 ∞/∞ 型，用上下各微分，做兩次 t² 就被微掉了，分母還是 ∞。板書結論：ℒ(t²) 存在，σ > 0。
  2. 2.　lim e−σt·e2t = lim e2t / eσt = lim e−(σ−2)t = 0，σ > 2
    指數合併，只看指數的正負：σ > 2 時 −(σ−2) 是負的 → 0（σ = 2 時是 1、σ < 2 時是 ∞）。板書結論：ℒ(e2t) 存在，σ > 2。
  3. 3.　lim e−σt·et² = lim et² / eσt = lim et²−σt = lim et(t−σ) = ∞
    t 一超過 σ，指數就變正而且越來越大，不管 σ 多大。板書結論：ℒ(et²) 不存在。

判斷 ℒ(f) 存不存在

  1. 寫出 f(t)e−σt，能合併的指數先合併。
  2. 是 ∞/∞ 型就用羅必達，或直接比「誰長得快」：常數 < 多項式 < eat < et²。
  3. 找得到一個 a，讓 σ > a 時極限 = 0 → 存在，收斂範圍就是 σ > a。

常見錯誤

  • ✗ 忘了寫 σ 的範圍。✓ ℒ(e2t) = 1/(s−2) 要附上 σ > 2。
  • ✗ 直接對複數 s 取極限。✓ 先取絕對值，把 e−jωt 消掉（長度 1），只剩實數 σ。

拆開來各自查表：ℒ 與 ℒ⁻¹ 的例題EXAMPLES & INVERSE TRANSFORM

有了 1/s 和 1/(s − a) 兩張「查表卡」，遇到一長串加減的函數，就拆開、各自查表、再加回來。反過來從 F(s) 找回 f(t)，叫做 ℒ⁻¹。這一招能用，靠的是下一節要證明的「線性」—— 老師這裡先用、後面補證明（板書寫「後補」）。

f(t) ──ℒ──→ F(s)　　　f(t) ←──ℒ⁻¹── F(s)

Ex. 1　ℒ(2u(t) + 4 + e2t)（照片 10）

  1. = 2ℒ(u(t)) + 4ℒ(1) + ℒ(e2t)
    線性：加號拆開、常數提出去（後補證明，第 12 節）。
  2. = 2/s + 4/s + 1/(s − 2)
    查表：ℒ(u) = ℒ(1) = 1/s；ℒ(e2t) 是 a = 2。
  3. = 6/s + 1/(s − 2)
    同分母合併。收斂條件取兩個都成立的範圍：σ > 0 且 σ > 2 → σ > 2補。

  1. = ⅓ℒ(u(t)) − ¼ℒ(e−t/5)
    一樣拆開、常數提出。
  2. = ⅓·(1/s) − ¼·1/(s + ⅕)
    e−t/5 的 a = −⅕，所以 s − a = s + ⅕。

  2. = 2u(t) − 4e2t
    查表倒著用：1/s ← u(t)；1/(s − 2) ← e2t。

照片 13、14、15 · 黑板12 · Linearity

線性（疊加原理），以及 ℒ 為什麼是線性的LINEARITY · SUPERPOSITION

上一節一直在「拆開來各自算」，這一節補上為什麼可以這樣做。的意思很生活：果汁機打一顆蘋果得到一杯，打一根香蕉得到一杯；那「2 顆蘋果 + 3 根香蕉」一起打，就是 2 杯蘋果汁 + 3 杯香蕉汁，不會多出奇怪的東西。

若 T(x₁) = y₁、T(x₂) = y₂，則 T(ax₁ + bx₂) = ay₁ + by₂

定義（照片 13）

  1. A transform / operator T is called linear if T satisfies the principle of superposition（疊加原理）
    一個「轉換／運算子」T 就是一台機器：丟東西進去、吐東西出來。它若滿足疊加原理，就叫線性。
  2. i.e.（that is）：if T(x₁) = y₁, T(x₂) = y₂, then T(ax₁ + bx₂) = ay₁ + by₂
    輸入先「放大再相加」，等於輸出各自「放大再相加」。順序對調結果一樣。

疊加機（板書的方塊圖）

這裡拿 f(t) = 1、g(t) = e2t 當例子。調 a、b，最下面那一列的輸出永遠等於「上面兩列的輸出各乘 a、b 再相加」—— 這就是線性。

Thm. Laplace Transform is linear（照片 14、15）

  1. 要證：ℒ(af(t) + bg(t)) = aF(s) + bG(s)
    把定義裡的 T 換成 ℒ、x 換成 f 和 g。
  2. ℒ(af(t) + bg(t)) = ∫₀∞ (af(t) + bg(t)) e−st dt
    定義：整坨丟進積分。
  3. = ∫₀∞ ( af(t)e−st + bg(t)e−st ) dt
    e−st 乘進括號（分配律）。
  4. = ∫₀∞ af(t)e−st dt + ∫₀∞ bg(t)e−st dt
    積分本身就是線性的：和的積分 = 積分的和。
  5. = a∫₀∞ f(t)e−st dt + b∫₀∞ g(t)e−st dt
    常數 a、b 跟 t 無關，可以提到積分外面。
  6. = aF(s) + bG(s)　　Q.E.D.
    兩個積分正好就是 ℒ(f) = F(s)、ℒ(g) = G(s) 的定義。Q.E.D. = 證明完畢。

常見錯誤

  • ✗ 以為乘法也能拆：ℒ(f·g) = F(s)·G(s)。✓ 線性只管加法和乘常數，兩個函數相乘不能這樣拆。
  • ✗ 常數被當成函數轉換：ℒ(3f) = ℒ(3)·ℒ(f)。✓ 常數直接提出去：ℒ(3f) = 3F(s)。

ℒ(cos ωt)：不要硬積分，用聰明的方法THE SMART WAY

直接算 ∫₀∞ cos ωt·e−st dt 要分部積分兩次再移項，很煩（老師說「分部積分：不要做」）。聰明的方法是利用 cos 的特性：微分兩次會變回自己（乘上 −ω²）。再配合第 05 節的 ℒ(f″) 公式，一行代數就解出來。

ℒ(cos ωt) = s / (s² + ω²)　　ℒ(sin ωt) = ω / (s² + ω²)　（σ > 0）

板書推導（照片 15、16）

  1. f(t) = cos ωt，　f(0) = 1
    先把初始值準備好，等一下 ℒ(f″) 公式要用。cos 0 = 1。
  2. f′(t) = −ω sin ωt，　f′(0) = 0
    微分一次（連鎖律帶出 ω）。sin 0 = 0。
  3. f″(t) = −ω² cos ωt = −ω² f(t)　…… (1)
    再微一次，又變回 cos，只是多了 −ω²。這就是「聰明」的關鍵。
  4. 對 (1) 取 ℒ：ℒ(f″(t)) = ℒ(−ω² f(t)) = −ω² ℒ(f(t)) = −ω² F(s)
    右邊用線性，把常數 −ω² 提出去。
  5. s²F(s) − s f(0) − f′(0) = −ω² F(s)
    左邊用第 02 節的 ℒ(f″) 公式。
  6. s²F(s) − s = −ω² F(s)
    代 f(0) = 1、f′(0) = 0。
  7. (s² + ω²) F(s) = s　⇒　F(s) = ℒ(cos ωt) = s / (s² + ω²)
    F(s) 的項移到同一邊、提出來，再除過去。完全沒有積分。

ℒ(sin ωt)：板書 To Sum Up 第 4 格是空的，同一招補完補

  1. g(t) = sin ωt，g(0) = 0；g′(t) = ω cos ωt，g′(0) = ω；g″(t) = −ω² g(t)
    sin 也是微兩次變回自己乘 −ω²，只是初始值換成 0 和 ω。
  2. s²G(s) − s·0 − ω = −ω² G(s)　⇒　(s² + ω²) G(s) = ω
    兩邊取 ℒ，代初始值。
  3. G(s) = ℒ(sin ωt) = ω / (s² + ω²)
    cos 的分子是 s、sin 的分子是 ω。收斂條件跟 1 一樣是 σ > 0（cos、sin 不會長大）。
