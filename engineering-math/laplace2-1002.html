8. LinearLINEARITY

△ A transform / operator T is called linear, if T satisfies the principle of superposition（疊加原理），i.e.（that is） if T(x₁) = y₁，T(x₂) = y₂ then T(ax₁ + bx₂) = ay₁ + by₂ * if　x₁ → [T] → y₁，x₂ → [T] → y₂ 　then　ax₁ + bx₂ → [T] → ay₁ + by₂

Thm. Laplace Transform is linear

pf. ℒ(af(t) + bg(t)) = aF(s) + bG(s) ps：f(t) → [ℒ] → F(s)，g(t) → [ℒ] → G(s) ⇒ af + bg → [ℒ] → aF(s) + bG(s)
ℒ(af(t) + bg(t)) = ∫₀∞ (af(t) + bg(t)) e−st dt = ∫₀∞ (af(t)e−st + bg(t)e−st) dt = ∫₀∞ af(t)e−st dt + ∫₀∞ bg(t)e−st dt = a∫₀∞ f(t)e−st dt + b∫₀∞ g(t)e−st dt　　（ℒ(f(t)) = F(s)，ℒ(g(t)) = G(s)） = aF(s) + bG(s)　Q.E.D.

9. ℒ(cos ωt)、ℒ(sin ωt)、ℒ(tⁿ)COS · SIN · tⁿ

△ ℒ(cos ωt) = ?　ℒ(sin ωt) = ?

1. ℒ(cos ωt) = ∫₀∞ cos ωt e−st dt　　分部積分：不要做 * 用聰明的方法 f(t) = cos ωt，f(0) = 1 f′(t) = −ω sin ωt，f′(0) = 0 f″(t) = −ω² cos ωt = −ω² f(t)　——(1) 對 (1) 取 ℒ ℒ(f″(t)) = ℒ(−ω² f(t)) = −ω² ℒ(f(t)) = −ω² F(s) ⇒ s²F(s) − s f(0) − f′(0) = −ω² F(s) s²F(s) − s = −ω² F(s) (s² + ω²) F(s) = s ⇒ F(s) = ℒ(cos ωt) = s / (s² + ω²)

2. ℒ(sin ωt) = ∫₀∞ sin ωt e−st dt　　分部積分，不做

* 用聰明的方法 f(t) = sin ωt，f(0) = 0 f′(t) = ω cos ωt，f′(0) = ω f″(t) = −ω² sin ωt = −ω² f(t)　——(2) 對 (2) 取 ℒ ℒ(f″(t)) = ℒ(−ω² f(t)) = −ω² ℒ(f(t)) s²F(s) − s f(0) − f′(0) = −ω² F(s) s²F(s) − ω = −ω² F(s) (s² + ω²) F(s) = ω F(s) = ℒ(sin ωt) = ω / (s² + ω²)

△ ℒ(tⁿ) = ?

ℒ(tⁿ) = ∫₀∞ tⁿ e−st dt　　n 次分部積分，不做 * 用聰明的方法 f(t) = tⁿ，f(0) = 0 f⁽¹⁾(t) = n tn−1，f⁽¹⁾(0) = 0 f⁽²⁾(t) = n(n−1) tn−2，f⁽²⁾(0) = 0 ⋮ f(n−1)(t) = n(n−1)⋯2 t，f(n−1)(0) = 0 f⁽ⁿ⁾(t) = n(n−1)(n−2)⋯2×1 = n!　——(3) 對 (3) 取 ℒ ℒ(f⁽ⁿ⁾(t)) = ℒ(n!) = n!ℒ(1) = n!/s sⁿF(s) − sn−1f(0) − sn−2f⁽¹⁾(0) − ⋯ − f(n−1)(0) = n!/s　（f(0) ~ f(n−1)(0) 都是 0） sⁿF(s) = n!/s F(s) = ℒ(tⁿ) = n! / sn+1
