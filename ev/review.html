重點 4 · CH04 4.3.2、4.4.7、4.6.1；CH03 3.2.2

電動車的電力轉換設備POWER CONVERSION

📌 重點整理（照講義）

  • 逆變器：電池 DC → 驅動馬達的 AC；再生煞車時反向運作（AC → DC，當整流器）充電池。
  • DC-DC 轉換器：直流某一電壓 → 另一電壓（高壓電池 → 12/24 V）。
  • 車載充電器：電網 → 高壓電池（圖 4.7）。
  • 控制單元 PCU：控制逆變器，回應駕駛的煞車、加速訊號。
  • 開關元件：IGBT（高效率、快速切換）、MOSFET（逆變器切換裝置，只需極小電流）；切換訊號經脈寬調變。

重點 6 · CH03 3.1.13

定律：弗萊明左右手、安培定律LAWS

📌 重點整理（照講義）

  • 弗萊明定律：食指 = 磁場方向、中指 = 電流方向、拇指 = 導線運動方向；左手定則用於馬達，右手定則用於發電機。
  • 安培定律：於一封閉迴路中，各線段導線長度與該線段方向磁場強度乘積之和，等於此迴路所包圍之各電流大小與磁導率之乘積。
  • 歐姆（電流與電壓成正比）、楞次（感應電流方向與磁通變化相反）、法拉第（磁場改變 → 感應電動勢）、克希荷夫（流入 = 流出；迴路電位升降和 = 0）。

重點 7 · CH03 3.1.9～3.1.12；CH04 4.2.1、4.2.3

電動機跟發電機的原理MOTOR & GENERATOR

📌 重點整理（照講義）

  • 馬達：電能 → 機械能；利用兩磁場間交互作用（電流通過導體形成磁場）。
  • 發電機：機械能 → 電能；導體切割磁力線產生感應電壓，方向取決於磁場與運動方向，大小與切割速度成正比。
  • 兩者基本作用原理相同；電流的磁效應是繼電器、馬達、發電機的基本原理。
  • 電動車發電：煞車時馬達轉變成發電機（再生煞車／KERS），逆變器反向把 AC 變 DC 存進電池。

  • 目的：降低燃料消耗（及 CO₂）、降低廢氣排放、提高扭矩與功率；煞車時馬達變發電機回收能量。

  • 運轉模式：啟動、加速、巡航、減速、怠速。

重點 9 · CH04 4.2.4、圖 4.22～4.29

串並聯架構圖SERIES / PARALLEL

📌 重點整理（照講義）

  • 串聯式：燃料 → 引擎 → 發電機 →（電池）→ 電動馬達 → 變速箱 → 車輪；引擎只發電，馬達驅動車輛。屬重度。
  • 並聯式：引擎與馬達都可驅動車輛（燃料 → 引擎 → 變速箱；電池 → 馬達／發電機 → 變速箱）。大多數現行混合動力車採用。
  • 功率分配式：引擎 → 行星齒輪 → 發電機、電動馬達 → 變速箱；結合兩者優點但結構複雜。屬重度。
  • 七種細分：單離合器並聯（中度）、雙離合器並聯（重度）、雙離合器變速箱並聯、分軸並聯（重度）、串聯（重度）、串聯－並聯（混聯，串聯的延伸）、功率分配（重度）。

重點 11 · CH04 圖 4.37；CH03 3.1.7

電力線的內阻、高壓低壓、損失差異LINE LOSS

📌 重點整理（照講義）

  • I = P ÷ V：同功率，電壓越高，電流越小。
  • 線損 = I²R：30 kW、3 mΩ：48 V → 625 A → 約 1,172 W；350 V → 85.7 A → 約 22 W（圖 4.37）。
  • 電阻越大損失越大；導體電阻：長度越長越大、截面積越大越小、看材質（電阻率）、溫度越高越大。

重點 12 · CH04 圖 4.38；CH03 3.1.8

電池組什麼時候串聯、並聯SERIES / PARALLEL CELLS

📌 重點整理（照講義）

  • 串聯：電流相同、總電壓 = 各電壓之和 → 要高電壓就串（圖 4.38：串起來 350 V）。
  • 並聯：電壓相等、總電流 = 各支路電流之和 → 要大電流（容量）就並（圖 4.38：並起來 48 V）。
