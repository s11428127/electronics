整頁的主線

  1. 1.3.3：電腦模擬（SPICE、PSpice）算得準，但手算才看得出「誰影響誰」
    模擬只給數字。1973 年柏克萊做出 SPICE，PSpice 是它的 PC 版。講義的重點：參數之間的因果關係，只有手算分析看得到，所以模擬不能取代手算（投影片 1-1）。
  2. vD = VDQ + vd：直流決定 Q 點，交流在 Q 點上晃
    投影片 1-2。大寫＋大寫下標 = 直流；小寫＋小寫下標 = 交流；小寫＋大寫下標 = 總量。
  3. 交流夠小 ⟹ 二極體 = 一顆電阻 rd = VT/IDQ
    投影片 1-3～1-5。這就是「小訊號分析」：先做 DC 找 Q 點，再做 AC 用 rd，最後加起來。
  4. 交流太大 ⟹ 失真：Q 點要設計得夠高

    投影片 1-9。小訊號的前提是「夠小」，超過就不能當電阻看。

補課：交流在曲線上長什麼樣子READING THE SMALL-SIGNAL PICTURE

講義 1-2 那張圖有三塊：右上是二極體曲線，下面是電壓隨時間的波形，左邊是電流隨時間的波形。像水龍頭：把手（電壓）來回小小轉，水流（電流）就跟著變。

vD(t) = VDQ + vd(t)　→　每一刻往上找曲線　→　iD(t) = IDQ + id(t)

一張圖，三個部分

  1. 右上：二極體曲線，直流 VDQ 對到 Q 點（IDQ）
    沒有交流時二極體就停在這裡。例：VDQ = 0.677 V → IDQ = 2 mA（IS = 10−14 A）。
  2. 下面：vD(t) 轉 90° 畫在橫軸下面，越往下時間越晚
    電壓在 VDQ 左右來回。橫軸是電壓，所以電壓波形只能「站著」畫。
  3. 每一刻：從電壓往上碰到曲線，再往左讀電流
    這就是二極體在做的事：給它這個電壓，它就給這個電流（曲線上的點）。
  4. 左邊：把每一刻的電流連起來 = iD(t)，在 IDQ 上下來回
    縱軸是電流，所以電流波形「躺著」畫在左邊，越往左時間越晚。
  5. 整段交流期間，工作點只在 Q 附近「一小段曲線」上來回滑

    交流越小，那一段越短、越像直線（下一節的小訊號、第 02 節的切線 rd）。交流太大，那一段明顯彎，電流波形上下不對稱（第 04 節的失真）。

  • ✗ 電壓晃多少，電流就晃一樣比例。電流變化由曲線斜率決定：越陡，同樣的電壓晃動，電流晃越多。

原講義 PART 501 · 投影片 1-2、1-3 · 1.4.1 Sinusoidal Analysis

：直流上面疊一點交流DC PLUS A SMALL AC SIGNAL

直流電源讓二極體停在 Q 點；交流訊號讓它在 Q 點附近小小地晃。晃得夠小，那一小段彎線看起來就是直的。

vD = VDQ + vd　　iD = IDQ + id　　vd ≪ VT = 26 mV ⟹ id ≈ vd / rd

總量 = 直流 + 交流

  1. vD = VDQ + vd
    電壓拆兩份。VDQ 是直流電源和電阻決定的工作點（PART 5 的負載線），vd 是疊上去的交流（投影片 1-2）。
  2. iD = ISe(VDQ + vd)/VT = IDQ · evd/VT
    指數的加法變乘法。順偏時 −1 可以丟掉，直流那一項就是 IDQ。
  3. vd ≪ VT ⟹ evd/VT ≈ 1 + vd/VT
    泰勒展開只留前兩項。vd 只有幾 mV 時，後面的平方項小到可以忽略（投影片 1-4、1-5）。
  4. iD ≈ IDQ + (IDQ/VT)·vd
    直流照舊，交流跟 vd 成正比。正比 = 線性 = 電阻的行為。
  5. id = vd / rd，rd = VT/IDQ

    對交流來說二極體就是一顆電阻（投影片 1-3：AC Model）。前提是 vd 夠小，不然 rd 不是定值；Q 點換了，斜率換了，rd 也跟著換。

拿到「直流＋交流」的題目

  1. 把每個量拆成直流（大寫）和交流（小寫）兩份。
  2. 直流部分照 PART 5 的方法找 Q 點（IDQ、VDQ）。
  3. 檢查交流夠不夠小：二極體上的 vd 要 ≪ 26 mV。
  4. 夠小 → 二極體換成 rd = VT/IDQ 算交流。

小訊號的陷阱

  • ✗ 小訊號就是「電壓小」。是交流比 VT 小；直流可以很大。
  • ✗ VD、vd、vD 隨便寫。大寫直流、小寫交流、小寫＋大寫下標是總量，考卷靠這個分。
  • ✗ 交流多大都能用 rd。vd 接近 26 mV 就開始失真，上下不對稱。

原講義 PART 502 · 投影片 1-3～1-5、1-11、1-12 · Incremental Resistance

rdINCREMENTAL RESISTANCE

在 Q 點畫一條切線：切線的斜率就是二極體對交流的「導電能力」gd，倒過來就是電阻 rd。電流越大，曲線越陡，rd 越小。

gd = diD/dvD|Q = IDQ/VT　　rd = 1/gd = VT/IDQ　　（1 mA → 26 Ω）

對曲線微分，得到 rd

  1. iD = IS(evD/(nVT) − 1)
    二極體方程式（PART 4）。講義 1-11 帶著 n，一般 n = 1。
  2. diD/dvD = (IS/nVT)·evD/(nVT)
    指數微分不變，鏈鎖律掉出 1/(nVT)；那個 −1 微分後消失。
  3. 在 Q 點：ISeVDQ/(nVT) ≈ IDQ ⟹ gd = IDQ/(nVT)
    講義用紅筆圈起來的那一塊就是 IDQ（順偏、指數 ≫ 1）。這叫增量電導或擴散電導。
  4. rd = 1/gd = nVT/IDQ
    增量電阻跟增量電導互為倒數（投影片 1-4）。也叫擴散電阻。
  5. 講義 1-12：IS = 10−14 A、VDQ = 0.6 V ⟹ IDQ = 105.24 μA、rd ≈ 247 Ω

    微分算 gd = 4.048 × 10−3 A/V → 247 Ω；近似式 0.026/105.24 μA → 247 Ω。兩種算法一樣（MATCHED）。

求 rd 的標準流程

  1. 先求 IDQ（題目給 VDQ 就用 ISeV/VT；給電路就用 PART 5 的方法）。

原講義 PART 502+ · 補課 · 投影片 1-4、1-11 ＋ PART 5 的 rf

補課：為什麼要微分？rd 和 rf 差在哪WHY DIFFERENTIATE · rd VS rf

微分 = 某一點的斜率：在 Q 點電壓多推一小步，看電流多多少。二極體是指數，所以這個斜率剛好等於「現在的電流 ÷ 26 mV」，倒過來就是 rd。rd 是 Q 點腳下的坡度（交流用）；PART 5 的 rf 是一條線用到底的平均坡度（直流用）。

斜率 ≈ Δi/Δv（Δv → 0 就是微分）＝ IDQ/VT　　rd = VT/IDQ（跟 Q 點變）　　rf：片段線性的固定斜率（題目給）

不用背微分公式也推得出來

  1. 想知道：在 Q 點，電壓多 Δv，電流多 Δi 是多少？
    這就是「斜率」。直線哪裡量都一樣；曲線每一點都不同，所以要指定在 Q 點量。
  2. iD(VDQ + Δv) = ISe(VDQ + Δv)/VT = IDQ · eΔv/VT
    指數的加法變乘法：多推 Δv，電流變成原本的 eΔv/VT 倍。
  3. Δv 很小：eΔv/VT ≈ 1 + Δv/VT ⟹ Δi ≈ IDQ · Δv/VT
    每多 1 mV，電流多「現在電流的 1/26」（約 3.8%）。像存款利息：存款越多，利息越多。
  4. 斜率 = Δi/Δv = IDQ/VT（2 mA → 76.9 mA/V）
    實際試：多推 10 mV → 93.8、1 mV → 78.4、0.1 mV → 77.1 mA/V，一步越小越接近 76.9。微分 = 這一步取到無限小（講義 1-11 就是在做這件事）。
  5. rd = 1/斜率 = VT/IDQ；rf 是另一回事

    rf（PART 5）：片段線性用一條斜線描整段導通曲線，斜率固定，用來找 Q 點（直流，搭配 Vγ 電池）。rd：Q 點那一點的切線，只管 Q 點旁邊的小交流，而且 Q 點一換就變（0.5 mA → 52 Ω、5 mA → 5.2 Ω）。交流裡沒有 Vγ 電池，因為交流只看變化，固定的 0.6 V 不會變。

原講義 PART 503 · 投影片 1-6～1-8、1-10 · DC Analysis + AC Analysis · Example 1.11

DC 分析＋AC 分析SPLIT THE CIRCUIT IN TWO

兩個電源一起作用很難算。做法：拆成兩張電路。DC 電路只留直流、二極體換 Vγ 電池；AC 電路只留交流、二極體換 rd。各算各的，最後加起來。

DC：交流源歸零（電壓源短路、電流源開路）→ IDQ　　AC：直流電壓源短路（）、二極體 → rd → id、vo　　總量 = 直流 + 交流

拆電路的規則，用 Example 1.11 走一遍

  1. DC 分析：獨立交流源設為零
    交流電壓源 = 0 V → 短路；交流電流源 = 0 A → 開路；直流源保留（投影片 1-7）。目的：找 Q 點。
  2. IDQ = (VPS − Vγ)/R = (5 − 0.6)/5k = 0.88 mA，VO = 4.4 V
    二極體換成 0.6 V 電池，一條 KVL（投影片 1-10，Example 1.11）。
  3. AC 分析：直流電源的交流增量設為零
    直流電壓源「變化量」是 0 → 短路（AC ground）；直流電流源 → 開路；交流源保留。目的：求增益、阻抗。
  4. rd = 0.026/0.88 mA = 29.5 Ω；vi = id(rd + R)
    二極體換成 rd，跟 R 串聯。交流阻抗跟直流工作點有關，所以一定先做 DC。
  5. id = 0.1 sin ωt / 5.0295k = 19.9 sin ωt μA，vo = idR ≈ 0.0995 sin ωt V
    rd ≪ R，交流幾乎全部落在 R 上，輸出幾乎等於輸入。
  6. 為什麼可以加起來？因為在 Q 點線性化之後，AC 模型是線性電路

    投影片 1-8：片段線性模型每一段是線性的，但要先判斷哪一段，所以整體仍非線性；一旦 Q 點確定、做了小訊號線性化，二極體對交流就是一顆固定電阻 —— 線性電路才能用重疊原理把 DC 和 AC 加起來。

DC＋AC 分析的標準流程（講義 1-10）

  1. DC：交流源歸零，二極體換 Vγ（或片段線性）模型，KVL 求 IDQ、VO。
  2. rd = VT/IDQ。
  3. AC：直流電壓源短路，二極體換 rd，KVL 求 id、vo。

拆電路的陷阱

  • ✗ AC 電路裡直流電壓源拿掉變開路。電壓源歸零是短路；電流源歸零才是開路。

  • ✗ 先做 AC。rd 要用 IDQ 算，一定先 DC。

原講義 PART 504 · 投影片 1-9 · Q-point Design & Distortion

Q 點設計與Q-POINT DESIGN & DISTORTION

Q 點太低、交流太大，會出兩種事：二極體在負半週被推到 OFF，輸出被削平（截止失真）；或交流大到曲線不再像直線，上下半週不對稱（非線性失真）。

不截止：VPS − Vm > Vγ　　小訊號：vd = Vm · rd/(rd + R) ≪ VT

交流可以多大？

  1. 總輸入 = VPS + vi，最低點 = VPS − Vm
    負半週的谷底，二極體拿到的「推力」最小。
  2. VPS − Vm < Vγ ⟹ 二極體 OFF ⟹ 輸出 = 0（被削掉）
    這叫截止失真（cutoff clipping，投影片 1-9）。Q 點太低就容易發生。
  3. 沒 OFF，但 vd 不夠小 ⟹ 非線性失真
    指數曲線往上越來越陡：上半週電流被放大、下半週被壓扁。
  4. 設計：Q 點要夠高（VPS 夠大），交流要夠小

    這就是 DC operating point design（bias point design）：先把直流工作點擺在讓交流有空間晃的地方，交流才能乾淨地通過。
