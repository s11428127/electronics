📝 HW1 第 7 題原講義 PART 301 · 投影片 1-20～1-24 · 1.2.1 The Equilibrium pn Junction

pn 接面怎麼形成FORMING THE JUNCTION

P 型那邊電洞很多、N 型那邊電子很多。一接起來，濃度差就會讓它們往對面擴散 —— 但每跑過去一個，就在原地留下一個不會動的離子。離子越積越多，電場越來越強，最後剛好擋住擴散。

熱平衡：|Jdiffusion| = |Jdrift|　⟹　總電流 = 0

從接上到熱平衡，一步一步

  1. P 區：pp0 ≈ Na、np0 = nᵢ²/Na　　N 區：nn0 ≈ Nd、pn0 = nᵢ²/Nd
    先把兩邊各自的多數、少數載子算出來（PART 2 的質量作用定律）。兩邊的電洞濃度差了 NaNd/nᵢ² 倍 —— 通常是十幾個數量級。
  2. 濃度差 ⟹ 電洞 P → N 擴散、電子 N → P 擴散
    跟墨水擴散一樣，只是現在兩種載子同時往對面跑。注意兩者造成的擴散電流方向相同（都是 P → N）。
  3. 電洞離開 P 區 ⟹ 露出 B⁻；電子離開 N 區 ⟹ 露出 P⁺
    離子固定在晶格上不會走。接面兩側就出現一條只有離子、沒有載子的帶子：空乏區（又叫空間電荷區）。
  4. 正離子（N 側）→ 負離子（P 側）⟹ 電場 E 由 n 指向 p
    電場從正電荷指向負電荷。這個電場的方向剛好擋住多數載子繼續擴散（電洞想往 N 走、電場把它往 P 推）。
  5. 同一個電場把少數載子往反方向推 ⟹ 漂移電流（N → P）
    N 區少數的電洞、P 區少數的電子，一碰到空乏區就被電場掃過去。這股漂移電流方向跟擴散電流相反。
  6. 擴散越來越弱、漂移越來越強 ⟹ 兩者相等時停下：|Jdiff| = |Jdrift|

    這叫動態熱平衡：接面上其實一直有載子在擴散、一直有載子在漂移，只是大小相等、方向相反，宏觀上總電流 = 0。

形成過程最常搞混的地方

  • ✗ 空乏區裡的離子會導電。離子固定在晶格上，只負責建立電場，不會移動、不導電。
  • ✗ 熱平衡 = 載子都不動。是動態平衡：擴散和漂移都還在，只是剛好抵消。
  • ✗ 電場方向記反。由 n（正離子）指向 p（負離子）；在圖上就是「從右指向左」。
  • ✗ 擴散電流主要來自少數載子。擴散靠多數載子、漂移靠少數載子（講義 1-22 的紅字）。
📝 HW1 第 8 題原講義 PART 302 · 投影片 1-25～1-27 · Built-in Potential Barrier

VbiBUILT-IN POTENTIAL BARRIER

空乏區的離子在接面兩側造成一個電位差，叫內建電壓（built-in，不是 build-in）。它就是多數載子要擴散過去必須翻過的那道「坡」。坡多高？只看兩邊摻多少、溫度多少。

Vbi = (kT/e) · ln( NaNd / nᵢ² ) = VT · ln( NaNd / nᵢ² )　　VT = kT/e ≈ 26 mV（300 K）

Vbi 公式從哪來（講義只給結論，這裡用 PART 2 學過的東西推）

  1. 熱平衡：電洞電流 = 0　⟹　e·p·μp·E − e·Dp·(dp/dx) = 0
    漂移項 + 擴散項 = 0（電洞的擴散項是負號）。電子也一樣，用電洞推比較直接。
  2. 移項：(1/p)·(dp/dx) = (μp/Dp)·E = E / VT
    用 D/μ = kT/e = VT。這就是 PART 2 學它的用處。
  3. E = −dV/dx　⟹　d(ln p) = −dV / VT
    電場是電位的負梯度；(1/p)dp 就是 d(ln p)。
  4. 從 P 側積分到 N 側：ln(pn0/pp0) = −(Vn − Vp)/VT　⟹　Vbi = Vn − Vp = VT·ln(pp0/pn0)
    兩邊電洞濃度的比值，直接決定了電位差。N 側電位比較高（圖 1.12(b) 那條往右上升的曲線）。
  5. pp0 = Na、pn0 = nᵢ²/Nd　⟹　Vbi = VT·ln(NaNd/nᵢ²)

    代入就是講義的公式。為什麼 Vbi 對摻雜不敏感？因為取了 ln：Na 乘 10 倍，Vbi 只多 VT·ln10 ≈ 60 mV。

算 Vbi 的標準流程

  1. 確認 Na（P 側）、Nd（N 側）、nᵢ（室溫矽用 1.5×10¹⁰）。
  2. 算比值 NaNd/nᵢ²：指數相加再減 2×log nᵢ，例如 10¹⁶·10¹⁷/(1.5×10¹⁰)² = 4.44×10¹²。
  3. 取自然對數 ln（不是 log₁₀）。
  4. 乘上 VT（300 K 用 0.026 V）。結果應該落在 0.6～0.9 V，跑出這個範圍先檢查單位與 ln。

Vbi 的陷阱

  • ✗ ln 按成 log。是自然對數 ln；用 log₁₀ 會小 2.3 倍。
  • ✗ 把 Vbi 當成二極體導通電壓 0.7 V。兩個不是同一件事：Vbi 依摻雜在 0.6～0.8 V 之間變（Example 1.5 是 0.757、Example 1.6 是 0.637），0.7 V 是二極體順向導通時的慣用壓降（PART 4）。
  • ✗ 以為 Vbi 可以用電錶量到。量不到：電錶探針跟半導體的接觸面也有接觸電位，整圈加起來剛好抵消。Vbi 只負責維持熱平衡，不會產生淨電流。
📝 HW1 第 9 題原講義 PART 303 · 投影片 1-28～1-31 · 1.2.2 Reverse-Biased pn Junction

偏壓接法與FORWARD / REVERSE BIAS · REVERSE-BIASED JUNCTION

外加電壓有兩種接法：P 接正是（PART 4），P 接負是逆向偏壓。逆偏時外加電場跟內建電場同方向，坡被墊得更高 —— 多數載子完全過不去，只剩少數載子流過的一點點 IS。

Etotal = Ē + EA　⟹　位障 Vbi + VR，空乏區 W ↑　　iD ≈ −IS（矽 10⁻¹⁴ A 等級）

逆偏時發生什麼事

  1. 順偏：P 接 +、N 接 −（iD 從 P 流向 N）　　逆偏：P 接 −、N 接 +
    投影片 1-28。記法：P 接 Positive 就是順向。二極體符號的三角形指向的就是順向電流方向。
  2. 逆偏外加的 EA 跟內建 Ē 都由 n 指向 p　⟹　Etotal = Ē + EA 變大
    N 接正、P 接負，外加電場從正指向負 —— 剛好跟內建電場同方向。
  3. 更強的電場把空乏區邊緣的多數載子再往外推 ⟹ 露出更多離子 ⟹ W ↑
    N 側邊緣的電子被拉走、只剩 P⁺；P 側邊緣的電洞被拉走、只剩 B⁻（投影片 1-30 的圖）。離子多了，空乏區就寬了。
  4. 位障升高到 Vbi + VR ⟹ 多數載子的擴散電流 ≈ 0
    坡太高了，多數載子翻不過去，所以沒有順向電流。
  5. 少數載子先擴散到空乏區邊緣，再被電場掃過去 ⟹ IS = IS,n + IS,p

    對少數載子來說，這個電場是「順風」。但少數載子本來就少得可憐，所以 IS 極小；而且它受限於「有多少少數載子跑到邊緣」，不受逆偏電壓大小影響 —— 加 1 V 和 10 V 都一樣，所以叫「飽和」。

逆偏的陷阱

  • ✗ 逆偏電流 = 0。不是 0，是 −IS（極小但存在）；負號代表方向跟順向定義的 iD 相反。
  • ✗ 逆偏加越大電流越大。在崩潰之前幾乎不變，因為它受限於少數載子的數量。
  • ✗ IS 是多數載子造成的。是少數載子：N 區的電洞、P 區的電子。
  • ✗ 逆偏可以無限加。加到某個電壓會，逆向電流突然暴增（之後章節）。
原講義 PART 304 · 投影片 1-32～1-37 · Junction Capacitance

與JUNCTION CAPACITANCE · VARACTOR

空乏區沒有載子，像一層絕緣體；兩側的 P 區、N 區像電容的兩塊極板。逆偏一變，空乏區寬度 W 跟著變，等於極板距離在變 —— 所以這是一顆可以用電壓調整的電容。

Cj = Cj0 · ( 1 + VR / Vbi )−1/2　　（Cj0：VR = 0 時的接面電容）

Cj 公式的直覺推導

  1. 平行板電容：C = Q/V = εA/d
    投影片 1-36。A 是極板面積、ε 是中間絕緣層的介電係數、d 是極板距離。
  2. pn 接面：極板距離 d ↔ 空乏區寬度 W　⟹　Cj = εA / W
    空乏區就是那層「絕緣層」。VR 從 VR 變到 VR + ΔVR 時，兩側各多出 ±ΔQ 的離子電荷（投影片 1-32 圖 1.14）—— 這就是電容的定義 ΔQ/ΔV。
  3. W ∝ √(Vbi + VR)　（課本 1.2.2 的空乏區寬度公式）
    要露出更多離子才能撐起更高的位障；用高斯定律解出來，寬度跟總位障的平方根成正比（上一節實驗室的那條關係）。
  4. Cj ∝ 1/W ∝ (Vbi + VR)−1/2
    W 在分母，所以平方根變成 −1/2 次方。
  5. 用 VR = 0 時的 Cj0 當基準：Cj = Cj0·[(Vbi + VR)/Vbi]−1/2 = Cj0(1 + VR/Vbi)−1/2

    這就是講義的公式。VR ↑ → W ↑ → Cj ↓。拿來調頻率就是變容二極體：LC 電路的 f = 1/(2π√LC)，C 變小 → f 變高。

Cj 題目怎麼算（照 Example 1.6）

  1. 先用 Na、Nd 算 Vbi（上一節的流程）。
  2. VR 代正值（逆偏的大小），算 1 + VR/Vbi。
  3. 開根號再取倒數（−1/2 次方），乘上 Cj0。
  4. 檢查：VR 越大 Cj 應該越小，數量級通常是 pF 或更小。

接面電容的陷阱

  • ✗ VR 越大電容越大。相反：空乏區越寬 = 極板越遠 = 電容越小。
  • ✗ 公式裡 VR 代負數。VR 是逆偏電壓的大小，代正數。
  • ✗ 變容二極體順偏使用。一定要逆偏：順偏會有大電流流過，就不是電容了。
  • ✗ 接面電容只有好處。它也會拖慢切換速度：二極體要從導通切到截止，得先把空乏區的電荷重新分布（投影片 1-33 NOTE 3）。

投影片 1-35 的 Hartley 振盪器、調諧放大器是應用，細節在之後的章節。這裡只要抓住一句話：電壓改 Cj → C 改 f → 用電壓選頻率。Q = fr/BW：頻寬越窄，選台越準。

講義勘誤ERRATA

PART 3 的 1-19～1-37 我逐頁驗算過。Example 1.5、1.6 的數字全部正確，下面是要修正或要注意的地方。

① 投影片 1-21：N 區剩下的離子符號寫反

  • 講義紅字寫：在 N 區便沒有傳導載子，只剩下 P⊖
  • 應該是：只剩下 P⊕。磷（施體）給出電子之後變成正離子；同一頁下方的晶格圖畫的就是 P⊕。

② 投影片 1-25：build-in → built-in（考英文要注意）

  • 講義寫：build-in potential barrier、build-in voltage
  • 應該是：built-in potential barrier、built-in voltage（過去分詞「內建的」）。課本圖 1.12 的說明寫的就是 built-in。

③ 投影片 1-27 NOTE (3)：靜電流 → 淨電流

  • 講義寫：vbi 乃用以維持熱平衡，並不會產生靜電流
  • 應該是：淨電流（net current）。應該是同音筆誤。

④ 投影片 1-27 NOTE (2)：「室溫下約定俗成取 vbi ≃ 0.7 V」—— 請跟老師確認

  • 0.7 V 通常是矽二極體導通電壓（順向壓降）的慣用值；Vbi 是另一個量，會隨摻雜在約 0.6～0.8 V 之間變。
  • 同一份講義的兩個例題就不是 0.7：Example 1.5 = 0.757 V、Example 1.6 = 0.637 V。
  • 如果老師是指「沒給摻雜時，Vbi 可以粗估成 0.7 V」那沒問題；但不要把它跟導通電壓當成同一件事。

小筆誤：1-29 第 (2) 點「正負離子數↑」重複寫了兩次；1-30 「被掃移只剩 B」應該是 B⊖。
