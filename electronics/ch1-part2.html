Chapter 1 · Part 2 · 投影片 p.31–55

P 型半導體與載子輸運

PART 1 停在 N 型。這一段先把 P 型補完，然後進入整章真正的重頭戲：載子到底怎麼動、怎麼形成電流。答案只有兩個機制 —— 被電場推的漂移，和被濃度差推的擴散。

電子 electron ⊖ 電洞 hole ⊕ 7 個互動模組 12 題中英對照測驗
Big picture

這一段在講什麼

用一句話串起來：決定有多少載子（濃度），電場和決定這些載子怎麼動（電流）。

四步驟骨架

  1. 摻 5 價（P）→ 多電子 → n 型　｜　摻 3 價（B）→ 多電洞 → p 型
    1.1.2 PART 1 講完 n 型，這段補 p 型。兩者對稱。
  2. n₀ · p₀ = nᵢ²　⟹　 ≈ 摻雜濃度， = nᵢ²/摻雜濃度
    1.1.2 定量 知道摻多少，就能算出兩種載子各有多少。
  3. Jdrift = e(n·μn + p·μp)E = σE
    1.1.3 加了電場，載子被推著跑 → 。整理出來就是歐姆定律的微觀版。
  4. Jdiff = e·Dn·(dn/dx) − e·Dp·(dp/dx)
    1.1.3 就算沒有電場，只要濃度不均勻，載子也會自己跑 → 。這是下一章 pn 接面的關鍵。

為什麼要學這些？因為 pn 接面（下一段）就是「n 型碰上 p 型」，接面附近的濃度差會造成擴散、擴散又造成內建電場、電場又造成反向的漂移 —— 兩個機制打平就形成平衡。這段的每一條公式，下一段都會用到。

01 · 投影片 p.31–32 · Extrinsic (P-Type)

P 型半導體：摻雜

在矽裡摻入 3 價的硼（B）。硼只有 3 個價電子，要跟 4 個鄰居形成共價鍵就是少一個。鄰近矽的價電子跑來填補，原本那個位置就變成電洞hole —— 硼因此被稱為acceptor：它「接受」電子。

為什麼硼會「製造」電洞

  1. 矽需要 4 個價電子跟 4 個鄰居配對　但硼只有 3 個
    硼取代了晶格中一個矽的位置。它盡力跟 3 個鄰居形成共價鍵，第 4 個鍵缺一個電子。
  2. 鄰近矽的價電子跳過來填補這個空位

    只要一點點熱能就夠了（比打斷一整條共價鍵容易得多）。填補之後硼滿足了八隅體，但是 ——

  3. 那個電子「原本的位置」變成了電洞　⟹　電洞被製造出來

    電洞可以繼續被其他價電子遞補（就是 PART 1 講的電洞移動），所以它可以導電。

  4. 硼多接了一個電子　⟹　變成帶負電的 B⁻ 離子
    B⁻ 被固定在晶格上不能動，所以不導電。這跟 n 型的 P⁺ 完全對稱： 導電的永遠是被製造出來的那個載子，不是留下的離子。

名稱由來：p 型的 p 是 positive，因為多數載子電洞帶正電；n 型的 n 是 negative，多數載子電子帶負電。不是指材料整體帶電 —— 兩者都是的。

最常被搞混的三件事

  • ✗ 「p 型半導體帶正電」。✓ p 型是的。4 價的矽加 3 價的硼，兩個電中性物質加起來還是電中性。每個電洞（正）都有一個 B⁻ 離子（負）平衡。
  • ✗ 「B⁻ 離子帶負電，所以它會導負電流」。✓ 離子不能動，不導電。導電的是電洞。PART 1 講離子鍵時就強調過這點。
  • ✗ 「p 型裡沒有電子」。✓ 常溫下熱擾動仍會產生電子－電洞對，所以 p 型裡還是有電子，只是數量極少，稱為少數載子。

觀念釐清： vs （跟摻雜無關）

  1. elemental：由單一元素組成，例如 Si、Ge
    4 價元素，週期表第 IV 族。
  2. compound：由兩種以上元素化合而成，例如 GaAs、InP
    通常是 III 族 + V 族。它本身就是那個材料，不是摻出來的。
  3. Si + B → p 型　／　Si + P → n 型　⟹　仍然是元素半導體

    摻雜的比例只有約 1:10⁸，基礎材料還是單一元素的矽，只是導電性被改變了。「元素 vs 化合物」講的是材料本身，「本質 vs 非本質」講的是有沒有摻雜 —— 這是兩個獨立的分類軸，可以自由組合。

有趣的是：即使只摻了「一億分之一」，載子濃度還是暴增了三萬倍。這就是為什麼半導體製程對純度要求那麼變態 —— 一點點雜質就足以改變整塊材料的電性。

03 · 投影片 p.40–41 · 定量分析

：算出兩種載子各有多少

摻雜之後，電子和電洞各是多少？答案出奇地簡單，而且兩者是蹺蹺板關係：一個上去，另一個一定下來。

no · po = ni²　（下恆成立，與摻雜量無關）

從推出兩條實用公式

  1. 前提：「」。意思是溫度穩定、沒有外加能量（沒有光照、沒有外加電場）， 載子的產生率 = 復合率。這個條件下乘積才是定值。

  2. 電中性條件：n₀ + Na⁻ = p₀ + Nd⁺
    整塊材料不帶電：負電荷（自由電子 + 受體負離子）＝ 正電荷（電洞 + 施體正離子）。
  3. n 型（只摻施體，Na = 0）：n₀ = p₀ + Nd，且 n₀p₀ = nᵢ²

    兩式聯立，消去 p₀ 得一個二次式，解出：

    n₀ = Nd/2 + √( (Nd/2)² + nᵢ² )
  4. 當 Nd ≫ nᵢ：　n₀ ≅ Nd　，　p₀ = nᵢ²/Nd

    這就是課本用的近似。因為 Nd 通常是 10¹⁵～10¹⁸，而 nᵢ 只有 10¹⁰， 根號裡的 nᵢ² 完全可以忽略，整個式子就塌縮成 n₀ ≈ Nd。

  5. p 型同理：　p₀ ≅ Na　，　n₀ = nᵢ²/Na

    把角色對調即可。口訣：多數載子 ≈ 摻雜濃度；少數載子 = nᵢ² ÷ 多數載子。

看到載子濃度題目

04 · 投影片 p.42–45 · Drift Current

：電場推著載子跑

載子會動，只有兩個原因：電場推（漂移drift）或濃度差擠（擴散diffusion）。這一節先講漂移 —— 而且有一個超容易搞混的點：電子和電洞跑的方向相反，電流方向卻相同。

vdn = −μnE　⟹　Jn = e·n·μn·E　　　vdp = +μpE　⟹　Jp = e·p·μp·E

為什麼 Jn 前面的負號會消失

  1. vdn = −μnE
    電子帶負電，受力 F = −qE 與電場反向，所以前面有負號。 μn 叫電子移動率（mobility），意思是「單位電場下能達到的」，矽的 μn ≈ 1350 cm²/(V·s)。
  2. Jn = (電荷) × (濃度) × (速度) = (−e) · n · vdn

    = 電荷密度 × 速度。電子的電荷是 −e，這是第二個負號。

  3. Jn = −e·n·(−μnE)
    把 vdn 代進去。現在有兩個負號。
  4. Jn = +e·n·μn·E　（與 E 同向）

    負負得正。所以電子雖然往左跑，電流卻是往右的。

  5. 電洞：Jp = (+e)·p·(+μpE) = +e·p·μp·E　（也與 E 同向）

    電洞帶正電、順著 E 跑，兩個正號 → 還是正的。兩種載子殊途同歸，電流都與 E 同向，所以可以直接相加。

05 · 投影片 p.49–51 · Conductivity

總漂移電流、與

兩種載子的電流都與 E 同向，所以直接相加。整理之後會跑出一個只跟材料有關的係數 —— 那就是conductivity σ。

J = Jn + Jp = e(n·μn + p·μp)E ≡ σE = (1/ρ)E

歐姆定律其實就藏在這裡

  1. J = e·n·μn·E + e·p·μp·E
    把上一節兩條加起來。注意是「加」不是「減」 —— 因為兩者同向。
  2. = [ e·n·μn + e·p·μp ] · E

    把共同的 E 提出來。中括號裡的東西完全不含 E，只跟材料的載子濃度與移動率有關。

  3. σ ≡ e(n·μn + p·μp)　單位 (Ω·cm)⁻¹　⟹　J = σE
    給它一個名字叫導電度。倒數 ρ = 1/σ 叫（resistivity），單位 Ω·cm。
  4. J = (1/ρ)E　⟹　I/A = (1/ρ)(V/L)　⟹　V = I·(ρL/A) = I·R

    這就是歐姆定律。J = σE 是它的「微觀版本」，R = ρL/A 是「巨觀版本」。同一件事的兩種寫法。

  5. 藉由摻雜改變 n、p　⟹　改變 σ　⟹　改變導電度

    這句話就是整個半導體工業的基礎：我們可以用摻雜「訂製」材料的導電度。

06 · 投影片 p.52–54 · Diffusion Current

：濃度不均也會產生電流

就算完全沒有電場，只要載子分布不均勻，它們也會自己從濃的地方往稀的地方跑 —— 就像一滴墨水在水裡會自己散開。這種流動一樣構成電流。

Jn = +e·Dn·(dn/dx)　　　Jp = −e·Dp·(dp/dx)

為什麼一個是正號、一個是負號

  1. 先講共同點：兩種載子都是從濃度高的地方往低的地方跑。這是擴散的本質，跟電荷正負無關。

  2. 若濃度往 +x 遞增（dn/dx > 0）　⟹　載子往 −x 方向跑
    高濃度在右邊，所以往左流。粒子流方向與梯度方向相反。
  3. 電洞（帶正電）：電流方向 = 粒子流方向 = −x

    所以當 dp/dx > 0 時，Jp 是負的 → 公式要寫成 Jp = −e·Dp·(dp/dx)。

  4. 電子（帶負電）：電流方向 = 粒子流的反方向 = +x

    所以當 dn/dx > 0 時，Jn 是正的 → 公式是 Jn = +e·Dn·(dn/dx)。那個正號就是電子帶負電「再變號一次」的結果。

  5. Dn、Dp 叫（diffusion coefficient），矽：Dn = 35、Dp = 12 cm²/s
    跟移動率一樣，電子的值比電洞大 —— 電子就是比較「靈活」。

07 · 投影片 p.55 · Brief Summary

總電流密度：四項全家福

兩種機制 × 兩種載子 = 四項。把它們全部加起來，就是半導體裡電流的完整描述。

J = e(n·μn + p·μp)E　+　e·Dn·(dn/dx)　−　e·Dp·(dp/dx)

四項組合器（點按鈕開關）

4 / 4 項

拿到電流密度題目怎麼判斷要用哪幾項

  1. 題目有給「電場 E」或「外加電壓」嗎？有 → 要算漂移項。
  2. 題目有給「濃度隨位置變化」或「濃度梯度 dn/dx」嗎？有 → 要算擴散項。
  3. 是 n 型還是 p 型？多數載子那一項通常大好幾個，少數載子那項多半可以直接忽略（像 Example 1.3 那樣）。
  4. 課本原話：實務上通常只有其中一種機制在某個區域佔主導，所以不必四項都算。

這一節的計算陷阱

  • ✗ 單位沒統一。濃度 cm⁻³、長度 cm、電場 V/cm、μ 的 cm²/(V·s)、D 的 cm²/s —— 全部用 cm 系統。題目給 μm 一定要先換成 cm（1 μm = 10⁻⁴ cm）。
  • ✗ σ 的兩項寫成相減。是 σ = e(nμn + pμp)，相加。兩種載子的漂移電流同向。
  • ✗ 擴散公式的正負號記反。記法：電子 +、電洞 −（Jn = +eDn·dn/dx，Jp = −eDp·dp/dx）。因為電子多帶一次負電，多變號一次。
  • ✗ 把少數載子濃度也拿去算漂移電流的主項。先比較數量級，差太多就直接忽略，省時間也不會錯。

講義勘誤

① 的單位寫成立方（出現兩次）

  • 位置：投影片 p.44（電子）與 p.45（電洞）。

  • 佐證：同一份講義 p.50 貼的課本 Example 1.3 原文寫的就是 cm²/V–s，所以是投影片上手打的註解打錯，數值 1350 / 480 本身是對的。
