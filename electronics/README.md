# 電子學互動講義

把電機系電子學（Neamen, *Microelectronics: Circuit Analysis and Design*, 4e）的課堂投影片，
改寫成可以動手操作的網頁：每個觀念都配一個可拉、可點、可玩的互動模組，而不是一張靜態圖。

線上瀏覽：開啟 `index.html` 即可，**不需要任何建置流程**（純 HTML + CSS + Canvas，零相依套件）。

```
electronics/
  index.html            科目首頁：**章節選單**
  ch1-part1.html        CH1 PART 1：半導體材料與性質（投影片 p.1–30）
  ch1-part2.html        CH1 PART 2：P 型半導體與載子輸運（投影片 p.31–55）
  assets/ch1-part1.js   PART 1 的 8 個互動模組 + 10 題測驗
  assets/ch1-part2.js   PART 2 的 7 個互動模組 + 12 題中英對照測驗
  docs/CONTENT_MAP.md   章節分類、核心公式與講義勘誤紀錄
shared/
  app.css               設計語彙（色票、字體、版面）——跨科目共用
  app.js                互動引擎（Canvas 舞台、主題色、繪圖原語）——跨科目共用
```

導覽是三層：**主頁（選科目）→ 電子學首頁（選章節）→ 章節頁**。一章一頁，不會全部塞在一起。

## 設計原則

- **定量數值一律即時計算**，用課本表 1.3 的 B 與 Eg 代入 `ni = B·T^(3/2)·exp(−Eg/2kT)`，
  不寫死答案。
- **示意與真實分開講**：晶格上畫得出來的斷鍵數量是壓縮過的（真實比例下 300 K 每 10¹² 個矽原子
  才有一個載子），畫面會標明，旁邊的數字才是真實量級。
- 明暗主題自動跟隨系統，也可手動切換；手機寬度（~390px）下版面會收成單欄。
