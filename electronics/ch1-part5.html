複習：實際曲線與簡化模型RECAP · PRACTICAL CURVE & MODELS

V3 講義在進新內容前，先把實際二極體的曲線（這次多畫了崩潰那一段）和兩種簡化模型再講一次。先把這張圖記熟：左邊崩潰、中間 OFF、右邊導通。

理想：vD < 0 斷路、導通時 vD = 0　　定電壓降：vD < Vγ 斷路、導通時 vD = Vγ ≈ 0.7 V，iD 由外部電路決定

從實際曲線到兩種模型

  1. 實際二極體（1-89）：逆偏 −IS 貼地；超過 VZK（崩潰）往下衝；順偏過 Vγ 往上衝
    V3 的 Fig 1.20 多了左邊那一段：逆偏到「崩潰起始電壓」VZK 就崩潰（下一節）。講義寫的「Practice diode」應為 practical diode（勘誤 ①）。
  2. mA 尺度看，導通那段幾乎垂直 ⟹ 把它換成一面「牆」
    PART 4：每 60 mV 電流 × 10。從 1 mA 到 10 mA 電壓才多 0.06 V，所以電壓幾乎固定。
  3. 牆放在 0 V ⟹ 理想二極體（1-94）；牆放在 Vγ ⟹ 定電壓降模型（1-95）
    電源比 0.7 V 大很多時兩者差不多；電源小的時候一定要扣 0.7 V。
  4. 數學寫法（1-96、1-97）：vD < Vγ ⟹ iD = 0（OFF）；iD > 0 ⟹ vD = Vγ（ON）

    注意 OFF 那段是「不導通、等效電阻 ∞」—— 講義 1-93、1-95、1-97 圖上把它寫成「導通」，是筆誤（勘誤 ②）。1-97 的「iD ≥ 0 V」也多了一個 V（勘誤 ③）。

用簡化模型的標準流程

  1. 先假設二極體 ON：換成短路（理想）或 Vγ 電池（定電壓降）。
  2. 算出 iD。iD > 0 → 假設成立。

複習段的陷阱

  • ✗ 模型會畫出崩潰。理想、定電壓降、片段線性都只有 OFF 和 ON 兩段，崩潰要另外考慮。
  • ✗ 定電壓降模型導通時電流無限大。電流由外部電路決定：(VPS − Vγ)/R。
  • ✗ 水平那段是「導通、電阻 ∞」。是不導通（截止），電阻 ∞ 才對得上。
原講義 PART 4（V3）01 · 投影片 1-106、1-111 · 1.2.5 Breakdown Voltage

與 PIVBREAKDOWN VOLTAGE & PIV

逆偏越加越大，空乏區的電場越來越強。強到某個程度，共價鍵被扯斷，一下子冒出一大堆電子電洞對，逆向電流突然暴衝 —— 這就是。一般二極體要避開它，所以規格會寫。

|vR| < BV：iD ≈ −IS　　|vR| ≥ BV：逆向電流大幅增加（由外部電路限流）　　設計：最大逆壓 < PIV < BV

崩潰怎麼發生、為什麼要 PIV

  1. 逆偏 VR ↑ ⟹ 空乏區的電場 E ↑
    PART 3：逆偏把坡墊高、空乏區變寬，空乏區裡的電場跟著變強（E ≈ (Vbi + VR)/W 的等級）。
  2. E 大到某值 ⟹ 破壞共價鍵 ⟹ 產生電子電洞對
    投影片 1-106：電子被電場掃到 N 區、電洞被掃到 P 區 —— 方向跟逆向電流一樣，所以逆向電流突然變大。
  3. 開始崩潰的電壓 = 崩潰電壓 BV（曲線上叫 VZK）
    BV 的大小由摻雜決定（下一節）：同一張圖上的 BV1（小）、BV2（大）。
  4. 崩潰 ≠ 損壞；但 P = V·I 太大 ⟹ 過熱燒毀
    1-106 NOTE (2)：有些應用故意用崩潰（例如穩在 BV1 或 BV2 當穩壓），但無限制地加大逆偏，電流巨大、功率過大就會壞。
  5. 一般二極體：BV 約 50～200 V，用 PIV 額定 ⟹ 實際最大逆壓不可超過 PIV

    投影片 1-111。＝設計上保證可以安全工作的值。整流電路裡，二極體每個負半周都被反著加一次電壓，最大值就是輸入峰值；選零件時 PIV 要比它大，還要留餘裕。則相反，故意操作在崩潰區穩壓。

檢查二極體會不會崩潰

  1. 找出二極體 OFF 時兩端的最大逆壓（電阻負載的半波整流 = 輸入峰值 Vm；rms 要乘 √2）。

  3. 留餘裕（實務 1.5～2 倍），電源會浮動、會有突波。

崩潰的陷阱

  • ✗ 崩潰 = 二極體燒壞。崩潰是電流暴增的現象，限流得當就不會壞；齊納二極體就靠它工作。
  • ✗ 家用 110 V，二極體 PIV 110 V 就夠。110 V 是 rms，峰值 155.6 V。
  • ✗ 崩潰電流是順向電流。是逆向電流（N → P 方向流過二極體）。
原講義 PART 4（V3）02 · 投影片 1-107～1-110 · Avalanche & Zener Breakdown

vs AVALANCHE VS ZENER

一樣是「共價鍵被打斷」，打斷的方法有兩種：撞斷（累增，像雪崩、像保齡球）和扯斷（齊納，像撕紙）。誰會發生，看摻雜 —— 摻雜決定空乏區多寬，寬度決定同樣電壓下電場多強。

W ∝ √( (Vbi + VR)(1/NA + 1/ND) )　　E ≈ V / W　　摻雜 ↑ ⟹ W ↓ ⟹ |BV| ↓（齊納）；摻雜 ↓ ⟹ |BV| ↑（累增）

兩種機制，一步一步

  1. 累增（低摻雜）：少數載子穿越空乏區時被電場加速，得到大動能
    投影片 1-107 第 1 點。空乏區寬，加速的距離長。
  2. 撞上晶格 ⟹ 打斷共價鍵 ⟹ 多一對電子電洞（）
    第 2 點。講義英文框寫「colliding with the fixed ions」，比較精確的說法是撞上晶格原子、打斷共價鍵（勘誤 ⑤，請確認）。
  3. 新的電子電洞又被加速、再撞 ⟹ 1 → 2 → 4 → 8 … 連鎖反應 ⟹ 大電流
    第 3、4 點。講義 NOTE 的「累積崩潰」應為「累增崩潰」（勘誤 ④）。
  4. 齊納（高摻雜）：W 很窄 ⟹ 小逆偏就有極強電場 ⟹ 直接把束縛電子拉離共價鍵
    投影片 1-108、1-109。不用撞，電場本身就夠強（約 106 V/cm 等級，課本延伸）。
  5. W = √(2εs(Vbi + VR)/e · (NA + ND)/(NAND))，E ≈ V/W
    PART 3 的空乏區公式。(NA + ND)/(NAND) = 1/NA + 1/ND：摻雜越濃，W 越窄。E ≈ V/W 是平均電場，突變接面的最大電場約是它的 2 倍（補充）。
  6. 結論（1-110）：高摻雜 → 小 |BV|（BV1，齊納）；低摻雜 → 大 |BV|（BV2，累增）

    經驗上 BV < 約 5 V 是齊納、> 約 6～7 V 是累增，中間兩種都有（課本延伸）。講義 1-109 的旁註也提醒：外加的逆壓不一定百分之百只落在理想化的空乏區上，所以 E ≈ V/W 只是估計。

判斷崩潰機制的流程

  1. 看摻雜：高（≳ 1018 cm−3）還是低。
  2. 高摻雜 → W 窄 → E ≈ V/W 大 → 小電壓就崩潰 → 齊納。
  3. 低摻雜 → W 寬 → 要大電壓 → 載子加速撞擊 → 累增。
  4. 題目給 BV：< 5 V 多半齊納、> 7 V 多半累增。

兩種崩潰的陷阱

  • ✗ 齊納崩潰需要比較大的逆偏。相反：高摻雜、空乏區窄，小逆偏就崩潰。
  • ✗ 累增崩潰是電場直接把電子扯出來。那是齊納；累增是加速後撞出來、連鎖反應。
  • ✗ 摻雜越高，空乏區越寬。越窄：W ∝ √(1/NA + 1/ND)。
  • ✗ 「齊納二極體」只會發生齊納崩潰。市售齊納二極體 VZ 大於約 6 V 的，主要其實是累增崩潰，只是統稱齊納二極體。
原講義 PART 4（V3）03 · 投影片 1-93、1-112～1-115 · 1.3 Diode as a Switch

理想開關與DIODE AS A SWITCH · HALF-WAVE RECTIFIER

二極體是的二端元件。最粗的看法：它是一個自動開關 —— 順偏 ON、逆偏 OFF。拿交流電來推它，就只剩正半周通過，這就是半波整流。

理想開關：vD < 0 ⟹ OFF（iD = 0）；順偏 ⟹ ON（vD = 0，iD 由外部電路決定）　　半波整流：vO = vI − Vγ（ON）、0（OFF）

從定義到半波整流

  1. iD = IS(evD/VT − 1) ⟹ 非線性二端元件
    投影片 1-112：描述元件 I–V 關係的數學模型，讓我們不用實作就能分析、設計電路。
  2. vD、iD 的參考方向固定：+ 在 P 端、電流 P → N；vD > 0 順偏、vD < 0 逆偏
    投影片 1-113：「定義的 + − 與電流方向是不變的」。外加電壓反過來時，是 vD 變負，不是把定義翻過來 —— 第 07 節逆偏的 Q 點就靠這個。
  3. 理想開關模型（Fig 1.26）：逆偏 OFF、順偏 ON
    投影片 1-114。跟理想二極體同一個東西。
  4. 半波整流（Fig 1.27）：vI > 0 ⟹ ON ⟹ vO = vI；vI < 0 ⟹ OFF ⟹ vO = 0
    投影片 1-115：正半周「通過」、負半周「截止」，輸出方向不變但大小一直變 = 。
  5. 定電壓降模型（1-93）：vO = vI − 0.7（vI > 0.7 V），峰值 5 − 0.7 = 4.3 V

    導通從 sin θ = 0.7/5 → θ = 8.0° 才開始、172° 結束，導通時間約 45.5%（不是 50%）。電源越小，這 0.7 V 越不能忽略。

半波整流題目的標準流程

  1. 判斷每一段時間二極體 ON 還是 OFF（vI 跟 Vγ 比）。
  2. ON：二極體換成 Vγ 電池（或短路），vO = vI − Vγ。
  3. OFF：電流 0，vO = 0；這時二極體承受的逆壓 = vI（檢查 PIV）。
  4. 畫波形：輸出比輸入矮 Vγ、負半周削平。

半波整流的陷阱

  • ✗ 輸出峰值 = 輸入峰值。要扣 Vγ（理想模型才相等）。
  • ✗ 二極體剛好導通半個週期。vI 超過 Vγ 才導通，比半個週期短一點。
  • ✗ 脈動直流就是直流。方向不變但大小一直變，還要濾波才平。
原講義 PART 4（V3）04 · 投影片 1-116～1-119 · 1.3.1 Iteration and Graphical Analysis

：與 Q 點LOAD LINE & Q-POINT

二極體自己有一條規矩（特性曲線），外面的電源和電阻也給了一條規矩（KVL）。KVL 畫出來是一條直線 —— 負載線。兩條都要滿足，答案就是交點，叫。用算的就是。

負載線：ID = −VD/R + VPS/R（斜率 −1/R，截距 VPS 與 VPS/R）　　Q = 負載線 ∩ 特性曲線

負載線怎麼來、Q 點怎麼找

  1. KVL：VPS = IDR + VD　（5 = ID·2k + VD）
    投影片 1-119。電源電壓 = 電阻壓降 + 二極體壓降。這條式子只跟外面電路有關。
  2. 移項：ID = −(1/R)VD + VPS/R = −VD/2k + 5/2k
    寫成 y = mx + b 的形式：在 ID–VD 圖上是一條直線，斜率 −1/R。
  3. 兩個截距：ID = 0 → VD = VPS = 5 V；VD = 0 → ID = VPS/R = 2.5 mA
    「截距求法」（1-118 STEP 2）：兩點連一條線最快。講義寫的 slop 應為 slope（勘誤 ⑥）。
  4. STEP 1 畫特性曲線（實驗或 datasheet）、STEP 3 找交點
    投影片 1-118 的三個步驟。交點同時滿足元件和電路，就是直流工作點。
  5. 疊代法：猜 VD → KVL 算 ID → VD = VTln(ID/IS) → 重複
    不畫圖、用算的逼近同一個交點（Example 1.8，IS = 10−13 A → 0.619 V、2.19 mA）。
  6. Q ≈ (0.62 V, 2.2 mA)；反過來設計：R = (VPS − VD)/ID = (5 − 0.62)/2.2 mA ≈ 2 kΩ

    講義 1-119 的 Problem 就是這個反推。注意 Q 點的 VD 怎麼調都卡在 0.6 V 附近 —— 二極體曲線太陡，電流幾乎只由 VPS 和 R 決定。

圖形法的標準流程

  1. 寫 KVL，整理成 ID = −VD/R + VPS/R。
  2. 算兩個截距：(VPS, 0) 和 (0, VPS/R)，連成負載線。
  3. 跟二極體特性曲線找交點 → Q = (VDQ, IDQ)。
  4. 要精確就疊代：從 0.6～0.7 V 開始猜，兩三輪就收斂。

圖形法的陷阱

  • ✗ 負載線是二極體的特性。負載線只由外面電路（VPS、R）決定，跟二極體無關。
  • ✗ 縱軸截距是 VPS·R。是 VPS/R（5 V/2 kΩ = 2.5 mA）。
  • ✗ R 變大，負載線變陡。變平：斜率 −1/R。
  • ✗ 疊代時用 log。VD = VT ln(ID/IS)，是自然對數。
原講義 PART 4（V3）05 · 投影片 1-120～1-122 · 1.3.2 Piecewise Linear Model

PIECEWISE LINEAR MODEL

畫圖、疊代都麻煩。最常用的做法：用兩段直線去描那條彎線。直線可以直接放進 KVL，一行解完 —— 這叫模型代入法。

VD < Vγ：ID = 0（OFF）　　VD > Vγ：VD = Vγ + IDrf（ON）　　串聯電路：ID = (VPS − Vγ) / (R + rf)

從兩段直線到 Example 1.9

  1. 第一段：VD < Vγ，一條趨近 0、跟 VD 軸平行的直線 ⟹ OFF
    投影片 1-120 ②。Vγ 叫導通電壓（切入電壓），一般 0.6～0.7 V。
  2. 第二段：VD > Vγ，斜率 1/rf 的直線 ⟹ ON
    投影片 1-120 ①。rf 叫，一般數十 Ω。
  3. 直線方程式：ID = (VD − Vγ)/rf ⟺ VD = Vγ + IDrf
    投影片 1-121：從特性曲線（點斜式）或等效電路（電池 + 電阻）推都一樣。
  4. 代入 KVL：VPS = IDR + Vγ + IDrf ⟹ ID = (VPS − Vγ)/(R + rf)
    二極體換成「Vγ 電池 + rf」之後整個電路是線性的。
  5. Example 1.9：(5 − 0.6)/(2000 + 10) = 2.19 mA；VD = 0.622 V；PD = 1.36 mW

    跟 Example 1.8 疊代的 2.19 mA 幾乎一樣，但簡單得多（1-122 (1)）。因為 rf = 10 Ω ≪ R = 2 kΩ，rf 對電流影響很小（1-122 (2)）。Vγ 改 0.7 V：rf = 10 Ω 時 2.14 mA、rf = 0 時 2.15 mA（勘誤 ⑦）。

  1. 假設二極體 ON，換成 Vγ 電池（+ 端在 P 側）串 rf。

片段線性的陷阱

  • ✗ VD = Vγ。片段線性要加 IDrf（0.6 + 0.022 = 0.622 V）；rf = 0 才是 Vγ。
  • ✗ 分母只寫 R。R + rf（雖然 rf 小，但題目給了就要放）。
  • ✗ Vγ 電池方向畫反。+ 在陽極（P）側，跟順向電流同方向會「吃掉」電壓。
  • ✗ 沒檢查假設。VPS < Vγ 時算出負電流，代表二極體其實 OFF。
原講義 PART 4（V3）06 · 投影片 1-123～1-125 · Constant-Voltage-Drop Model & Q-point

＋負載線CONSTANT-VOLTAGE DROP & THE Q-POINT

再簡化一步：rf 跟 kΩ 的電阻比根本可以忽略，乾脆讓它 = 0。斜線立成垂直線，二極體導通就是一顆固定的 Vγ 電池。這時 Q 點只會在 Vγ 那條垂直線上上下滑。

rf = 0（1/rf = ∞）：VDQ = Vγ　　IDQ = (VPS − Vγ) / R

垂直線 × 負載線

  1. rf → 0 ⟹ 斜率 1/rf → ∞ ⟹ ON 那段變成 VD = Vγ 的垂直線
    投影片 1-123：片段線性模型的簡化，又稱定電壓降模型。條件 rf ≪ R。
  2. 只看模型：VD > Vγ 時 ID → ∞？
    投影片 1-124 NOTE (1)：單看那條垂直線，好像電壓再多一點電流就無限大。
  3. 加上外部電路（負載線）⟹ ID = IDQ = (VPS − Vγ)/R，有限值
    NOTE (2)：實際電流由負載線決定，二極體兩端被「釘」在 Vγ。
  4. Fig 1.30：A 5 V/2k → 2.15 mA；B 5 V/4k → 1.075 mA；C 2.5 V/2k → 0.9 mA；D 2.5 V/4k → 0.45 mA
    VPS 變 → 負載線平移；R 變 → 負載線轉動（斜率 −1/R）。交點都在 0.7 V 那條線上。
  5. Q 點由 (1) 電源電壓、(2) 外接電阻、(3) 二極體 I–V 特性 決定

    投影片 1-125：(1)(2) 是外接電路的因素（決定負載線），(3) 是元件本身（決定特性曲線）。三者任一改變，Q 點就跟著動。

  1. 確認 VPS > Vγ（否則 OFF，ID = 0）。

定電壓降的陷阱

  • ✗ R 加倍，Q 點電壓也變。定電壓降模型的 VDQ 永遠是 Vγ，只有電流變。
  • ✗ VPS 減半，電流也剛好減半。(2.5 − 0.7)/(5 − 0.7) = 0.42，比一半還少，因為 0.7 V 不跟著減。

原講義 PART 4（V3）07 · 投影片 1-126 · Reverse-Biased Diode

逆偏的 Q 點REVERSE-BIASED DIODE

同一套方法也能處理二極體反接。重點只有一個：VD、ID 的定義方向不變，所以電源對二極體來說變成負的，負載線跑到左下，交在特性曲線的 OFF 段。

反接：−VPS = IDR + VD　截距 (−VPS, 0)、(0, −VPS/R)　⟹　Q = (−VPS, 0)

照定義寫 KVL

  1. 二極體反接 ⟹ 從二極體的 + − 定義看，電源是 −VPS
    投影片 1-113：定義的極性與電流方向不變，變的是數值的正負。
  2. 令 ID = 0 ⟹ VD = −5 V；令 VD = 0 ⟹ ID = −5/2k = −2.5 mA
    投影片 1-126 右上圖：負載線在第三象限。
  3. 特性曲線（片段線性）在 VD < Vγ 是 ID = 0 的水平線
    逆偏時二極體 OFF。
  4. 交點 Q = (VD, ID) = (−5 V, 0 A)

    電流 0、電阻沒壓降，整個 5 V 都反著落在二極體上。片段線性模型比 Example 1.8 的理想二極體方程式略不準，但分析簡單得多（1-126 下方說明）。逆壓若超過 BV，就要回到 §01 的崩潰。

原講義 PART 4（V3）Errata · 講義檢查結果

講義勘誤ERRATA

V3 講義 1-85～1-126 我逐頁驗算過。Example 1.9、Problem 的 R = 2 kΩ、Fig 1.30 四個 Q 點、逆偏 Q 點的數字都正確，下面是要修正或要注意的地方。

① 投影片 1-89：Practice diode → practical diode

  • 講義寫：Practice diode　應該是：practical diode（PART 4 網頁勘誤 ② 同一個字）。

② 投影片 1-93、1-95、1-97：水平那段標成「導通」

  • 講義在 vD < Vγ 的水平段寫：導通　等效電阻 ∞
  • 應該是：不導通（截止、OFF）　等效電阻 ∞。電阻 ∞ 就是不導通；垂直那段才是導通。

③ 投影片 1-97：「iD ≥ 0 V」

  • 電流的單位不是 V：iD ≥ 0 V　→　iD ≥ 0（A）。

④ 投影片 1-107 NOTE：「累積崩潰」→ 累增崩潰

  • 同一頁標題寫「累增崩潰 (avalanche breakdown)」，NOTE 寫成 累積崩潰，應統一為 累增崩潰（雪崩崩潰）。

⑤ 投影片 1-107 英文框：「colliding with the fixed ions」—— 請確認

  • 撞擊游離的對象是晶格原子（打斷共價鍵），不是空乏區裡的固定離子。講義中文寫的「碰撞時破壞共價鍵」是對的。
  • 若是從課本原文抄來的，請對照課本確認原句；考英文時建議寫 collide with lattice atoms and break covalent bonds。

⑥ 投影片 1-120：slop → slope

  • slop（濺出的水）→ slope（斜率）。

⑦ 投影片 1-122 (3)：Vγ = 0.7 V 求出 ID = 2.15 mA —— 請確認

  • 同一頁是 rf = 10 Ω 的例子：(5 − 0.7)/(2000 + 10) = 2.14 mA。
  • 2.15 mA 是 rf = 0（定電壓降，Fig 1.30 的 A 點）的結果：4.3/2000 = 2.15 mA。差 0.01 mA，觀念（差距很小）不變，只是數字對應的模型要分清楚。

補充（不是錯）：1-109 的 E ≈ V/W 是平均電場，突變接面的最大電場約是平均的 2 倍；講義旁註「外加的反向電壓不一定百分之百只落在空乏區」也是在提醒這只是估計。1-126 提到的 Example 1.8 講義沒有放題目，本頁依課本補上（VPS = 5 V、R = 2 kΩ、IS = 10−13 A），請對照課本確認。
