原講義 PART 501 · 投影片 1-13～1-15、1-18 · Diffusion & Junction Capacitance

vs DIFFUSION VS JUNCTION CAPACITANCE

順偏時，電子跑到 p 區、電洞跑到 n 區，在那裡變成「多出來的少數載子」——像一間倉庫的庫存。電壓一變，庫存跟著變，這個 ΔQ/ΔV 就是擴散電容 Cd。

Cd = dQ/dV（課本：Cd = τT IDQ / (2VT)）　　順偏＋交流：Cd ≫ Cj　　頻率 ↑ ⟹ Cd ↓

電容從哪裡來

  1. 順偏 ⟹ 少數載子注入對面中性區 ⟹ 儲存電荷 Q
    投影片 1-14：注入的少數載子就像電容「板上的電荷」，暫時存在那裡。
  2. vD = VD + ΔV ⟹ 少數載子濃度曲線上下動 ⟹ ±ΔQ
    投影片 1-13（Fig 1.37）：陰影部分就是多存或少存的電荷。電壓 ↑ 注入更多 → 像電容充電。
  3. Cd = ΔQ/ΔV
    定義跟一般電容一樣。電流越大，庫存越多，Cd 越大（課本：Cd ∝ IDQ）。
  4. 頻率 ↑ ⟹ 載子來不及進出 ⟹ dQ ↓ ⟹ Cd ↓
    投影片 1-15：低頻時充放電跟得上，Cd 完整表現；高頻時 dQ/dt 跟不上 dV/dt。
  5. 接面電容 Cj：空乏區兩邊的固定電荷，任何偏壓都在

    投影片 1-18：Cj 在 DC、AC、順偏、逆偏都存在（PART 3 的變容二極體就是它）；Cd 只在順偏＋交流時作用。順偏下 Cd ≫ Cj（講義 1-13 Remark 寫成「接面電容 Cj ≫ Cd」，應為擴散電容，見勘誤 ①）。

分辨兩種電容

  1. 逆偏 → 只有 Cj（空乏區）。
  2. 順偏＋交流 → Cd 和 Cj 都有，Cd 通常大很多。
  3. Cd ∝ IDQ；頻率越高，Cd 越小。

電容的陷阱

  • ✗ 順偏時 Cj ≫ Cd。Cd ≫ Cj（講義 1-13 Remark 筆誤）。
  • ✗ 順偏時就沒有接面電容。Cj 還在，只是被 Cd 蓋過。
  • ✗ 擴散電容的電荷在空乏區。在空乏區外的中性區（注入的少數載子）。

原講義 PART 502 · 投影片 1-16、1-17 · 1.4.2 Small-Signal Equivalent Circuit

小訊號等效電路SMALL-SIGNAL EQUIVALENT CIRCUIT

把前兩節的東西拼起來：交流眼中的二極體 = rd 並聯 Cd。頻率低時電容像斷路，看到 rd；頻率高時電容抄捷徑，阻抗往下掉。

簡化：Y = gd + jωCd，gd = 1/rd　　完整：rs 串聯（rd ∥ Cd ∥ Cj）　　fc = 1 / (2π rd C)

從二極體到 RC 電路

  1. 電阻那一支：gd = 1/rd
    交流電流有一部分「穿過」二極體（第 02 節）。
  2. 電容那一支：jωCd
    另一部分電流用來給庫存充放電（第 01 節）。
  3. 兩支並聯 ⟹ 導納相加：Y = gd + jωCd
    投影片 1-16（Fig 1.38(a)）：電導納（admittance）Y，並聯時直接相加。
  4. 頻率 ↑ ⟹ ωCd ↑ ⟹ |Z| = 1/|Y| ↓
    講義 NOTE：擴散電容和二極體電阻形成 RC 電路，頻率增加、電容阻抗降低，二極體等效阻抗下降。
  5. 完整模型（Fig 1.38(b)）：再加 Cj（並聯）和 rs（串聯）

    rs 是 p、n 中性區本身的電阻。低頻時可以只用 rd；高頻（或開關）時電容不能省。

原講義 PART 503 · 投影片 1-22～1-27 · 補 1.2.5 Switching Transient

開關暫態：與SWITCHING TRANSIENT

水龍頭關了，水管裡的水還會流一下。二極體從順偏切到逆偏也一樣：存著的少數載子還在，電流會反過來流一陣子才停。

t < 0 順偏：i = IF　　0 < t < ts：vD ≈ 0、i ≈ −IR（掃出儲存電荷）　　ts < t < ts + tf：空乏區重建、|i| 下降　　關閉時間 > 開啟時間

順偏 → 逆偏，一步一步

  1. 順偏時：P 區存了多餘的電子、N 區存了多餘的電洞
    投影片 1-23。這就是第 01 節的「庫存」。
  2. t = 0 電源反轉：載子不會瞬間消失 ⟹ 二極體仍像短路，vD ≈ 0
    投影片 1-24：外部電壓變了，但接面內部還沒恢復成逆偏的空乏區。
  3. 0 < t < ts：反向電壓把載子「掃出」⟹ 逆向恢復電流 ≈ −IR（幾乎固定）
    投影片 1-25：vD ≈ 0，所以 IR ≈ VR/R。少數載子濃度回到熱平衡值所需的時間 = 儲存時間 ts。
  4. t > ts：空乏區擴大、位障升到 Vbi + VR，電流在 tf 內降到 0
    投影片 1-27：強電場擋住新的注入、掃走剩下的載子，反向電流慢慢變小 = 掉落時間 tf。
  5. 關閉時間 ts + tf > 開啟時間

    開啟只要把空乏區縮小、開始注入；關閉要先把庫存清掉。所以二極體當開關（例如整流）時，速度卡在關閉。注意：講義 1-27 寫「在掉落時間 ts 內」位障升高，應是 tf（勘誤 ②）。

看開關暫態的波形

  1. 順偏：IF = (VF − Vγ)/R。
  2. 剛切逆偏：vD ≈ 0 → IR ≈ VR/R，維持 ts。
  3. ts 之後：vD 往 −VR 走，電流在 tf 內歸零。
  4. 要快：用蕭特基，或加大 IR。

開關暫態的陷阱

  • ✗ 一切到逆偏，電流就變 0。先反向流 −IR 一段 ts。
  • ✗ ts 期間二極體已經承受 −VR。vD ≈ 0，電壓在 R 上。
  • ✗ 開啟比關閉慢。關閉比較慢（要清庫存）。

原講義 PART 504 · 投影片 1-19～1-21 · 1.5.1～1.5.3 Solar Cell, Photodiode, LED

、、SOLAR CELL · PHOTODIODE · LED

同一個 pn 接面，三種用法：光進電出來發電（太陽能電池）、光進電出來測光（光二極體，逆偏）、電進光出（LED，順偏）。

太陽能電池：光 → 空乏區產生 EHP → 電場分開 → 推動負載　　光二極體：逆偏，Iph ∝ 入射光　　LED：順偏 → 少數載子與多數載子復合 → 放出光子

三種元件，同一個空乏區

  1. 光打進空乏區 ⟹ 產生電子電洞對（EHP）
    光子的能量把共價鍵打開。投影片 1-19（Fig 1.39）。
  2. 空乏區電場 E 把電子推到 n、電洞推到 p ⟹ 光電流
    太陽能電池不接電源，自己推電流給負載（發電）。材料：Si、GaAs、III-V 化合物；化合物半導體轉換效率較好。
  3. 光二極體：故意加逆偏，空乏區更寬、電場更強 ⟹ 光電流 ∝ 光強
    投影片 1-20：把光訊號變電訊號（光偵測器）。沒光時只有很小的逆向飽和電流。
  4. LED：順偏 ⟹ 電子電洞擴散過空乏區 ⟹ 變成多出的少數載子
    投影片 1-20：在中性區跟多數載子復合（recombination），掉下來的能量用光放出來。
  5. 應用：LED + 光學腔 → 雷射二極體；LED + 光纖 + 光二極體 → 光通訊

    投影片 1-21（Fig 1.40）：一端 LED 把電訊號變光、光纖傳過去、另一端逆偏的光二極體把光變回電。

光進電出、電進光出

分辨三種光電元件

  1. 能量方向：光 → 電（太陽能電池、光二極體）；電 → 光（LED）。
  2. 偏壓：太陽能電池不加、光二極體逆偏、LED 順偏。
  3. LED 一定要串限流電阻。

光電元件的陷阱

  • ✗ 光二極體順偏。逆偏（順偏時光電流被大順向電流蓋掉）。
  • ✗ LED 的光在空乏區產生。在中性區復合時放出。
  • ✗ 太陽能電池要接電源。它本身就是電源，接負載。

原講義 PART 505 · 投影片 1-28～1-31 · 1.5.4 Schottky Barrier Diode · Example 1.12

SCHOTTKY BARRIER DIODE

把 p 型換成金屬，接在中度摻雜的 n 型上。電流靠多數載子，沒有少數載子庫存 → 關得快；IS 大很多 → 同樣電流壓降小約 0.2～0.3 V。

IS,SBD ≫ IS,pn ⟹ 同電流 VSBD < Vpn　　ΔV = VT ln(IS,SBD/IS,pn)　　Example 1.12：0.539 V vs 0.299 V

金屬 + n 型 = 快又省電壓

  1. 金屬接 n 型：n 型的電子流向金屬，直到費米能階對齊
    投影片 1-28：靠近金屬的 n 型失去電子、留下帶正電的離子 → 空乏區。
  2. 導通靠多數載子越過接面 ⟹ 沒有少數載子儲存 ⟹ 幾乎沒有 ts
    投影片 1-29：電子跑進金屬還是「多數」，不會變成要被清掉的庫存。所以切換很快。
  3. 逆偏：金屬裡大量電子貢獻電流 ⟹ IS 遠大於 pn
    投影片 1-30：pn 的 IS 來自少數載子漂移（少）；蕭特基的 IS 來自金屬端的多數載子（多）。
  4. V = VT ln(I/IS)：IS 大 104 倍 ⟹ 電壓少 0.24 V
    Example 1.12（投影片 1-31）：1 mA 時 pn 0.539 V、蕭特基 0.299 V（Fig 1.42）。
  5. 結論：高速、壓降小，大量用在 IC 設計

    代價：IS 大 → 逆偏漏電流也大。

蕭特基題目

  1. 給 IS 求電壓：V = VT ln(I/IS + 1)。
  2. 比較：IS 每差 10 倍，電壓差 60 mV。
  3. 問速度：沒有少數載子儲存 → ts ≈ 0。

蕭特基的陷阱

  • ✗ 蕭特基靠少數載子。靠多數載子，所以沒有儲存時間。
  • ✗ IS 大是缺點所以壓降大。IS 大 → 壓降小（漏電大才是缺點）。
  • ✗ 金屬接 p 型。講義的結構是金屬接中度摻雜 n 型。

原講義 PART 506 · 投影片 1-32～1-34 · 1.5.5 Zener Diode · Design Example 1.13

ZENER DIODE

PART 5 說過：一般二極體要避開崩潰。齊納二極體反過來，故意住在崩潰區——那裡電壓幾乎不動，拿來。外接電阻負責限流。

崩潰區：VZ = VZ0 + IZrz（rz：幾 Ω～數十 Ω；rz → 0 ⟹ VZ = VZ0）　　限流：I = (VPS − VZ)/R　　PZ = IZVZ ≤ 額定

從崩潰曲線到穩壓電路

  1. 高摻雜 ⟹ 崩潰電壓低，崩潰區幾乎是一面垂直的牆
    投影片 1-32（Fig 1.43）。PART 5 的齊納崩潰：空乏區窄、電場強。
  2. 把那段牆用直線描：VZ = VZ0 + IZrz，斜率 1/rz
    投影片 1-33：跟片段線性模型一樣的手法。rz 是齊納電阻（增量電阻）。
  3. VZ、IZ 的方向跟一般二極體相反
    NOTE：齊納的 VZ 是陰極對陽極為正、IZ 從陰極流進去。寫 KVL 要用它自己的定義。
  4. Design Example 1.13：R = (10 − 5.6)/3 mA = 1.47 kΩ
    rz = 0：齊納 = 5.6 V 電池，多出來的 4.4 V 都在 R 上。
  5. PZ = IZVZ = 3 mA × 5.6 V = 16.8 mW

    齊納要撐得住這個功率。電源在一定範圍內變動，輸出都留在 5.6 V —— 這就是穩壓（下一章的穩壓器會正式用到）。

齊納電路的標準流程

  1. 確認 VPS > VZ（不然沒崩潰，齊納 = 斷路）。
  2. 齊納換成 VZ0 電池（串 rz）。
  3. I = (VPS − VZ0)/(R + rz)，VZ = VZ0 + Irz。
  4. 檢查 PZ = IZVZ ≤ 額定。

齊納的陷阱

  • ✗ 齊納順偏接。逆偏接，陰極接高電位。
  • ✗ 不用電阻也可以。一定要限流電阻，不然電流暴衝燒掉。
  • ✗ VPS 變大，輸出也變大。輸出卡在 VZ，多的落在 R 上。

原講義 PART 5Errata · 講義檢查結果

講義勘誤ERRATA

原講義 PART 5（V3）1-13～1-34 逐頁驗算過。Example 1.12、Design Example 1.13 的數字都正確，下面是要修正或要注意的地方（1-1～1-12 的在 PART 6）。

① 投影片 1-13 Remark：「接面電容 Cj ≫ Cd」

  • 講義寫：一般而言，在順偏＋交流信號時，接面電容 C ≫ C
  • 應該是：擴散電容 Cd ≫ 接面電容 Cj。同一份講義 1-18 也寫「擴散電容在順偏條件下通常是主導電容」，前後要一致。

② 投影片 1-27：「在掉落時間 ts 內」—— 請確認

  • ts 是儲存時間，掉落時間是 tf。
  • 內容也對不上 1-24、1-25：ts 期間 vD ≈ 0、接面還是「近短路」；位障升到 Vbi + VR、空乏區電場變強是 ts 之後（tf）的事。所以這頁應是「在掉落時間 tf 內」。請對照老師上課說法確認。

③ 投影片 1-22 左下圖：「從逆偏切換到零偏」—— 請確認

  • 這一頁講的是順偏 → 逆偏的關閉過程，圖說應為 從順偏切到逆偏（或「從順偏切到零偏」）。若圖原本是開啟過程（turn-on），請以老師說法為準。
