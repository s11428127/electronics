原講義 CH2 PART 201 · 板書 · 電池充電器 · Battery Charger

電池充電器：推電池BATTERY CHARGER

二極體後面不是電阻、而是一顆電池。電源要先推過「電池 + 二極體」的門檻，二極體才通 —— 導通的時間會比半個週期還短。

vS > VB + Vγ 才導通　　iD = (vS − Vγ − VB)/R　　ωt1 = sin−1[(VB+Vγ)/VM]，ωt2 = 180° − ωt1　　PIV = VB + VM

一步一步推

  1. 電路：vS → 二極體 → R → 電池 VB → 回到電源
    電池方向是「被充電」：電流流進它的正極，所以它會擋住電流。
  2. KVL（剛要導通的瞬間，iD = 0）：vS − Vγ − 0·R − VB = 0
    剛導通時電流還是 0，電阻沒壓降。
  3. ⇒ 導通條件 vS > VB + Vγ
    比普通半波整流（只要 > Vγ）多一個 VB。
  4. 導通後：iD = (vS − Vγ − VB)/R
    電阻分到「剩下」的電壓。
  5. 起始角：VM sin ωt1 = VB + Vγ ⇒ ωt1 = sin−1[(VB+Vγ)/VM]
    把 vS = VM sin ωt 代進導通條件取等號。
  6. 結束角：ωt2 = 180° − ωt1；導通比例 = (ωt2 − ωt1)/360°
    sin 左右對稱。
  7. PIV = VB + VM
    負半週谷底：電源 −VM、電池 +VB 同向疊加。

  • ✗ 起始角算成 sin−1(VB/VM)。 要連 Vγ 一起：(VB+Vγ)/VM。

原講義 CH2 PART 202 · 板書 10/28 · 2.1.2 Full-Wave · Center-Tapped

中間抽頭CENTER-TAPPED FULL-WAVE RECTIFIER

半波丟掉整個負半週。全波用次級線圈的中間抽頭，上下兩半邊各接一顆二極體，輪流上班，負半週也能用。

vO = |vS| − Vγ　　不導通區 |vS| < Vγ　　PIV = 2Vm − Vγ

一步一步推

  1. 正半週：上面的二極體 ON、下面 OFF
    上半邊的電壓讓電流走上面那條路。
  2. vO = vS − Vγ
    跟半波一樣，只經過一顆二極體。
  3. 負半週：換下面的二極體 ON、上面 OFF
    下半邊此時的極性是對的，電流從負載同一方向流過。
  4. vO = −vS − Vγ = |vS| − Vγ
    此時 vS 是負的，加負號翻成正。
  5. ⇒ vO = |vS| − Vγ，不導通區 |vS| < Vγ
    兩顆都還推不開的時候輸出為 0。
  6. PIV：看 OFF 那一顆。陰極 = vO = Vm − Vγ，陽極 = −Vm
    兩邊相差：(Vm − Vγ) + Vm。
  7. ⇒ PIV = 2Vm − Vγ
    中間抽頭的缺點：二極體要耐兩倍的壓。

原講義 CH2 PART 2★ 老師說會考（第 4 題） 03 · 板書 10/28、11/3 · 2.1.2 Full-Wave · Bridge

橋式全波整流BRIDGE FULL-WAVE RECTIFIER

不要抽頭，改用四顆二極體接成橋。電流一進一出，每次經過兩顆，所以多吃一個 Vγ，但耐壓要求變一半。

導通條件 |vS| > 2Vγ　　iL = (|vS| − 2Vγ)/R　　vO = |vS| − 2Vγ（不導通時 0）　　PIV = Vm − Vγ

照 10/28 板書一步一步推

  1. 正半週（vS > 0）：一對二極體導通，各換成 Vγ 電池；KVL：vS − Vγ − iLR − Vγ = 0
    電流一進一出，路上有兩顆二極體（板書假設兩顆相同）。
  2. 剛要導通：iL = 0 ⇒ vS − 2Vγ = 0 ⇒ 導通條件 vS > 2Vγ
    跟半波一樣的招：令電流 = 0，找出臨界電壓。
  3. vS > 2Vγ：iL = (vS − 2Vγ)/R，vO = iLR = vS − 2Vγ；vS ≤ 2Vγ：iL = 0，vO = 0
    板書 In Summary 正半週三行。
  4. 負半週（vS < 0）：另一對導通；KVL：−vS − Vγ − iLR − Vγ = 0
    電流流過 R 的方向跟正半週一樣，所以 vO 還是正的。
  5. −vS > 2Vγ：iL = (−vS − 2Vγ)/R，vO = −vS − 2Vγ；否則 0
    板書 In Summary 負半週三行。兩半週合起來就是 vO = |vS| − 2Vγ。
  6. VTC：−2Vγ < vS < 2Vγ 平在 0；右邊斜率 +1、左邊斜率 −1（V 字形）
    板書「電壓轉移特性曲線」：轉折點在 ±2Vγ。
  7. 波形：每半週一顆駝峰，峰值 Vm − 2Vγ
    板書「輸出波形」：正半週一對導通、負半週另一對導通。
  8. PIV（11/3 板書）：OFF 的那顆一端在 Vm − Vγ、另一端在 0 ⇒ PIV = (Vm − Vγ) − 0 = Vm − Vγ

    峰值瞬間：輸入 Vm 扣掉導通那顆的 Vγ，就是關著那顆陰極的電壓；另一端接地。負半週另一對同理。比中間抽頭（2Vm − Vγ）小約一半。

原講義 CH2 PART 204 · 板書 · 比較與設計 · Example 2.2

中間抽頭 vs 橋式：比較與設計COMPARISON & DESIGN

同樣要一個輸出電壓，兩種電路各需要多大的次級電壓、多少匝數比、多高的耐壓？先看電流經過幾顆二極體，再往下算。

次級峰值：中間抽頭 VO + Vγ；橋式 VO + 2Vγ　　N1/N2 = 市電峰值 / 次級峰值　　rms = 峰值/√2

一步一步推

  1. 輸出峰值 = 次級峰值 − 路徑上的 Vγ
    中間抽頭 1 顆、橋式 2 顆。
  2. ⇒ 次級峰值 = VO + Vγ（中間抽頭）／VO + 2Vγ（橋式）
    反過來推，設計時用這個方向。
  3. rms = 峰值/√2
    變壓器規格常用 rms。
  4. 匝數比 N1/N2 = 120√2 / 次級峰值
    市電 rms 先換成峰值。
  5. PIV：2Vm − Vγ（中間抽頭）／Vm − Vγ（橋式）
    把次級峰值代進去。
  6. 結論：橋式次級圈數只要一半、整個次級線圈都用到、PIV 低；代價是 4 顆二極體
    板書第二頁的比較。

同樣輸出，兩種電路要多少

Example 2.2

解題步驟

  1. 決定用哪一種（幾顆在路徑上）。
  2. 次級峰值 = 輸出峰值 + 損失。
  3. rms、匝數比、PIV 依序算。

常見錯誤

  • ✗ 匝數比用 rms 除以峰值。 同單位：120√2 = 169.7 V 對次級峰值。
  • ✗ 橋式 PIV 比較大。 橋式 PIV 比較小（約一半）。
  • ✗ 中間抽頭的 N2 是整個次級。 取「半邊」的圈數來算。
