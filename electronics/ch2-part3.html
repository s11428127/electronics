截波器與箝位器

整流之外，二極體還能削波形（截波）或搬波形（箝位）。做法都一樣：先找二極體開始導通的分界點，再分區寫輸出。

整頁的主線

  1. 並聯截波：vi > VB + Vγ 時 vO = VB + Vγ
    二極體 + 電池當門檻。
  2. 雙向截波：上限 VB1 + Vγ1、下限 −(VB2 + Vγ2)
    兩個分界點、三個區間。
  3. 箝位：vO = vi − (VM − VB − Vγ)
    電容鎖住峰值，整個波形平移。
原講義 CH2 PART 301 · 板書 · Clipper 截波器 · Parallel

並聯截波器SHUNT (PARALLEL) CLIPPER

訊號太大，超過某個電壓的部分要削掉。並聯截波器用二極體加電池當門檻：輸入超過它，二極體導通、輸出被釘住。

vi > VB + Vγ：vO = VB + Vγ　　否則：vO = vi

一步一步推

  1. 二極體換成等效模型：ON = Vγ 電池、OFF = 斷路
    CH1 學過的定電壓降模型。
  2. 二極體 + 電池串在一起，要推過 VB + Vγ 才會導通
    兩個門檻疊加，跟電池充電器一樣的想法。
  3. vi > VB + Vγ：ON ⇒ vO = VB + Vγ
    輸出被電池加二極體「釘」在門檻（多出來的電壓掉在電阻 R 上）。
  4. vi < VB + Vγ：OFF ⇒ i = 0，vO = vi
    斷路，電阻沒壓降。
  5. ⇒ 正峰被削成平頂，其餘照原樣
    板書的結論：vO = VB + Vγ（導通）／vi（不導通）。

解題步驟

  1. 找二極體開始導通的輸入電壓（分界點）。
  2. 分兩段：大於分界點、小於分界點。
  3. 每一段用 ON／OFF 模型寫 vO。
  4. 求最大、最小值。

常見錯誤

  • ✗ 門檻只有 VB。 要加 Vγ：VB + Vγ。
  • ✗ 輸入沒超過門檻還是被截。 沒超過就完全不變。
  • ✗ 截平的部分 vO = 0。 是被釘在 VB + Vγ。

原講義 CH2 PART 302 · 板書 · Clipper 截波器 · Series

串聯截波器SERIES CLIPPER

二極體改成串在訊號路徑上。輸入大於某個分界點，輸出變 0；小於分界點，輸出是輸入平移一個分界點。

vi > VB − Vγ：vO = 0　　vi < VB − Vγ：vO = vi − (VB − Vγ)

一步一步推

  1. 找分界點：二極體剛好導通的 vi = VB − Vγ
    板書的結果。電路圖的接法請照老師原圖（我讀不清手寫極性）。
  2. vi > VB − Vγ：vO = 0
    板書。
  3. vi < VB − Vγ：vO = vi − (VB − Vγ)
    輸出 = 輸入減掉分界點，整個波形被平移。
  4. ⇒ 最大值 0；最小值 = −VM − (VB − Vγ)
    最小值發生在 vi = −VM。

  1. 找分界點 VB − Vγ。

原講義 CH2 PART 303 · 板書 · Example 2.7 · Two-Way Clipper

雙向截波器TWO-WAY CLIPPER

上面一顆管上限，下面一顆管下限，頭尾一起削。中間兩顆都 OFF，輸出照著輸入走。有 R2 的版本，超過上限的部分用分壓留下一部分。

上限 VB1 + Vγ1　　下限 −(VB2 + Vγ2)　　中間 vO = vi　　超過上限：vO = (vi − Vγ1 − VB1)·R2/(R1+R2) + Vγ1 + VB1

一步一步推

  1. vi > VB1 + Vγ1：上面那顆 ON
    板書用 Vγ1、VB1 標上面那顆。
  2. R1、R2 串聯，二極體 + 電池那條路把中間點「墊高」到 Vγ1 + VB1
    輸入超過的部分 (vi − Vγ1 − VB1) 落在 R1 + R2 上。
  3. 輸出取 R2 的那一份：vO = (vi − Vγ1 − VB1)·R2/(R1+R2) + Vγ1 + VB1
    分壓公式，再加回墊高的準位。
  4. vi < −(VB2 + Vγ2)：下面那顆 ON ⇒ vO = −(VB2 + Vγ2)
    直接釘住。
  5. Example 2.7（Vγ = 0，R1 = R2，VB1 = 2 V、VB2 = 4 V）：上方 vO = ½vi + 1，下方 −4 V
    R2/(R1+R2) = ½；數字是我讀手寫的，請確認。

解題步驟

  1. 找兩個分界點（上限、下限）。

原講義 CH2 PART 304 · 板書 · Clamper 箝位器

箝位器CLAMPER

不削頭，整個波形上下平移。靠一顆電容把峰值「記住」：二極體只在剛開始幫電容充電，之後電容被鎖住，輸出 = 輸入 − 電容電壓。

VC = VM − VB − Vγ　　vO = vi − (VM − VB − Vγ)　　最大 VB + Vγ　　最小 −2VM + VB + Vγ

一步一步推

  1. 二極體 ON 時：vC = vi − VB − Vγ
    KVL：輸入 = 電容 + 電池 + 二極體。
  2. 輸入上升到峰值 VM，電容跟著充到 VM − VB − Vγ
    最高點之前二極體一直 ON。
  3. 過了峰值，二極體 OFF：電容沒有放電路徑，電壓鎖住 ⇒ VC = VM − VB − Vγ
    板書：vC = VM − VB − Vγ 維持不變。
  4. vO = vi − VC = vi − (VM − VB − Vγ)
    輸出取在電容之後，每一點都減掉同一個數。
  5. 最大：vi = VM ⇒ VB + Vγ；最小：vi = −VM ⇒ −2VM + VB + Vγ
    代入就得到板書的兩個極值。

拉 VB，看整個波形怎麼平移

解題步驟

  1. 算電容穩態電壓 VC = VM − VB − Vγ。
  2. vO = vi − VC。
  3. 代 vi 的最大、最小求輸出極值。

常見錯誤

  • ✗ 輸出最大值是 VM。 最大值是 VB + Vγ。
  • ✗ 輸出擺幅變小。 擺幅不變，還是 2VM。
  • ✗ 電容會在負半週放電。 二極體 OFF，沒路徑，電壓鎖住。
