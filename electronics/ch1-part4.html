一句話：順偏把坡壓低 → 翻得過坡的載子「指數地」變多 → 電流 iD = IS(evD/VT − 1)。後面所有東西（60 mV 一個數量級、理想二極體、溫度效應、溫度計）都是這條式子的推論。

投影片 1-41 的三種狀態，一張表看完

  1. 熱平衡（vD = 0）：電場阻力 = 濃度驅力　⟹　總電流 = 0
    PART 3 的內容：擴散與漂移打平，動態平衡。
  2. 逆偏（vD < 0）：淨電場變大、空乏區變寬（Cj ↓）　⟹　iD ≈ −IS，像開關 OFF
    電場阻力 > 濃度驅力，多數載子過不去；只剩少數載子造成的極小 IS。
  3. 順偏（vD > 0）：淨電場變小、空乏區變窄　⟹　持續的順向電流 iD，像開關 ON（或 0.7 V 壓降）
    電場阻力 < 濃度驅力，多數載子大量擴散過去。這一頁的主角。

：把坡壓低FORWARD-BIASED PN JUNCTION

P 接正、N 接負。外加電場跟內建電場反方向，坡從 Vbi 降成 Vbi − vD。濃度驅力贏過電場阻力，多數載子大量翻過去，到了對面就變成，一路擴散、一路復合 —— 這股擴散就是順向電流。

Etotal = Ē − EA（仍由 n 指向 p，但變小）　位障 Vbi − vD　　邊緣少數載子：pn(0) = pn0 · evD/VT

順偏時發生什麼事，一步一步

  1. P 接 +、N 接 −　⟹　外加 EA 由 p 指向 n，跟 Ē 反向　⟹　Etotal = Ē − EA
    投影片 1-38 (1)(2)。只要 vD < Vbi，EA < Ē，淨電場仍由 n 指向 p，只是變弱了。
  2. 電池從兩端送進電子與電洞 ⟹ 空乏區邊緣的離子被「補回」成中性 ⟹ W ↓
    投影片 1-40：N 側的 P⁺ 收到電子變回中性的 N 型、P 側的 B⁻ 的多餘電子被拉走變回 P 型。露出來的離子少了，空乏區就窄了（W ∝ √(Vbi − vD)）。
  3. 位障 Vbi → Vbi − vD ⟹ 濃度驅力 > 電場阻力 ⟹ 多數載子持續擴散過接面
    投影片 1-38 (3)～(5)：P 區電洞擴散到 N 區、N 區電子擴散到 P 區。兩者造成的電流同方向（P → N），合起來就是順向電流 iD。
  4. 翻得過坡的比例 ∝ e−(位障)/VT　⟹　pn(0) = pn0 · evD/VT（課本延伸）
    熱運動的載子，能量超過 E 的比例跟 e−E/kT 成正比（波茲曼分布）。坡從 Vbi 降了 vD，翻得過去的就多了 evD/VT 倍 —— 所以 N 區邊緣的電洞從 pn0 暴增成 pn0evD/VT。講義沒寫這條，但它是「電流是指數」的根源。
  5. 邊走邊復合 ⟹ δp(x) = δp(0) · e−x/Lp，Lp = √(Dpτp)
    投影片 1-43 Fig 1.16：注入的少數載子往中性區擴散，同時被多數載子復合掉（PART 2 的多出載子、生命週期），濃度隨距離指數衰減。L 叫。
  6. 少數載子的濃度梯度 ⟹ 擴散電流 ⟹ iD ∝ δp(0) + δn(0) ∝ (evD/VT − 1)

    投影片 1-45 的紅字：多數載子跨過接面 → 變成對方的少數載子 → 形成濃度梯度 → 擴散電流。梯度正比於邊緣的多出濃度，所以電流也帶著那個 evD/VT。下一節把它寫成正式的 I–V 公式。

判斷偏壓狀態、描述載子行為的標準流程

  1. 看 P 端（陽極）對 N 端（陰極）的電壓 vD：正 = 順偏、負 = 逆偏。
  2. 位障 = Vbi − vD（逆偏時 vD = −VR，位障變成 Vbi + VR）。
  3. 順偏：多數載子擴散過去 → 變成對面的少數載子 → 邊緣濃度 × evD/VT → 指數衰減。
  4. 電流方向：電洞 P→N、電子 N→P，兩者的電流都是 P → N，相加。

順偏最常搞混的地方

  • ✗ 順偏時淨電場反過來由 p 指向 n。只要 vD < Vbi，淨電場仍由 n 指向 p，只是變小（投影片 1-38 (2)、Fig 1.15 說明）。
  • ✗ 順向電流主要是漂移電流。是擴散電流：靠的是注入的少數載子的濃度梯度。
  • ✗ 電洞往右、電子往左，兩個電流抵消。電子帶負電，往左走 = 電流往右，兩者相加。
  • ✗ 注入的少數載子會一直存在。一路被復合，大約走幾個擴散長度 L 就幾乎沒了。

理想 I–V 關係IDEAL CURRENT–VOLTAGE RELATIONSHIP

上一節得到「電流 ∝ evD/VT − 1」。把比例常數叫做 IS，就是整個 CH1 最重要的一條式子。它一邊貼地、一邊往上暴衝 —— 這就是 pn 接面的特性。

iD = IS ( evD / nVT − 1 )　　vD > 0.1 V：iD ≈ ISevD/nVT　　vD < 0：iD ≈ −IS

從「注入」到 I–V 公式

  1. 擴散電流 = e·D·(濃度梯度)，梯度 ≈ δ(0)/L　⟹　Jp = eDp·δp(0)/Lp
    指數衰減 δp(0)e−x/L 在 x = 0 的斜率大小就是 δp(0)/L。PART 2 的擴散電流公式直接套。
  2. δp(0) = pn(0) − pn0 = pn0(evD/VT − 1)
    上一節的注入公式減掉原本就有的 pn0。「−1」就是從這裡來的：vD = 0 時多出來的是 0，電流也是 0。
  3. 電洞 + 電子：iD = eA(Dppn0/Lp + Dnnp0/Ln)·(evD/VT − 1)
    兩種載子的擴散電流同方向，相加。括號前面那一大串全部是常數（課本延伸）。
  4. 令 IS = eA(Dppn0/Lp + Dnnp0/Ln) ∝ nᵢ²　⟹　iD = IS(evD/VT − 1)
    pn0 = nᵢ²/Nd、np0 = nᵢ²/Na，所以 IS 正比於 nᵢ² —— 矽約 10⁻¹⁸～10⁻¹² A 等級，極小。這也是第 5 節溫度效應的伏筆。
  5. 實際二極體：evD/VT → evD/nVT，1 ≤ n ≤ 2（，未聲明取 n = 1）
    投影片 1-44 NOTE：空乏區裡的復合在低電流時影響大，n 接近 2；電流夠大時擴散主導，n 接近 1。
  6. 兩個極限：vD ≫ VT ⟹ −1 可忽略；vD ≪ −VT ⟹ e… → 0，iD ≈ −IS

    vD = 0.1 V 時 e0.1/0.026 ≈ 47，忽略 −1 的誤差約 2%；再大就更小。所以講義說「vD > 0.1 V 時 iD ≈ ISevD/nVT」—— 這是數學近似成立的門檻，不是導通電壓（投影片 1-47 的旁註）。

I–V 公式的陷阱

  • ✗ 逆偏時電流 = 0。是 −IS：極小但不是 0，負號代表方向（投影片 1-46）。
  • ✗ VT 代 26（mV）然後 vD 代 0.7（V）。單位要一致：0.7 / 0.026 = 26.9，不是 0.7 / 26。
  • ✗ 「vD > 0.1 V」是導通電壓。那只是 −1 可以忽略的門檻；IS = 10⁻¹⁴ A 時，0.1 V 的電流還不到 1 pA。
  • ✗ n 越大電流越大。相反：指數變成 vD/(nVT)，n 越大曲線越「緩」，同一電壓電流越小。

每 60 mV 變 10 倍ONE DECADE PER 60 mV

指數函數的特色：電壓加一個固定量，電流就乘一個固定倍數。對二極體來說，這個「固定量」是 60 mV、「固定倍數」是 10。在對數座標上，I–V 曲線就變成一條直線（Fig 1.18）。

ΔvD = nVT · ln( i2 / i1 )　　i2/i1 = 10 ⟹ ΔvD = VT ln 10 ≈ 60 mV（n = 1）

60 mV 從哪來

  1. 順偏（vD > 0.1 V）：i1 = ISev1/nVT，i2 = ISev2/nVT
    −1 已經可以忽略（上一節）。
  2. 相除：i2/i1 = e(v2 − v1)/nVT
    IS 消掉了。這很重要：IS 很難準確知道（每顆二極體都不一樣），但比值關係跟它無關。
  3. 取 ln：v2 − v1 = nVT·ln(i2/i1)
    指數的反函數是 ln。這條式子比 i–v 公式本身更常用。
  4. i2/i1 = 10、n = 1：Δv = 0.026 × ln 10 = 0.026 × 2.303 = 0.0599 V ≈ 60 mV

    反過來說：電流變 2 倍只要 0.026 × ln 2 ≈ 18 mV；變 100 倍要 120 mV。n = 2 的話全部加倍（每 120 mV 一個數量級）。這就是為什麼二極體導通後電壓「幾乎不動」—— 電流從 1 mA 到 10 mA，電壓才多 0.06 V。

60 mV 規則的陷阱

  • ✗ 電壓加倍，電流加倍。電流是指數：加 60 mV 就 × 10，跟電壓的倍數無關。
  • ✗ 任何電壓都適用 60 mV 規則。只在順偏、−1 可忽略時（vD ≳ 0.1 V）成立。
  • ✗ 用 log 不用 ln。Δv = nVT·ln(比值)；用 log₁₀ 的話要寫成 2.303·nVT·log₁₀(比值)，也就是 60 mV × log₁₀(比值)。

模型IDEAL DIODE MODEL

指數公式很準，但解電路時很難用（v 跟 i 糾纏在 e 的次方裡）。工程上的做法是把那條曲線簡化成開關：逆偏 = 斷路（OFF）、順偏 = 短路（ON）。再精確一點，就讓它導通時固定掉 0.7 V。

vD < 0：iD = 0（斷路，RR → ∞）　　導通：vD = 0（短路，RF = 0），iD 由外部電路決定

為什麼可以這樣簡化

  1. 逆偏：|iD| = IS ≈ 10⁻¹⁴ A ≪ 電路裡的 mA　⟹　當成 0，斷路
    差了 11 個數量級，忽略它的誤差比電阻的誤差還小。RR = VR/IR，IR → 0 所以 RR → ∞。
  2. 順偏：每 60 mV 電流 × 10　⟹　mA 尺度上看，曲線幾乎是一道垂直的牆
    Fig 1.17 用 mA 當單位時，0.6 V 以前看起來是 0，過了之後幾乎垂直往上。
  3. 把牆放在 0 V ⟹ 理想二極體；把牆放在 0.7 V ⟹ 定電壓降模型（Vγ，）
    投影片 1-41：「二極體被 MODEL 成導通（類似開關 ON 或 0.7 V 壓降）」。電源電壓比 0.7 V 大很多時，兩種模型差不多。
  4. 導通時 RF = VF/IF = 0 是因為 VF = 0，電流 IF = (VS − Vγ)/R，有限值

    投影片 1-49 在 IF 旁標了「∞」—— 這是錯的（見勘誤 ①）。短路只代表二極體本身不擋電流，電流多大由電源和電阻決定（同一頁圖上也寫了「ISC 受電路的限制」）。

溫度效應TEMPERATURE EFFECTS

iD = IS(evD/nVT − 1) 裡有兩個量跟溫度有關：VT = kT/e，和 IS ∝ nᵢ²。溫度一高，熱產生的載子變多，IS 暴增 —— 同樣的電流只要更小的電壓。曲線整條往左移。

固定 iD：dvD/dT ≈ −2 mV/°C　　IS ∝ nᵢ² ∝ T³e−Eg/kT：每升 5 °C 約翻倍（實際逆偏電流約每 10 °C 翻倍）

−2 mV/°C 從哪來

  1. 順偏：iD ≈ ISevD/VT　⟹　固定 iD 時 vD = VT·ln(iD/IS)
    溫度計、偏壓電路都是「電流固定、看電壓」，所以把式子解成 vD。
  2. nᵢ = BT3/2e−Eg/2kT（投影片 1-53）⟹ IS ∝ nᵢ² ∝ T³e−Eg/kT
    IS 是少數載子造成的，少數載子 = nᵢ²/N，所以 IS 跟著 nᵢ² 走。
  3. 300 K → 305 K：(305/300)³ × e(Eg/k)(1/300 − 1/305) = 1.05 × e0.71 ≈ 2.1 倍
    這就是講義「每增加 5 °C，IS 倍增」。e 的次方那項（能隙）是主角，T³ 只貢獻 5%。
  4. T ↑：VT 線性變大（讓 vD ↑），IS 指數變大（讓 ln 變小、vD ↓）⟹ 後者贏
    投影片 1-51：「IS 的增加通常遠比 VT 的增加顯著」。
  5. 對 T 微分：dvD/dT = (vD − Eg/e − 3VT)/T ≈ (0.6 − 1.12 − 0.078)/300 ≈ −2.0 mV/K

    把 IS = K·T³e−Eg/kT 代進 vD = VTln(iD/IS) 再對 T 微分（課本延伸）。結果跟講義的 −2 mV/°C 一致；實際數字依電流和元件在 −1.5～−2.5 mV/°C 之間。直覺：越熱，載子越多，越「好過」（類似電阻性較低）。

溫度效應的陷阱

  • ✗ VT 變大，所以 vD 變大。IS 的指數增長贏過 VT，固定電流下 vD 變小。
  • ✗ 溫度升高，同一電壓下電流變小。變大：曲線往左移，同一電壓對應的電流變多。
  • ✗ −2 mV/°C 是精確常數。是經驗值，依電流與元件約 −1.5～−2.5 mV/°C（下一節溫度計算出來是 −1.75 mV/K）。
  • ✗ 鍺跟矽的 IS 差不多。鍺的能隙小（0.66 eV），nᵢ 大很多，IS 大好幾個數量級（投影片 1-53）。

DIODE THERMOMETER

缺點反過來就是優點：既然 vD 會隨溫度乖乖地、幾乎線性地下降，那讓二極體流固定電流、量它的電壓，就能反推溫度。課本的電路只有一顆 15 V 電源、一顆 15 kΩ 電阻和一顆二極體。

ID ≈ (15 − 0.6) V / 15 kΩ ≈ 1 mA（近似固定）　⟹　VD ≈ 1.12 − 0.522 · (T / 300) V　⟺　T = 300 · (1.12 − VD) / 0.522 K

Fig 1.48 那條直線怎麼來

  1. ID = (15 − VD)/15k ≈ 0.96 mA，VD 只變 0.1 V，ID 只變 0.7%
    電源電壓遠大於 VD，所以這顆大電阻 + 大電源就是一個「近似定電流源」（投影片 1-52、1-54：ID 要保持 CONSTANT）。
  2. VD = VTln(ID/IS)，IS = K·T³·e−Eg/kT　⟹　VD = Eg/e − (kT/e)·ln(K·T³/ID)
    把 e−Eg/kT 從 ln 裡拿出來，剛好變成常數 Eg/e = 1.12 V（矽的能隙）。
  3. ln(K·T³/ID) 隨 T 變得很慢 ⟹ 在 300 K 附近當常數 ⟹ VD ≈ 1.12 − c·T
    T³ 在 ln 裡面，溫度變 20% 它才變一點點。所以 VD 對 T 幾乎是直線（Fig 1.48 的 Linear relationship）。
  4. 用一個量測點校正：T = 300 K 時 VD = 0.598 V ⟹ c·300 = 1.12 − 0.598 = 0.522 V
    這就是課本的 VD = 1.12 − 0.522(T/300)。斜率 −0.522/300 = −1.74 mV/K（跟上一節的 −2 mV/°C 同一個等級）。
  5. 驗算 Fig 1.48：T = 255.2 K（0 °F）→ 0.676 V；T = 310.8 K（100 °F）→ 0.579 V ✓

    1.12 − 0.522 × 255.2/300 = 0.676；1.12 − 0.522 × 310.8/300 = 0.579。圖上三個數字全部吻合。量到的電壓越小，代表溫度越高。

小遊戲：讀溫度計

答對 0 題

溫度計題目的標準流程

  1. 確認電流近似固定（大電源 + 大電阻），沒有的話先算 ID。
  2. 用校正點寫出直線：VD = VD0 + 斜率 × (T − T0)，斜率約 −1.7～−2 mV/K。
  3. 量到的 VD 代回去解 T；K 和 °C 差 273，°F 要再換算。

溫度計的陷阱

  • ✗ 電壓越高溫度越高。相反：VD 越小代表越熱。
  • ✗ 電流不用固定。一定要固定：電流變 10 倍電壓就差 60 mV，相當於 30 多度的誤差。
  • ✗ T 代攝氏。公式裡的 T 是絕對溫度 K（300 K ≈ 27 °C）。

講義勘誤ERRATA

PART 4 的 1-38～1-54 我逐頁驗算過。Example 1.7、60 mV 規則、溫度計 Fig 1.48 的數字全部正確，下面是要修正或要注意的地方。

① 投影片 1-49：理想二極體導通時「IF → ∞」

  • 講義在 RF = VF/IF = 0 Ω 的 IF 旁標了：∞
  • 應該是：RF = 0 是因為 VF = 0，IF 是由外部電路決定的有限值（同一頁圖上也寫了「ISC（受電路的限制）」）。
  • 對照：下面逆偏那行 RR = VR/IR ≒ ∞、IR 旁標 0 —— 這個是對的。

② 投影片 1-42：Practice diode → practical diode（考英文要注意）

  • 講義寫：實際二極體 (Practice diode)
  • 應該是：practical diode（或 real diode）。practice 是名詞「練習」，形容詞是 practical。

③ 投影片 1-44：「矽 IS：10⁻¹³～10⁻¹⁸ A」—— 請對照課本確認

  • 我印象中 Neamen 課本寫的是 10⁻¹⁸～10⁻¹² A。不算錯（都是極小的數），但上限差了一個數量級，考填充題時以課本為準。

④ 投影片 1-44 NOTE：「低電流 n = 2、高電流 n = 1」—— 補充，不是錯

  • 低電流時空乏區復合主導 → n ≈ 2；中等電流擴散主導 → n ≈ 1 ✓。
  • 但電流非常大（大注入，注入的少數載子濃度跟摻雜同等級）時，n 又會往 2 走。講義的「高電流」指的是中等電流範圍。

用語：1-47「意指：數學近似等效，非 0.1 V 為導通電壓之意」這個旁註很重要，建議畫重點；1-50 的 −2 mV/°C 和 Fig 1.48 算出來的 −1.74 mV/K 不矛盾，前者是經驗法則、後者是課本這顆特定二極體在 1 mA 下的值。

驗算過、正確的部分：
  • 1-38 順偏 Etotal = Ē − EA，淨電場仍由 n 指向 p ✓
  • 1-43 Fig 1.16：注入的少數載子隨距離近似指數衰減，主因是復合 ✓
  • 1-46 Example 1.7：10⁻¹⁴ × (e0.70/0.026 − 1) = 10⁻¹⁴ × 4.93×10¹¹ = 4.93 mA；vD = −0.70 V → ≈ −10⁻¹⁴ A ✓
  • 1-47 vD > 0.1 V 時 −1 可忽略：e0.1/0.026 = 46.8，誤差 2.1% ✓
  • 1-48 每 60 mV 一個數量級：0.026 × ln 10 = 59.9 mV ✓
  • 1-53 每 5 °C IS 倍增：300 → 305 K 算出 × 2.1 ✓；nᵢ = BT3/2e−Eg/2kT ✓
  • 1-52/1-54 Fig 1.47：(15 − 0.6)/15 kΩ ≈ 0.96 mA ✓；Fig 1.48：VD = 1.12 − 0.522(T/300) 在 255.2 / 300 / 310.8 K 給出 0.676 / 0.598 / 0.579 V ✓
