原講義 CH2 PART 101 · 投影片 2-2～2-4 · Block Diagram for ac to dc Converter

電源供應器方塊圖BLOCK DIAGRAM OF A DC POWER SUPPLY

一個充電器拆開，裡面就是四段：變壓器降壓、整流變單向、濾波弄平、穩壓穩住。每一段把波形往「一條直線」推近一步。

AC 110 V →〔變壓器〕→ 較小的交流 →〔整流〕→ 脈動直流 →〔濾波〕→ 有漣波的直流 →〔穩壓（7805）〕→ 5 V

一級一級看

  1. 市電：110 V（rms）、60 Hz，峰值 110√2 ≈ 155.6 V
    交流：一下正一下負。電子產品要的是低壓直流。
  2. 變壓器：把 110 V 提升或降低到適當的交流電壓
    投影片 2-3。還是交流，只是大小變了（下一節）。
  3. 整流電路：利用二極體單向導通 ⟹ 交流變成脈動的直流
    分半波整流和全波整流（投影片 2-2）。這一頁講半波。
  4. 濾波電路：整流輸出端加一顆電容，把脈動直流變平穩
    電容儲存電荷，在交流波動期間放電補上（投影片 2-3）。
  5. 穩壓電路：例如 7805 線性穩壓 IC，輸出穩定 5 V（具回授控制）

    CH1 PART 6 的齊納二極體也能做簡單的穩壓（Design Example 1.13）。

點一級，看它的輸出

看方塊圖的題目

  1. 記順序：變壓器 → 整流 → 濾波 → 穩壓。
  2. 每一級的輸出波形：正弦 → 小正弦 → 駝峰 → 有漣波的直流 → 直線。
  3. 算電壓：rms × √2 → ÷ 匝數比 → − Vγ。

方塊圖的陷阱

  • ✗ 整流完就是直流了。是脈動直流，方向不變但大小一直變，還要濾波。
  • ✗ 變壓器把交流變直流。變壓器只改大小，輸出還是交流。

原講義 CH2 PART 102 · 投影片 2-5 · Transformer Turns Ratio

與TRANSFORMER TURNS RATIO

一塊鐵心上繞兩組線圈。接市電的是一次側，輸出的是二次側。兩邊的電壓比 = 圈數比。

vS / vI = N2 / N1　　N1/N2：匝數比（transformer turns ratio）　　市電 vI = 110 V（rms）/ 60 Hz

匝數比怎麼用

  1. 一次側 vI：110 V（rms）、60 Hz 市電
    投影片 2-5：功率變壓器（power transformer）的一次側接市電。
  2. vS/vI = N2/N1
    電壓跟圈數成正比。N2 < N1 就降壓。
  3. 比的時候單位要一樣：rms 對 rms、峰值對峰值
    110 V 是 rms；要算整流後的峰值，記得乘 √2。
  4. 例：10:1 ⟹ vS 峰值 = 155.6/10 = 15.56 V

    二次側還是交流、頻率還是 60 Hz，只是變小。

匝數比題目

  1. 確認給的是 rms 還是峰值。
  2. N1/N2 = vI/vS（同單位）。
  3. 要整流後的峰值：二次側峰值 − Vγ。

變壓器的陷阱

  • ✗ vS/vI = N1/N2。N2/N1：二次側電壓跟二次側圈數成正比。
  • ✗ 12 V（rms）整流後峰值 11.3 V。12√2 − 0.7 = 16.27 V。

原講義 CH2 PART 103 · 投影片 2-5、2-6 · 2.1.1 Half-Wave Rectification · VTC

：三種情況與THREE CASES & THE VTC

二極體換成 CH1 的模型（rf = 0：ON 是 Vγ 電池、OFF 是斷路），再看 vS 落在哪裡。只有 vS 超過 Vγ 才有輸出。

① vS < 0：OFF，vD = vS，vO = 0　② 0 < vS < Vγ：OFF，vD = vS，vO = 0　③ vS > Vγ：ON，vD = Vγ，vO = vS − Vγ

一個一個情況推

  1. 二極體換成等效模型（rf = 0）
    投影片 2-6 NOTE：加入二極體等效模型分析電路。
  2. ① vS < 0 ⟹ OFF ⟹ ID = 0 ⟹ vD = vS，vO = 0
    逆偏。沒電流，電阻沒壓降，整個 vS 都在二極體上。
  3. ② 0 < vS < Vγ ⟹ 仍 OFF ⟹ vD = vS，vO = 0
    正的，但還推不開門。講義這裡寫成 Vr，應為 Vγ（勘誤 ①）。
  4. ③ vS > Vγ ⟹ ON ⟹ vD = Vγ，iD = (vS − Vγ)/R
    二極體 = Vγ 電池，剩下的電壓給 R。
  5. vO = iDR = vS − Vγ：轉移特性是一條斜率 1 的直線

    把三種情況畫成 vO 對 vS（Fig 2.2(b)）：Vγ 以前貼地，之後斜率 = 1。斜截式 y = mx + b：令 x = 0 得 y 截距、令 y = 0 得 x 截距 —— 這條線在 vS = Vγ 碰到橫軸。

三種情況的標準流程

  1. vS 跟 0、Vγ 比。
  2. OFF：iD = 0、vO = 0、vD = vS。
  3. ON：vD = Vγ、iD = (vS − Vγ)/R、vO = vS − Vγ。

三種情況的陷阱

  • ✗ vS 只要是正的就導通。要超過 Vγ（情況 ②）。
  • ✗ OFF 時 vD = 0。OFF 時 vD = vS；ON 時才是 Vγ。
  • ✗ VTC 斜率是 1/R。斜率 = 1，跟 R 無關。

原講義 CH2 PART 104 · 投影片 2-7 · Fig 2.3 Signals of the Half-Wave Rectifier

波形：vO、vD 與 WAVEFORMS & PIV

輸入換成弦波，每個瞬間套三種情況，就得到輸出波形：只剩正半週、比輸入矮 Vγ。二極體自己的電壓 vD = vS − vO，負半週會扛整個 −VM。

vO = max(0, vS − Vγ)　　vD = vS − vO（ON：Vγ；OFF：vS）　　PIV = VM

兩種方法畫波形

  1. 方法一：照公式，每一瞬間判斷三種情況
    投影片 2-7 右上那三行。
  2. 方法二：用 VTC，把 vS 投影到 vO
    橫軸找到這一刻的 vS，往上碰到 VTC，讀縱軸。兩種方法結果一樣（Fig 2.3(b)）。
  3. vD = vS − vO：ON 時平平卡在 Vγ，OFF 時跟著 vS
    投影片 2-7 Note，Fig 2.3(c)。
  4. 導通區間：VM sin ωt > Vγ ⟹ ωt 從 sin−1(Vγ/VM) 到 180° 減它
    比半個週期少一點；VM 越大越接近一半。
  5. 負半週谷底：vD = −VM ⟹ 二極體的 PIV 額定要大於 VM

    CH1 PART 5 的 PIV 在這裡派上用場。電阻負載的半波整流，最大逆壓就是輸入峰值。

畫整流波形的流程

  1. 畫輸入 vS，標出 Vγ 那條線。
  2. vO：超過 Vγ 的部分往下移 Vγ，其他畫 0。
  3. vD = vS − vO：ON 時 Vγ、OFF 時 = vS。
  4. 標峰值 VM − Vγ、PIV = VM。

波形的陷阱

  • ✗ vO 峰值 = VM。VM − Vγ（理想模型才相等）。
  • ✗ 負半週 vD = 0。vD = vS，谷底 −VM。
  • ✗ PIV = VM − Vγ。PIV = VM，OFF 時二極體扛全部。

原講義 CH2 PART 1Errata · 講義檢查結果

講義勘誤ERRATA

2-1～2-7 逐頁看過，觀念與公式正確，只有一個符號要統一。

① 投影片 2-6、2-7：Vr → Vγ

  • 情況 2 寫成 0 < vS < Vr、情況 3 寫成 vS > Vr、vD = Vr。
  • 應為 Vγ（切入電壓 gamma），跟同一頁的 iD = (vS − Vγ)/R、Fig 2.2(b) 一致。

勘誤僅針對數學、單位與用詞正確性；若與課堂說法不同，以老師為準。PIV、導通角、7805 壓差約 2 V 為課本延伸。
