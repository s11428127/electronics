課本 CH1313.1–13.2 · Mutual Inductance

互感與打點規則MUTUAL INDUCTANCE

線圈 1 的電流 i1 在變，它的有一部分穿過線圈 2，線圈 2 就感應出電壓 v2 = M di1/dt。M 一定是正的，但這個電壓的 + 在哪一端，要看兩個線圈怎麼繞 —— 電路圖用「點」代替。

v2 = M di1/dt　·　v1 = L1 di1/dt ± M di2/dt　·　串聯 L = L1 + L2 ± 2M　·　頻域 V1 = jωL1I1 ± jωM I2

互感電壓從哪來

  1. v1 = N1 dφ1/dt = N1(dφ1/di1)(di1/dt) = L1 di1/dt
    法拉第定律：磁通在變，線圈兩端就有電壓。自感 L1 = N1 dφ1/di1。
  2. φ1 = φ11 + φ12
    線圈 1 的磁通一部分只繞自己（φ11，漏磁），一部分穿過線圈 2（φ12）。
  3. v2 = N2 dφ12/dt = N2(dφ12/di1)(di1/dt) = M21 di1/dt
    穿過線圈 2 的那部分在線圈 2 感應電壓，比例常數就是互感。
  4. M12 = M21 = M

    反過來由 i2 在線圈 1 感應電壓也是同一個 M（13.3 用能量證明）。

打點規則與正負號

  1. 電流從線圈 1 的點流進 ⟹ 線圈 2 的點端為 +
    課本原文：enters the dotted terminal → positive at the dotted terminal of the second coil。
  2. 電流從線圈 1 的點流出 ⟹ 線圈 2 的點端為 −
    方向反過來，極性跟著反。
  3. 兩個電流同進同出點 ⟹ +M；一進一出 ⟹ −M

    實際解題就用這一句。每個線圈的電壓 = 自感項（照被動符號）＋ 互感項（照這一句）。

串聯加成與相消

  1. v = (L1 di/dt + M di/dt) + (L2 di/dt + M di/dt)
    同一個 i 依序流過兩個線圈，都從點流進：每個線圈多一個 +M di/dt。
  2. 加成：L = L1 + L2 + 2M　相消：L = L1 + L2 − 2M

    相消時一進一出，兩個互感項都變負（式 13.18、13.19）。

有互感的電路怎麼解

  1. 換成頻域：L → jωL、M → jωM。
  2. 選網目電流（通常都順時針），標出每個線圈「流過它的電流」。
  3. 判斷正負：看兩個線圈的電流是同進同出點（+jωM）還是一進一出（−jωM）。不確定就照課本圖 13.8，把互感項畫成相依電壓源再決定極性。
  4. 寫 KVL：每個線圈的壓降 = jωL × 自己的電流 ± jωM × 對方的電流。
  5. 解聯立（代入法或克拉瑪）。共用支路上的線圈，電流是兩個網目電流相減（Example 13.2）。

互感的坑

  • ✗ 看到 M 就一律加上去。✓ 先看點：同進同出 +、一進一出 −。
  • ✗ 互感項乘自己的電流（jωM I1 寫在線圈 1）。✓ 線圈 1 上的互感電壓是由「對方」的電流 I2 產生的。
  • ✗ 共用支路的線圈互感用網目電流 I1。✓ 要用流過那個線圈的實際電流（例如 I1 − I2）。
  • ✗ 以為直流電路也有互感電壓。✓ 直流穩態 di/dt = 0，沒有互感電壓。

補課解網目方程式 · Cramer's Rule

補課：解含 j 的聯立方程式CRAMER'S RULE

網目分析寫完，最後都剩兩條聯立方程式，係數還帶 j。克拉瑪法則把「解聯立」變成固定流程：算三個、相除，不用消去、不用猜。

a11I1 + a12I2 = b1，a21I1 + a22I2 = b2　⟹　Δ = a11a22 − a12a21　·　Δ1 = b1a22 − a12b2　·　Δ2 = a11b2 − b1a21　·　I1 = Δ1/Δ，I2 = Δ2/Δ

公式怎麼來（2 × 2）

  1. a11I1 + a12I2 = b1　…①
    a21I1 + a22I2 = b2　…②
    先整理成標準型。未知數照順序排在左邊，常數（電源）全部移到右邊。
  2. ① × a22 − ② × a12：(a11a22 − a12a21)I1 = b1a22 − a12b2
    目的是把 I2 消掉。兩式的 I2 係數都變成 a12a22，相減就沒了。
  3. Δ = a11a22 − a12a21（左上 × 右下 − 右上 × 左下）
    I1 前面那一坨有名字，叫係數矩陣的行列式。口訣：主對角線乘起來，減掉另一條對角線。
  4. Δ1 = b1a22 − a12b2：把第 1 行換成常數 [b1; b2]
    右邊那坨也是行列式。要求 I1，就把 I1 那一行（a11、a21）換成常數，照樣交叉相乘。
  5. Δ2 = a11b2 − b1a21：把第 2 行換成常數
    同一招消掉 I1 會得到 Δ · I2 = Δ2。要求誰，就換掉誰那一行。
  6. I1 = Δ1/Δ，I2 = Δ2/Δ

    Δ = 0 表示兩條方程式其實是同一條，沒有唯一解（電路圖抄錯了，回去檢查）。

有 j 的時候：只多兩個規則

  1. 乘法：(a + jb)(c + jd) = ac + jad + jbc + j2bd = (ac − bd) + j(ad + bc)
    跟國中的分配律一樣展開。唯一要記的是 j2 = −1，所以 bd 那項變號、跑到實部。
  2. 例：(−j8)(−j8) = 64 j2 = −64
    最常算錯的一項。兩個純虛數相乘，答案是負的實數。
  3. 除法：換成極座標，A∠α ÷ B∠β = (A/B)∠(α − β)
    直角座標硬除要乘共軛，很容易錯。換成大小與角度，大小相除、角度相減，一步就好。
  4. 換極座標：a + jb → √(a2 + b2)∠tan−1(b/a)
    a < 0 時角度要加 180°（點在左半平面）。計算機用 Pol( ) 或 ∠ 鍵最保險。
  5. Example 13.2：Δ = (4 + j3)(5 + j18) − (−j8)(−j8) = (−34 + j87) − (−64) = 30 + j87

    (4 + j3)(5 + j18) = 20 + j72 + j15 + j254 = (20 − 54) + j87；再減掉 −64，等於加 64。

克拉瑪計算機：一步一步看交叉相乘

第 1 步

上面每一格都能改（左邊實部、右邊 j 的係數）。按「下一步」，矩陣裡正在相乘的兩格會亮起來：綠底是主對角線，橘底是另一條對角線，虛線框是換進去的常數。

拿到兩條含 j 的方程式怎麼解

  1. 整理成標準型：I1 項、I2 項在左，電源在右；同一個未知數的係數先合併（例：4 − j3 + j6 = 4 + j3）。
  2. 填係數：a11、a12、a21、a22、b1、b2，負號跟著係數走。
  3. 算 Δ：左上 × 右下 − 右上 × 左下，每個乘積先展開，j2 換成 −1。
  4. 算 Δ1、Δ2：要求誰就把誰那一行換成常數。常數有 0 的話，那個乘積直接是 0。
  5. 相除：Δ、Δ1、Δ2 都換成極座標，大小相除、角度相減。
  6. 驗算：把 I1、I2 代回其中一條方程式，左右要相等。

克拉瑪法則的坑

  • ✗ (−j8)(−j8) = +64。✓ j × j = j2 = −1，所以是 −64；Δ 裡「減掉 −64」變成 +64。
  • ✗ 把 −j8 填成 j8（負號丟掉）。✓ 係數連同正負號一起填進矩陣。
  • ✗ 交叉相乘寫成 a11a22 + a12a21。✓ 中間永遠是減號。
  • ✗ 求 I1 卻把第 2 行換成常數。✓ 求 I1 換第 1 行（I1 的係數那一行）。
  • ✗ 直角座標直接「實部除實部、虛部除虛部」。✓ 除法一律換極座標：大小相除、角度相減。

課本 CH1313.3 · Energy in a Coupled Circuit

耦合電路的能量ENERGY IN A COUPLED CIRCUIT

兩個耦合線圈存的能量，比兩個獨立電感多一項 ±M i1i2。因為線圈不會自己生出能量，總能量一定 ≥ 0，由此推出 M 最大只能是 √(L1L2)，再用 k 表示「離上限多近」。

w = ½L1i12 + ½L2i22 ± M i1i2　·　M ≤ √(L1L2)　·　k = M/√(L1L2)，0 ≤ k ≤ 1

能量公式

  1. w1 = ∫ L1i1 di1 = ½L1I12
    先讓 i1 從 0 升到 I1、i2 保持 0：只有線圈 1 吃功率。
  2. w2 = M12I1I2 + ½L2I22
    再讓 i2 升到 I2：線圈 1 上多了互感電壓 M12 di2/dt，電流是 I1。
  3. w = ½L1I12 + ½L2I22 + M12I1I2
    兩段加起來。
  4. 先升 i2 再升 i1 ⟹ 互感項是 M21I1I2；最後能量要一樣 ⟹ M12 = M21
    能量只跟最後狀態有關，跟順序無關。
  5. w = ½L1i12 + ½L2i22 ± M i1i2

    同進同出點取 +，一進一出取 −。

為什麼 M ≤ √(L1L2)

  1. ½L1i12 + ½L2i22 − M i1i2 ≥ 0
    被動電路存的能量不能是負的；取最壞的負號。
  2. = ½(i1√L1 − i2√L2)2 + i1i2(√(L1L2) − M) ≥ 0
    配方：加減 i1i2√(L1L2)。
  3. 平方項最小是 0 ⟹ √(L1L2) − M ≥ 0

    所以 M 不能超過兩個自感的幾何平均。k = M/√(L1L2) 就落在 0～1 之間；k = φ21/φ2 是磁通穿過對方的比例。

能量題的標準流程（Example 13.3）

  1. k：直接 k = M/√(L1L2)。
  2. 換頻域，用 13.2 的方法解出 I1、I2。
  3. 換回時域，代入題目給的時間 t（注意 ωt 是弧度，換成角度再加相角）。
  4. 決定互感項正負：兩個電流（照你解出來的方向）同進同出點取 +，一進一出取 −。
  5. 代公式 w = ½L1i12 + ½L2i22 ± M i1i2。

能量的坑

  • ✗ 用相量的大小（或有效值）直接代進 ½Li2。✓ 要用那個瞬間的 i(t)。
  • ✗ 4t 在 t = 1 s 時當成 4°。✓ 4 rad = 229.2°。
  • ✗ 算出 k > 1。✓ 不可能，回去檢查 M 或 L 有沒有抄錯。
