先複習 PART 1（這一頁從這裡接下去）

  1. Vab = √3 Van∠+30°（abc）
    線電壓 = 兩相相減。這一頁的 Δ 負載吃的就是它。
  2. 平衡 → 單相等效：Ia = Van/ZY，其他兩相轉 ∓120°
    這一頁所有接法最後都會化回這一條。
  3. ZY = ZΔ/3
    12.2 推過的 Δ-Y 轉換。

這一頁只有一個新觀念：Δ 那一側，「線」的量是「相」的量的 √3 倍、差 30°。Δ 負載是電流 √3 倍；Y 電源是電壓 √3 倍。

原講義 CH1212.4 · Balanced Wye-Delta Connection

平衡 Y-Δ 接法BALANCED WYE-DELTA

Y 接電源接 Δ 接負載，這是最實用的組合（電源通常 Y、負載通常 Δ）。Δ 負載的每一格直接跨在兩條線之間，所以每格吃的是線電壓 VAB；流過每格的叫相電流 IAB。線上的電流在節點 A 被分給 AB、CA 兩格，所以 Ia = IAB − ICA：√3 倍、落後 30°。

VAB = Vab = √3 Vp∠30°　　IAB = VAB/ZΔ　　Ia = √3 IAB∠−30°（IL = √3 Ip）　　或 Ia = Van/(ZΔ/3)

相電流：KVL 沿 aABbna

  1. −Van + ZΔIAB + Vbn = 0
    從 a 出發經過 AB 那格到 b，再經過電源 b 相、a 相回到 a（沒有線路阻抗）。
  2. IAB = (Van − Vbn)/ZΔ = Vab/ZΔ = VAB/ZΔ

    Van − Vbn 就是線電壓。Δ 負載每格吃線電壓。

線電流：節點 A 的 KCL

  1. Ia = IAB − ICA
    流進節點 A 的有 Ia（從線上來）和 ICA（從 CA 那格來），流出去的是 IAB。
  2. ICA = IAB∠−240°（abc）
    三格相電流也只差 120°，CA 比 AB 晚 240°。
  3. Ia = IAB(1 − 1∠−240°) = IAB(1 + 0.5 − j0.866)
    1∠−240° = −0.5 + j0.866，減掉它。
  4. Ia = √3 IAB∠−30°

    |1.5 − j0.866| = √3、角度 −30°。跟 PART 1「線電壓 = 兩相相減」是同一個幾何：兩支差 120° 的箭頭相減，永遠 √3 倍、轉 30°。

另一條路：Δ 換成 Y

  1. ZY = ZΔ/3
    從三條線看進去完全一樣。
  2. Ia = Van/(ZΔ/3)

    直接拿到線電流；要相電流再除 √3、往前轉 30°。

Δ 負載：線電流 = 兩個相電流相減

Y-Δ 的標準流程

  1. 負載吃線電壓：VAB = √3 Van∠+30°（題目給 VAB 就直接用）。
  2. 相電流：IAB = VAB/ZΔ，其他兩格轉 ∓120°。
  3. 線電流：Ia = √3 IAB∠−30°，其他兩條轉 ∓120°。
  4. 驗算：Ia = Van/(ZΔ/3) 應該一樣。

Y-Δ 的坑

  • ✗ 用相電壓 Van 除 ZΔ 當相電流。✓ Δ 每格吃線電壓：IAB = VAB/ZΔ。（Van 要除的是 ZΔ/3，得到的是線電流。）
  • ✗ Ia = √3 IAB∠+30°。✓ 線電流落後相電流 30°（abc）。
  • ✗ 把線電流當成流過負載的電流。✓ 流過每格負載的是相電流，小 √3 倍。

原講義 CH1212.5 · Balanced Delta-Delta Connection

平衡 Δ-Δ 接法BALANCED DELTA-DELTA

電源也接成 Δ：每顆電源本身就跨在兩條線之間，所以電源的相電壓 = 線電壓。沒有線路阻抗時，負載每格兩端就是電源的電壓（VAB = Vab）—— 四種接法裡最好算的。負載仍是 Δ，所以線電流一樣是相電流的 √3 倍、落後 30°。代價是 Δ 電源三顆繞成一圈，稍微不平衡就會有，實務上很少用。

Vab = Vp∠0° = VAB　　IAB = Vab/ZΔ　　Ia = IAB − ICA = √3 IAB∠−30°

為什麼 Δ-Δ 最好算

  1. Δ 電源：Vab、Vbc、Vca 本身就是線電壓
    每顆電源的兩端就是兩條線。
  2. 沒有線路阻抗 → VAB = Vab、VBC = Vbc、VCA = Vca
    導線兩端同電位，負載每格直接接在電源每顆上。
  3. IAB = Vab/ZΔ，Ia = √3 IAB∠−30°

    線電流那一步跟 12.4 一模一樣（只看負載的節點 KCL）。

Δ 電源的麻煩：環流

  1. 迴路 a → b → c → a 上只有三顆電源（加上很小的線圈內阻 r）
  2. KVL：3r·I環 = Vab + Vbc + Vca
    平衡時右邊 = 0，沒事；只要差一點點，除以很小的 3r 就是很大的電流。
  3. I環 = ΣV / 3r　→　浪費、發熱

    所以電源幾乎都接 Y（PART 4 的互動可以玩這個）。

Δ-Δ 的標準流程

  1. 沒有線路阻抗：IAB = Vab/ZΔ 直接除。
  2. 線電流：Ia = √3 IAB∠−30°。反過來給 Ia 求 IAB：除 √3、角度 +30°。
  3. 有線路阻抗：兩邊都換成 Y（電源 Van = Vab/√3∠−30°、負載 ZΔ/3），再單相等效。

Δ-Δ 的坑

  • ✗ Δ 電源的「相電壓」再乘 √3 當線電壓。✓ Δ 電源的相電壓本來就是線電壓。
  • ✗ 有線路阻抗時還說 VAB = Vab。✓ 線上有壓降就不相等，要先換成 Y-Y 算。
  • ✗ 20 − j15 = 25∠−36.57°（課本 Example 12.4 的筆誤）。✓ tan−1(15/20) = 36.87°。

原講義 CH1212.6 · Balanced Delta-Wye Connection

平衡 Δ-Y 接法與總整理BALANCED DELTA-WYE · SUMMARY

Δ 電源接 Y 負載。Δ 電源沒有中性點，沒辦法直接畫單相等效電路 —— 解法是想像一個等效的 Y 電源，它產生的線電壓跟原本的 Δ 一模一樣：Van = Vab/√3∠−30°（就是「線電壓 = √3 相電壓、超前 30°」倒過來）。換完就是 Y-Y。到這裡，四種接法全部都能化成 Y-Y 的單相等效 —— 課本表 12.1 就是這一節的總整理。

Van = (Vp/√3)∠−30°　　Ia = Vp∠−30° / (√3 ZY)　　Y 負載：相電流 = 線電流

方法一：KVL 沿 aANBba

  1. −Vab + ZYIa − ZYIb = 0　→　Ia − Ib = Vp∠0°/ZY
    從 a 經過 A 相負載到 N，再經過 B 相負載（電流反向）回到 b。
  2. Ib = Ia∠−120°　→　Ia − Ib = Ia(1 − 1∠−120°) = √3 Ia∠30°
    又是「兩支差 120° 的相減」。
  3. Ia = (Vp/√3)∠−30° / ZY

方法二：Δ 電源換成等效 Y 電源

  1. Y 電源：Vab = √3 Van∠+30°
    PART 1 推過。
  2. 倒過來：Van = Vab/√3 ∠−30°

    Δ 電源每相若有內阻 Zs，等效 Y 的內阻是 Zs/3。

  3. 單相等效：Ia = Van/ZY，跟方法一一樣

任何平衡三相題的萬用流程

  1. 電源 Δ → Y：Van = Vab/√3 ∠−30°（內阻 Zs/3）。
  2. 負載 Δ → Y：ZY = ZΔ/3。
  3. 單相等效：Ia = Van/(Zs + Zℓ + ZY)，照相序補齊。
  4. 需要 Δ 裡面的量再換回去：相電流 = 線電流 /√3、∠+30°；線電壓 = √3 × 相電壓、∠+30°。

Δ-Y 的坑

  • ✗ Van = Vab/√3 ∠+30°。✓ 倒過來是 −30°。
  • ✗ 直接用線電壓除 ZY。✓ Y 負載每相只吃 VL/√3。
  • ✗ −62° − 120° 寫成 −178°（課本 Example 12.5 的筆誤）。✓ = −182° = +178°。
