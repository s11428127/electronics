CH8 二階電路

同時有 L 和 C 時，能量會在兩者之間丟來丟去，像盪鞦韆。電阻是摩擦：摩擦夠大就平平地停下來，摩擦太小就會衝過頭再晃回來。這一章教你判斷會不會晃，並把曲線算出來。

    這章帶走三件事THREE TAKEAWAYS

    1. 特徵方程 s2 + 2αs + ω02 = 0，ω0 = 1/√(LC)；串聯 α = R/(2L)，並聯 α = 1/(2RC)。
    2. α 跟 ω0 比大小：α > ω0 過阻尼（兩實根，慢慢回去）、α = ω0 臨界（重根，最快不晃）、α < ω0 欠阻尼（共軛複根，ωd = √(ω02 − α2)，會晃、會衝過頭）。
    3. 步階響應 = 終點 + 自然響應，有兩個常數，要兩個初始條件：x(0)（不能跳）和斜率 dv/dt(0) = iC(0)/C、di/dt(0) = vL(0)/L。
