先複習 CH9～CH11 會一直用到的三件事

  1. 相量：v(t) = Vmcos(ωt + θ)　⟷　V = V∠θ
    這一章的電壓、電流一律是 rms（電力系統的習慣），寫 110∠0° V 就是有效值 110 V。
  2. 相乘：大小相乘、角度相加；相除：大小相除、角度相減
    「∠−120°」就是把相量順時針轉 120°。整章都在轉 120° 和 30°。
  3. 串聯阻抗直接相加；Z = R + jX，|Z| = √(R² + X²)，∠Z = tan−1(X/R)
    CH11 PART 1 補課講過。X > 0 電感性，X < 0 電容性。

整章最重要的一句話：平衡的三相，只要算一相。其他兩相是同一個答案轉 ∓120°。

原講義 CH1212.1 · Introduction

為什麼要三相WHY THREE PHASES

CH11 的電路都是單相：一顆電源、兩條線（去和回）。家裡的插座就是這樣。但發電廠送出來的電幾乎全是三相three-phase：一台同時發出三個一樣大、一樣頻率、但錯開 120°的電壓。課本給三個理由：(1) 發電、輸電本來就是三相，要單相再從裡面拿一相；(2) 三相的總瞬時功率是常數，馬達轉得很順、不會抖（12.7 證明）；(3) 同樣的功率，三相用的銅線比較少（12.7 算出只要 75%）。

van = Vmcos ωt　　vbn = Vmcos(ωt − 120°)　　vcn = Vmcos(ωt + 120°)　　⟹　van + vbn + vcn = 0（每一瞬間）

為什麼三個加起來「每一瞬間」都是 0

  1. vbn + vcn = Vm[cos(ωt − 120°) + cos(ωt + 120°)]
    先把 b、c 兩相湊在一起，因為它們剛好對稱（一個 −120°、一個 +120°）。
  2. cos(x − y) + cos(x + y) = 2 cos x cos y
    和差化積公式：兩個對稱的角度相加，sin 的部分會互相抵掉。
  3. = Vm · 2 cos ωt · cos 120° = Vm · 2 cos ωt · (−½) = −Vmcos ωt
    cos 120° = −½，所以 b + c 剛好是 a 的負的。
  4. van + vbn + vcn = Vmcos ωt − Vmcos ωt = 0

    不是只有某些時刻，是每一瞬間都抵消。這就是三相可以「不要回程線」的根本原因（12.3）。

看「三個相加」那格：磁鐵轉到哪裡都是 0（四捨五入到 0.1 V）。磁鐵 N 極掃過哪個線圈，哪個線圈的電壓就最大 —— 三個線圈隔 120°，波形就錯開 120°。

拿到三相題目，先做這三件事

  1. 電源是 Y 還是 Δ？負載是 Y 還是 Δ？四種組合（12.3～12.6），先認出是哪一種。
  2. 平衡嗎？電源三相一樣大、差 120°，負載三相阻抗一樣 → 平衡 → 只算一相。不平衡 → 12.8 的方法。
  3. 數字是 rms 還是振幅？這一章預設 rms；看到 v(t) = 200 cos(…) 這種寫法，200 是振幅。

常見誤會

  • ✗ 三相 = 三個互不相干的單相電路。✓ 三個是同一台發電機、同頻率、固定錯開 120°，所以才能互相抵消。
  • ✗ 錯開 90°。✓ 三相錯開 120°（360° ÷ 3）；錯開 90° 的是兩相系統。
  • ✗ 三相的「220 V」是每一相對地 220 V。✓ 通常說的是線電壓（兩條火線之間），12.3 會算出每一相只有 220/√3 = 127 V。

原講義 CH1212.2 · Balanced Three-Phase Voltages

平衡三相電壓與相序BALANCED VOLTAGES · PHASE SEQUENCE

三顆電源一樣大、錯開 120°，就叫平衡（balanced）。它們接到中性點 n 的電壓叫相電壓phase voltage。三個錯開 120° 的排法有兩種：b 比 a 晚 120° 叫正相序 abc，c 比 a 晚 120° 叫負相序 acb。電源和負載都可以接成 或 ，所以一共有四種組合。

abc：Van = Vp∠0°、Vbn = Vp∠−120°、Vcn = Vp∠+120°　　Van + Vbn + Vcn = 0　　ZΔ = 3ZY

用相量再證一次「加起來 = 0」

  1. Vp∠0° + Vp∠−120° + Vp∠+120°
    相量加法要換成直角座標（實部加實部、虛部加虛部）。
  2. = Vp[1 + (−0.5 − j0.866) + (−0.5 + j0.866)]
    cos(±120°) = −0.5，sin(±120°) = ±0.866。
  3. = Vp(1 − 0.5 − 0.5) + jVp(−0.866 + 0.866) = 0

    三支一樣長、各差 120° 的箭頭頭尾接起來，剛好圍成一個正三角形回到原點。

相序怎麼看：誰先到最高點

  1. 相量是以 ω 逆時針旋轉的箭頭
    v(t) = Re{V ejωt}：時間往前走，箭頭就逆時針轉。
  2. 固定看一個點（例如正實軸），記下箭頭經過的順序
    經過正實軸的那一刻就是那一相到達最大值。
  3. abc：a → b → c → a…；acb：a → c → b → a…

    實用判斷法：從 a 開始，往順時針（越來越晚）找下一個差 120° 的是誰。是 b 就是 abc，是 c 就是 acb。

為什麼 ZΔ = 3ZY

  1. Δ → Y 轉換（CH9）：Z1 = ZbZc / (Za + Zb + Zc)
    一般的公式：Y 的每一臂 = 相鄰兩個 Δ 邊相乘 ÷ 三邊總和。
  2. 平衡：Za = Zb = Zc = ZΔ　⟹　ZY = ZΔ2 / (3ZΔ)
  3. ZY = ZΔ/3　或　ZΔ = 3ZY

    平衡的 Δ 負載換成 Y，每相變成三分之一 —— 之後每一種接法都靠這一條換成 Y-Y。

判斷相序／由一相推另外兩相

  1. 全部換成相量，角度用 −180°～180° 表示（加減 360°）。
  2. 從 Van 開始，看哪一相比它晚 120°（角度小 120°）：是 b → abc；是 c → acb。
  3. 由一相推其他相：abc 時 Vbn = Van∠−120°、Vcn = Van∠+120°；acb 時 b、c 對調。
  4. 檢查：三個大小一樣、兩兩差 120°，加起來 = 0。

相序的坑

  • ✗ 看到 −230° 比 −110° 小就說它「比較早」。✓ 先 +360° 換成 130°。角度一律換到同一圈再比。
  • ✗ abc 時 Vbn = Van∠+120°。✓ b 比 a 晚 → ∠−120°。
  • ✗ Δ 換 Y 時 ZY = 3ZΔ。✓ 反了：Y 比較小，ZY = ZΔ/3。

原講義 CH1212.3 · Balanced Wye-Wye Connection

平衡 Y-Y 接法BALANCED WYE-WYE

Y 接電源 → 三條線 → Y 接負載。每一相上串著三個阻抗：發電機內阻 Zs、線路 Zℓ、負載 ZL，合起來叫 ZY。兩條線之間的電壓叫線電壓line voltage，它是兩個相電壓相減：大小 √3 倍、超前 30°。平衡時三個線電流加起來 = 0，上沒有電流 —— 所以可以只拿出 a 相畫成來算。

ZY = Zs + Zℓ + ZL　　Vab = √3 Vp∠30°（VL = √3 Vp）　　Ia = Van/ZY，Ib = Ia∠−120°，Ic = Ia∠+120°　　In = 0

線電壓為什麼是 √3 倍、超前 30°

  1. Vab = Van + Vnb = Van − Vbn
    KVL：從 a 走到 b，先從 a 到 n，再從 n 到 b。Vnb = −Vbn。
  2. = Vp∠0° − Vp∠−120° = Vp[1 − (−0.5 − j0.866)]
    換成直角座標才能相減。
  3. = Vp(1.5 + j0.866)
  4. = √3 Vp∠30°

    |1.5 + j0.866| = √(2.25 + 0.75) = √3，角度 tan−1(0.866/1.5) = 30°。另外兩條同理：Vbc = √3Vp∠−90°、Vca = √3Vp∠−210°。

為什麼中性線上沒有電流、可以只算一相

  1. Ia = Van/ZY，Ib = Vbn/ZY = Ia∠−120°，Ic = Ia∠+120°
    三相電壓只差 120°、阻抗一樣 → 電流也只差 120°。
  2. Ia + Ib + Ic = Ia(1 + 1∠−120° + 1∠120°) = 0
    跟三個電壓加起來 = 0 一模一樣的道理。
  3. In = −(Ia + Ib + Ic) = 0　⟹　VnN = ZnIn = 0

    中性線上沒有電流、兩端也沒有電壓差 → 有沒有中性線都一樣（三線式、四線式結果相同）。n 跟 N 同電位，所以 a 相可以自己成一個迴路：這就是單相等效電路。

平衡 Y-Y 的標準流程

  1. 每相總阻抗：ZY = Zs + Zℓ + ZL（沒給的當 0）。
  2. 單相等效：Ia = Van/ZY。
  3. 照相序補齊：abc → Ib = Ia∠−120°、Ic = Ia∠+120°（acb 對調）。
  4. 要線電壓：Vab = √3 Van∠+30°；要負載電壓：VAN = IaZL。
  5. 中性線電流：平衡時直接寫 0。

Y-Y 的坑

  • ✗ 只用負載阻抗算電流，忘了線路阻抗。✓ 線路、內阻、負載是串聯的，全部加起來。
  • ✗ Vab = √3 Van∠−30°。✓ abc 相序線電壓超前 30°（acb 才是 −30°）。
  • ✗ 三線式沒有中性線，所以不能用單相等效。✓ 平衡時 n、N 同電位，有沒有中性線都可以用。
  • ✗ 把線電壓當相電壓除阻抗。✓ Y 負載每相吃的是相電壓 = 線電壓 / √3。
