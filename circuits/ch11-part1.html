這一頁只有一條主線：p(t) = v·i → 取平均 → P = ½VmImcos(θv−θi)。最大功率轉移也只是「把這個 P 做到最大」。

先備：一條弦波怎麼讀（CH9 的東西，先複習一下）

  1. v(t) = Vm cos(ωt + θv)

    三個數字各管一件事：Vm（）是波峰多高；ω（）是擺得多快；θv（相位角）是「起跑時間」—— 它比標準的 cos 早或晚多少度。

  2. θv − θi = 電壓比電流早多少度
    電壓、電流頻率一樣，所以兩條波的差別只剩。這一章所有功率公式，都只看這個差。
  3. V = Vm∠θv（），Z = V/I = R + jX（）

    把 ω 拿掉，只留「大小」和「角度」就是相量。阻抗的實部 R 是電阻、虛部 X 是（電感 X > 0、電容 X < 0）。

原講義 CH1111.2 · Instantaneous and Average Power

瞬時功率與平均功率INSTANTANEOUS & AVERAGE POWER

直流的功率很簡單：P = V × I。交流的電壓電流每秒翻正負 60 次，每一瞬間的乘積都不一樣，這叫瞬時功率instantaneous power p(t)。它跳來跳去沒辦法拿來報數字，所以要取一個週期的平均，得到一個固定的數 —— 平均功率average power P。電器上標的「800 W」、電費單算的，都是這個 P。

p(t) = ½VmIm cos(θv − θi)  +  ½VmIm cos(2ωt + θv + θi)　⟹　P = ½VmIm cos(θv − θi)

這條式子是怎麼來的？

  1. p(t) = v(t)·i(t) = Vmcos(ωt+θv) × Imcos(ωt+θi)

    功率的定義就是「電壓 × 電流」，跟直流一樣。只是現在兩個都是弦波，所以卡在一個「cos 乘 cos」。

  2. cos A · cos B = ½[ cos(A−B) + cos(A+B) ]
    用積化和差把乘法拆成加法（加法比乘法好看出誰會變、誰不會變）。令 A = ωt+θv、B = ωt+θi：
    A − B = θv − θi（ωt 消掉了，變成常數！）
    A + B = 2ωt + θv + θi（ωt 變兩倍）
  3. p(t) = ½VmImcos(θv−θi) + ½VmImcos(2ωt+θv+θi)

    代進去就得到兩項。左項完全沒有 t（是個定值），右項是 2ω 的弦波（擺得比電壓快一倍）。整章的故事到這裡就定調了。

  4. P = (1/T)∫₀T p(t) dt
    平均功率的定義：把 p(t) 在一個週期內積分（加總），再除以週期。就像「一個月的零用錢 ÷ 30 天 = 平均每天」。
  5. 第一項：常數的平均 = 它自己 → 保留
    第二項：弦波一週期的平均 = 0 → 消失

    弦波正半週的面積，剛好被負半週抵銷，所以積分為零。這就是為什麼「會擺盪的那一半不算進平均功率」。

  6. P = ½VmIm cos(θv − θi)

    剩下的就是答案。注意 cos(θv−θi) = cos(θi−θv)，所以只有相位差的大小重要，誰減誰不影響 P（但會影響 Q 的正負，PART 3 會用到）。

三個特例：cos 就是「打幾折」

  1. 純電阻：θv − θi = 0° → cos 0° = 1 → P = ½VmIm
    電壓電流同步，正×正、負×負都是正的，p(t) 永遠 ≥ 0。不打折：送來的全部吃掉，變成熱。
  2. 純電感：θv − θi = +90° → cos 90° = 0 → P = 0
    p(t) 一半時間正、一半時間負，面積完全相等。電感前半拍把能量存進磁場、後半拍原封不動還給電源 —— 像跟朋友借 100 元又還 100 元，淨支出 0。
  3. 純電容：θv − θi = −90° → cos(−90°) = 0 → P = 0
    一樣借了又還，只是存在電場裡。所以只有電阻會真的消耗平均功率，P = ½|I|²R 只看電阻。

順帶一提，用相量也能算：½V·I* = ½VmIm∠(θv−θi) = ½VmIm[cos(θv−θi) + j·sin(θv−θi)]，取實部就是 P。所以 P = ½Re[V·I*] —— 這條在 PART 3 會變成的起點。

電阻任何時刻都在吸收功率（p(t) ≥ 0）；電感與電容的平均功率為 0，它們只是把能量借來還去。

拿到「求平均功率」的題目

  1. 先把 sin 換成 cos。sin x = cos(x − 90°)，兩條波都寫成 cos 才能直接比角度。
  2. 看題目給什麼：給 v(t)、i(t) → P = ½VmIm cos(θv − θi)；給電流和阻抗 → P = ½|I|²R（R 是阻抗的實部）；給電壓和阻抗 → 先 I = V/Z。
  3. 電路裡有好幾個元件時，電感、電容直接寫 0，只算電阻；最後用「電源送出 = 電阻吸收總和」驗算。
  4. 最後檢查：P 不可能大於 ½VmIm；若是電源，算出負的代表它在吸收（被充電）。

這一節最常被扣分的地方

  • ✗ 忘記那個 ½。公式是 P = ½VmImcos θ，用的是振幅。若題目給的已經是 rms 值，才是 P = VrmsIrmscos θ（沒有 ½，PART 2 講）。✓ 先看清楚題目給的是振幅還是 rms。
  • ✗ 題目給 sin 卻直接當成 cos 代入。✓ 先轉成 cos：sin(x) = cos(x − 90°)，轉完再讀相角。
  • ✗ θv − θi 算成 45° − 10° = 35°。✓ θi = −10° 時是 45° − (−10°) = 55°，負負得正。
  • ✗ 以為 p(t) 的週期跟 v(t) 一樣。✓ p(t) 的角頻率是 2ω，週期只有一半。
  • ✗ 看到 p(t) 有負的部分就說「負載在發電」。✓ 負區只代表儲能元件把先前存的能量還給電源，不是產生新能量。

補課 · CH9–CH10 複習Before 11.3 · Load, Impedance, j, Thevenin

補課：負載、阻抗、j、戴維寧BACK TO BASICS

11.3 一開口就是「負載 ZL」「ZTh = 4 + j3」「共軛」。這些都是 CH9、CH10 的東西，忘了很正常。這一節不趕進度，一個詞一個詞講回來： 是把電用掉的那一端；是交流版的電阻，分成會發熱的和只擋不熱的； 是「放直軸」的標籤；把整個電源縮成一個插座。看完再往下讀 11.3 會順很多。

Z = R + jX　　|Z| = √(R² + X²)　　θ = tan⁻¹(X/R)　　ZR = R，ZL = jωL，ZC = −j/(ωC)　　j × j = −1

一步一步把這些詞講回來

  1. 電源 → 導線 → 負載（load）

    負載就是接在電路最後面、把電用掉的東西：燈泡、喇叭、馬達、充電器。題目說「負載要選多少」，意思是「要接一個什麼樣的電器」。跟「負擔」沒有關係。

  2. 直流：R = V ÷ I（例：12 V ÷ 3 A = 4 Ω）
    先回到最熟的直流：電阻就是「電壓推多少、電流只出來多少」的比值。被擋下來的能量變成熱 —— 電阻是真的會吃功率的元件。
  3. 電感：電流晚到 90°　　電容：電流早到 90°

    電感、電容對交流也會擋電流，但擋法不一樣：它們會讓電流跟電壓錯開 90°，而且能量借了又還、不發熱（11.2 看過，平均功率是 0）。這種擋法另外取名叫 X。

  4. 電阻 4 Ω ＋ 電抗 3 Ω ≠ 7 Ω，而是 √(4² + 3²) = 5 Ω
    兩種擋法方向不同，像「往東走 4 步、往北走 3 步」，離起點是斜邊 5，不是 7。所以需要一種能把「東」和「北」分開記的寫法 —— 那就是。
  5. Z = R + jX　（4 + j3 = 往東 4、往北 3）

    沒貼標籤的 R 放橫軸（實部），貼了 j 的 X 放直軸（虛部）。j 就是一張「放直軸」的標籤。電路學把虛數單位寫成 j 而不是 i，是因為 i 已經拿去當電流了。

  6. 1 →(× j)→ j →(× j)→ −1　⟹　j² = −1
    乘上 j 等於在平面上往左轉 90°：往東的 1 轉一次變往北的 j，再轉一次變往西的 −1。所以 j × j = −1。電感、電容讓電流錯開的正好是 90°，所以用 j 來記電抗剛剛好。
  7. i = Imcos ωt　⟹　v = L·di/dt = −ωL·Imsin ωt = ωL·Imcos(ωt + 90°)
    電感的電壓是電流的微分。cos 微分變 −sin，而 −sin x = cos(x + 90°)：電壓的大小變成 ωL 倍、角度超前 90°。「大小 ωL、轉 90°」寫成複數就是 ZL = jωL。
  8. 電容：i = C·dv/dt　⟹　ZC = 1/(jωC) = −j/(ωC)
    電容反過來：電流是電壓的微分，所以電流超前 90°。1/j 上下同乘 j：j/(j·j) = j/(−1) = −j，所以電容的電抗是負的。結論：X > 0 是電感性、X < 0 是電容性、X = 0 是純電阻。
  9. |Z| = √(R² + X²)，θ = tan⁻¹(X/R)；電流大小 |I| = |V| ÷ |Z|，電流落後 θ

    |Z|（唸「Z 的大小」，又叫）是總共擋多少；θ 是電流錯開幾度 —— 也就是 11.2 的 θv − θi，功率要打 cos θ 折。例：4 + j3 → |Z| = 5 Ω、θ = 36.87°、cos θ = 0.8。

  10. 串聯：Z總 = Z1 + Z2（實部加實部、虛部加虛部）
    跟電阻串聯一樣直接相加，只是東、北分開加：(4 + j3) + (4 − j3) = 8 + j0 = 8 Ω。虛部剛好消掉 —— 這就是 11.3「共軛匹配」在做的事。
  11. 任何電源，從 a、b 看進去 = VTh 串 ZTh

    戴維寧等效：電源那一側再複雜（發電機、變壓器、一堆電線），負載只接在 a、b 兩點，看不到裡面。所以可以把它縮成一個插座：插座電壓 VTh、插座裡面擋多少 ZTh。Th 是人名 Thevenin 的縮寫。

  12. VTh = 拔掉負載量 a、b 的電壓　　ZTh = 電源關掉、從 a、b 往裡看的總阻抗
    「電源關掉」= 電壓源換成一條線（短路）、電流源剪斷（開路）。CH11 的題目大多直接給 VTh、ZTh，少數要自己求。
  13. 共軛：(4 + j3)* = 4 − j3（實部照抄、虛部變號）
    在平面上就是上下翻面。Z + Z* = 2R，虛部一定消掉。11.3 會用到它。

看到「求阻抗／電流」的題目

  1. 從 cos(ωt) 抓出 ω（不是 f；ω = 2πf）。
  2. 每個元件換成阻抗：電阻 R、電感 jωL、電容 −j/(ωC)。
  3. 串聯直接加：實部加實部、虛部加虛部，得到 Z = R + jX。
  4. 看 X 的正負：正 → 電感性（電流落後）；負 → 電容性（電流超前）；0 → 純電阻。
  5. 算 |Z| 和 θ：|Z| = √(R² + X²)、θ = tan⁻¹(X/R)。
  6. 電流：大小 |I| = |V|/|Z|，角度 θi = θv − θ（除法 = 大小相除、角度相減）。
  7. 題目要你「從負載看電源」→ 先求 VTh（拔掉負載量開路電壓）和 ZTh（電源歸零往裡看）。

這幾個基本詞最常錯的地方

  • ✗ 4 + j3 Ω 就是 7 Ω。✓ 實部、虛部方向不同，不能直接加；總共擋 |Z| = 5 Ω。
  • ✗ 把 j 當成電流 i。✓ j 是虛數單位（數學課的 i），電路學因為 i 是電流才改叫 j。
  • ✗ 電容的阻抗寫成 jωC 或 1/(ωC)。✓ ZC = 1/(jωC) = −j/(ωC)：分母有 ωC，而且是負的 j。
  • ✗ |Z| = R（只看實部）。✓ |Z| = √(R² + X²)；只有算平均功率時才只用 R（P = ½|I|²R）。
  • ✗ 共軛把實部也變號：(4 + j3)* = −4 − j3。✓ 只有虛部變號：4 − j3。
  • ✗ ω 直接代 60。✓ 60 Hz 是 f，ω = 2π × 60 = 377 rad/s。

原講義 CH1111.3 · Maximum Average Power Transfer

最大平均功率轉移MAXIMUM AVERAGE POWER TRANSFER

擴大機接喇叭、天線接收音機：電源固定，負載要選多少，才能從電源拿到最多功率？直流時的答案是 RL = RTh。交流多了電抗，做法變成兩步：先用 XL 把 XTh 抵銷掉，再用 RL 去匹配 RTh。合起來叫共軛匹配conjugate matching。

ZL = ZTh*　（即 RL = RTh，XL = −XTh）　⟹　Pmax = |VTh|² / (8RTh)

先把電源化簡：戴維寧等效

  1. 不管電源那一側的電路多複雜，從負載兩端看進去，都可以換成一個電壓源 VTh 串一個阻抗 ZTh（）。

  2. VTh = 負載拿掉時的開路電壓　　ZTh = 電源歸零後從負載端看進去的阻抗
    電壓源歸零 = 短路、電流源歸零 = 開路。這是 CH10 的做法，到這裡直接拿來用。

為什麼是「共軛」而不是「相等」？

  1. I = VTh / (ZTh + ZL) = VTh / [(RTh+RL) + j(XTh+XL)]

    先寫出迴路電流：電源電壓除以總阻抗，電阻與電抗分開寫。

  2. P = ½|I|²RL = ½|VTh|²RL ÷ [(RTh+RL)² + (XTh+XL)²]
    負載只有 RL 會吃平均功率（上一節的結論）。取 |I|² 時，分母的複數變成「實部平方 + 虛部平方」。現在 P 是 RL 和 XL 兩個變數的函數，要找它的最大值。
  3. 先看 XL：它只出現在分母的 (XTh+XL)² 裡

    分母越小、P 越大。而 (XTh+XL)² 是平方，最小值就是 0。所以不必真的微分也看得出來：

    XL = −XTh　（電抗互相抵銷，電路變成純電阻）
  4. ∂P/∂RL = 0　⟹　RL = √[ RTh2 + (XTh+XL)² ]
    再對 RL 微分並令為零。這是通式，還沒代入上一步的結果（純電阻負載的題目會用到它）。
  5. 把 XL = −XTh 代進去 → 括號歸零 → RL = RTh

    兩個條件合起來寫成一個：ZL = RTh − jXTh = ZTh*。這就是的由來 —— 實部照抄、虛部變號。

  6. 匹配後：ZTh + ZL = 2RTh（虛部消失）　⟹　|I| = |VTh| / (2RTh)
    總阻抗只剩下 2RTh，是個純電阻。
  7. Pmax = ½|I|²RTh = ½ × |VTh|²/(4RTh2) × RTh = |VTh|² / (8RTh)

    那個 8 就是這樣來的：½（振幅轉平均）× 4（分母的 2 平方）= 8。若題目給的 VTh 是 rms 值，就沒有那個 ½，變成 |VTh|²/(4RTh)。

看到最大功率轉移題目

  1. 把負載拿掉，求開路電壓 VTh、從負載端看進去的 ZTh。
  2. 問：負載可不可以有電抗？可以 → ZL = ZTh*；只能純電阻 → RL = |ZTh|。這一步決定整題走向。
  3. 問：VTh 給的是振幅還是 rms？振幅 → Pmax = |VTh|²/(8RTh)；rms → Pmax = |VTh|²/(4RTh)。
  4. 只有共軛匹配那一種情況才能用 Pmax 的簡化公式；純電阻負載一律回頭算 I = VTh/(ZTh + RL)、P = ½|I|²RL。

最大功率轉移的坑

  • ✗ ZL = ZTh（照直流的經驗直接相等）。✓ 虛部要變號：ZL = ZTh*。相等的話電抗會疊加、電流反而變小。
  • ✗ 純電阻負載還寫 RL = RTh。✓ 電抗抵銷不掉時，RL = |ZTh|。
  • ✗ 純電阻負載也套 |VTh|²/(8RTh)。✓ 這條只在共軛匹配時成立，其他情況回去算電流。
  • ✗ 求 ZTh 時電壓源沒有短路、電流源沒有開路。✓ 獨立電源先歸零再看進去。
