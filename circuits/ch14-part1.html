課本 CH1414.1–14.2 · Transfer Function

轉移函數TRANSFER FUNCTION

輸入的弦波大小固定、改變頻率，看輸出怎麼變，就是頻率響應。把它寫成一個函數：H(ω) = 輸出相量 ÷ 輸入相量。寫成分子 ÷ 分母後，分子的根叫零點（H = 0）、分母的根叫極點（H → ∞）。

H(ω) = Y(ω)/X(ω) = N(ω)/D(ω)　·　電壓增益 Vo/Vi、電流增益 Io/Ii、轉移阻抗 Vo/Ii、轉移導納 Io/Vi　·　N = 0 → 零點、D = 0 → 極點

Example 14.1：RC 電路的頻率響應

  1. H(ω) = (1/jωC)/(R + 1/jωC)
    換成頻域，輸出在電容上，分壓。
  2. = 1/(1 + jωRC) = 1/(1 + jω/ω0)，ω0 = 1/RC
    分子分母同乘 jωC。
  3. H = 1/√(1 + (ω/ω0)2)、φ = −tan−1(ω/ω0)
    複數的大小、角度（式 9.18e）。
  4. ω = 0：1、0°；ω = ω0：0.707、−45°；ω → ∞：0、−90°

    低頻通過、高頻擋掉：低通。RL 電路輸出在 L 上（Practice 14.1）剛好相反：高通。

零點與極點（Example 14.2）

  1. Io = (4 + j2ω)/(4 + j2ω + 1/j0.5ω) · Ii
    分流：Io 走電容，比例 = 另一支 ÷ 總和。
  2. 令 s = jω：Io/Ii = s(s + 2)/(s2 + 2s + 1)
    暫時把 jω 換成 s，避免複數代數；分子分母同乘 j0.5ω。
  3. 零點：s(s + 2) = 0 ⟹ 0、−2；極點：(s + 1)2 = 0 ⟹ −1（二重）

    零點讓 H = 0、極點讓 H → ∞。14.4 波德圖就是用零點、極點一段一段畫。

轉移函數題的標準流程

  1. 看要哪一種：輸出、輸入分別是電壓還是電流（電壓增益、電流增益、轉移阻抗、轉移導納）。
  2. 換成頻域：R、jωL、1/jωC；為了好算，直接寫 sL、1/sC。
  3. 用分壓、分流（或網目、節點）求出輸出 ÷ 輸入。
  4. 整理成 N(s)/D(s)：分子分母同乘，讓兩邊都是多項式，約分到最簡。
  5. 零點、極點：N = 0、D = 0 的根。要頻率響應就代 s = jω，求大小和相位。

轉移函數的坑

  • ✗ H = 輸入 ÷ 輸出。✓ 輸出 ÷ 輸入。
  • ✗ 零點、極點搞反。✓ 分子（零點）→ H = 0；分母（極點）→ H = ∞。
  • ✗ 沒約分就找零點極點。✓ 課本式 14.3：先把共同因式約掉。
  • ✗ 相位只寫分子的角度。✓ φ = 分子角度 − 分母角度（RL：90° − tan−1(ω/ω0)）。

課本 CH1414.3 · The Decibel Scale

分貝刻度THE DECIBEL SCALE

頻率響應的數字常常差好幾個數量級，用對數比較好畫、好比較，而且串接時乘法變加法。功率比用 10 log，電壓、電流比用 20 log（因為功率跟電壓平方成正比）。

G = log10(P2/P1)（貝爾）　·　GdB = 10 log10(P2/P1)　·　GdB = 20 log10(V2/V1) = 20 log10(I2/I1)

為什麼電壓要乘 20

  1. GdB = 10 log10(P2/P1)
    分貝是貝爾的 1/10（式 14.5）。
  2. P1 = V12/R1、P2 = V22/R2
    課本圖 14.8：輸入電阻 R1、負載 R2（同一個 0.5 係數會約掉）。
  3. GdB = 20 log10(V2/V1) − 10 log10(R2/R1)
    log 的性質：平方提到前面變 2 倍、相除變相減（式 14.9）。
  4. R1 = R2 ⟹ GdB = 20 log10(V2/V1)

    電流同理。分貝是「同一種量」的比，所以用在電壓增益、電流增益，不直接用在轉移阻抗、導納。

幾個一定要記的值

  1. P2 = 2P1 ⟹ 10 log 2 ≈ 3 dB；P2 = 0.5P1 ⟹ ≈ −3 dB
    倒數的對數 = 負的對數（式 14.6、14.7）。
  2. 電壓 ×10 = 20 dB、×100 = 40 dB、×1 = 0 dB
    20 log 10 = 20。
  3. 電壓 × 1/√2（0.707）= −3 dB

    就是 Example 14.1 的 ω0：功率剛好剩一半。

分貝題的標準流程

  1. 先分清楚是功率比（× 10）還是電壓、電流比（× 20）。
  2. 倍數 → dB：GdB = 20 log10|H|（電壓）。
  3. dB → 倍數：|H| = 10HdB/20（Problem 14.7）。
  4. 串接：總 dB = 各級 dB 相加。

分貝的坑

  • ✗ 電壓比也用 10 log。✓ 電壓、電流用 20 log；功率才用 10 log。
  • ✗ 負的 dB 以為是負的增益（輸出反相）。✓ 負 dB 只是比 1 小（衰減），跟相位無關。
  • ✗ −3 dB 當成電壓剩一半。✓ −3 dB 是功率剩一半、電壓剩 0.707；電壓剩一半是 −6 dB。
