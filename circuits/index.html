交流功率分析

整章只在回答一個問題：交流電路裡，功率到底跑去哪了？有一部分被電阻真的吃掉（實功率 P），另一部分只是在電源與電感電容之間來回擺盪（虛功率 Q）。8 個模組把這件事從波形一路帶到電費單。

整章的核心關係式只有一條：S = P + jQ。其他所有公式都是它的變形。先把功率三角形畫熟，這章的計算題就解了一半。

11.2 · Instantaneous and Average Power

瞬時功率與平均功率

瞬時功率instantaneous power p(t) = v(t)·i(t) 是「某一瞬間」吸收功率的速率。把它展開會發現它由一個固定值加上一個以 2ω 擺盪的弦波組成 —— 那個固定值就是平均功率average power P。

p(t) = ½VmIm cos(θv − θi)  +  ½VmIm cos(2ωt + θv + θi)

左半是常數（不隨時間變），右半是弦波，取一週期平均後為零。所以 P = ½VmIm cos(θv − θi)。注意 p(t) 的頻率是電壓的兩倍，週期 T₀ = T/2。

11.3 · Maximum Average Power Transfer

最大平均功率轉移

直流時的結論是 RL = RTh。交流時要多考慮電抗：先用 XL 把 XTh 抵銷掉，再用 RL 去匹配 RTh。合起來就是共軛匹配conjugate matching。

11.4 · Effective or RMS Value

有效值（均方根值 rms）

為什麼台灣市電叫「110 V」但波峰其實有 155 V？因為那個 110 是有效值effective value：能對同一個電阻送出相同平均功率的那個等效直流值。名字 root-mean-square 就是它的算法，倒著唸即可。

Xrms = √( (1/T) ∫₀ᵀ x²(t) dt )　←　先平方 square、再平均 mean、最後開根號 root

Vm/√2 只對弦波成立。方波的 rms 就是 Vm、三角波與鋸齒波是 Vm/√3。考試若給非弦波卻照套 √2，就會錯。

有了 rms，交流的功率公式就跟直流長得一樣：P = I²rmsR = VrmsIrmscos(θv−θi)。這正是發明有效值的目的。

記憶法：電流落後 → 電感性 → lagging（馬達、冷氣）；電流超前 → 電容性 → leading。功率因數角 θv−θi 也等於負載阻抗的角度。

11.6 · Complex Power

複功率與功率三角形

複功率complex power S 把這章所有資訊包成一個複數：實部是 P、虛部是 Q、大小是視在功率、相角的餘弦是功率因數。一個 S 在手，四個量全有。

S = Vrms·I*rms = P + jQ　　|S| = √(P² + Q²)　　S = I²rmsZ = V²rms/Z*

注意那個星號。必須取電流的共軛 I*，角度才會是 θv − θi。不取共軛會變成 θv + θi，整題就毀了。

Q 的三種情況：Q = 0 純電阻（單位功因）；Q < 0 電容性（超前）；Q > 0 電感性（落後）。功率三角形跟阻抗三角形（Z, R, X）長得一模一樣，因為 S = I²rmsZ。

11.7 · Conservation of AC Power

交流功率守恆

不管負載是串聯還是並聯，電源送出的複功率 = 各負載吸收的複功率總和。但這裡藏著這一章最常被扣分的地方。

P 可以直接加、Q 可以直接加，視在功率 S 不可以直接加。正確做法永遠是：先各自加總 P 與 Q，最後才 |S| = √(P總² + Q總²)。

11.8 · Power Factor Correction

功率因數校正

工廠的馬達幾乎都是電感性、功因偏低。功因校正power factor correction就是在負載旁並聯一顆電容，用電容的 −Q 去抵銷電感的 +Q，讓功因接近 1。P 完全不變，但線電流會變小。

QC = Q₁ − Q₂ = P(tan θ₁ − tan θ₂)　　C = QC / (ω·V²rms)

為什麼要做？電力公司對大電流收費更高，因為線損 I²R 是平方成長。功因從 0.8 拉到 0.95，同樣的 P 下線電流可以少掉約 16%，線損少掉約 29%。

若負載本來就是電容性（超前功因），要並聯的就換成電感，公式改成 L = V²rms / (ω·QL)。

11.9 · Applications

應用：功率量測與電費

三種儀器對應三種功率：瓦特計wattmeter量 P、乏計varmeter量 Q、電表kilowatt-hour meter量用電度數。

電流線圈 current coil阻抗極低（理想為 0）→ 串聯在負載上
電壓線圈 voltage coil阻抗極高（理想為 ∞）→ 並聯在負載兩端
讀數P = |Vrms||Irms| cos(θv − θi)

因為電流線圈像短路、電壓線圈像開路，接上瓦特計不會干擾原電路，量到的才是真正的功率。
