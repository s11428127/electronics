交流功率分析

整章只在回答一個問題：交流電路裡，功率到底跑去哪了？有一部分被電阻真的吃掉（ P），另一部分只是在電源與電感電容之間來回擺盪（ Q）。8 個模組把這件事從波形一路帶到電費單。

整章的核心關係式只有一條：S = P + jQ。其他所有公式都是它的變形。先把功率三角形畫熟，這章的計算題就解了一半。

整章公式是怎麼串起來的

這章不是十幾條獨立公式，而是一條線推下來的。看懂這個順序，就不用硬背。

從「電壓乘電流」到「電費單」

  1. p(t) = v·i　→　積化和差　→　常數項 + 2ω 擺盪項
    11.2 發現功率天生就分成兩塊：一塊不動、一塊純擺盪。
  2. 取一週期平均 → 擺盪項歸零 → P = ½VmImcos(θv−θi)
    11.2 那個「不動的一塊」就是平均功率 P。
  3. 定義 rms（能送出等量功率的等效直流）→ Vrms = Vm/√2
    11.4 為了甩掉那個礙眼的 ½，讓公式長得像直流。
  4. P = VrmsIrmscos(θv−θi) = S × pf
    11.5 把乘積拆成兩半各自命名：S 是、pf 是折扣率。
  5. 想把 P 變成某個複數的實部 → S = VrmsI*rms = P + jQ
    11.6 順手掉出虛部 Q，四個量一次到齊 —— 這是全章的制高點。
  6. KCL / KVL + 共軛的分配律 → S總 = ΣSi
    11.7 因為 S 是向量，所以 P、Q 可加，但 |S| 不可加。
  7. 用電容的 −Q 抵銷電感的 +Q → C = P(tanθ₁−tanθ₂)/(ωV²rms)
    11.8 Q 變小 → S 變小 → 線電流變小 → 線損 I²R 變小 → 電費變少。

拿到任何一題交流功率，先做這三件事

  1. 統一單位：振幅還是 rms？這是最常見的失分點。看到 v(t) = Vmcos(…) 就是振幅，要除 √2；電力題目講「120 V 電源」預設就是 rms。決定之後，公式該不該帶 ½ 就確定了。
  2. 把每個負載化成一對 (P, Q)。不管題目給的是 pf、阻抗、還是 S 和角度，先轉成 P 和 Q。
    Q = P·tanθ　P = S·cosθ　Q = S·sinθ　P = I²rms·R　Q = I²rms·X
  3. 確認 Q 的符號。電感性（落後 lagging）+、電容性（超前 leading）−。符號一錯，後面全錯。
11.2 · Instantaneous and Average Power

瞬時功率與平均功率

瞬時功率instantaneous power p(t) = v(t)·i(t) 是「某一瞬間」吸收功率的速率。把它展開會發現它由一個固定值加上一個以 2ω 擺盪的弦波組成 —— 那個固定值就是平均功率average power P。

p(t) = ½VmIm cos(θv − θi)  +  ½VmIm cos(2ωt + θv + θi)

這條式子是怎麼來的？

  1. p(t) = v(t)·i(t) = Vmcos(ωt+θv) × Imcos(ωt+θi)

    功率的定義就是「電壓 × 電流」。兩個都是弦波，所以現在卡在一個「cos 乘 cos」。

  2. cos A · cos B = ½[ cos(A−B) + cos(A+B) ]
    用積化和差把乘法拆成加法。令 A = ωt+θv、B = ωt+θi，那麼：
    A − B = θv − θi（ωt 消掉了，變成常數！）
    A + B = 2ωt + θv + θi（ωt 變兩倍）
  3. p(t) = ½VmImcos(θv−θi) + ½VmImcos(2ωt+θv+θi)

    代進去就得到兩項。左項完全沒有 t（是個定值），右項是 2ω 的弦波。整章的故事到這裡就定調了。

  4. P = (1/T)∫₀ᵀ p(t) dt
    平均功率的定義：把 p(t) 在一個週期內積分再除以週期。接著逐項處理。
  5. 第一項：常數的平均 = 它自己 → 保留
    第二項：弦波一週期的平均 = 0 → 消失

    弦波在正半週的面積，剛好被下一個負半週抵銷掉，所以積分為零。這就是為什麼「會擺盪的那一半不算進平均功率」。

  6. P = ½VmIm cos(θv − θi)

    剩下的就是答案。注意 cos(θv−θi) = cos(θi−θv)，所以只有相位差的大小重要，誰減誰不影響。

順帶一提，用相量也能算：½V·I* = ½VmIm∠(θv−θi) = ½VmIm[cos(θv−θi) + j·sin(θv−θi)]，取實部就是 P。所以 P = ½Re[V·I*] —— 這條在 11.6 會變成複功率的起點。

例題 · 直接套公式

已知 v(t) = 120 cos(377t + 45°) V、i(t) = 10 cos(377t − 10°) A，求負載吸收的平均功率 P。

  1. Step 1　抓出四個數字。Vm = 120、Im = 10、θv = 45°、θi = −10°。
  2. Step 2　算相位差。 θv − θi = 45° − (−10°) = 55° 負的減負的，別漏掉那個負號 —— 這是最容易算錯的一步。
  3. Step 3　代公式。 P = ½ × 120 × 10 × cos(55°) = 600 × 0.5736

P = 344.2 W（θv−θi = 55° > 0 → 電流落後 → 電感性負載）

例題 · 為什麼電感的平均功率是 0

純電感負載，電流落後電壓 90°。用同一條公式驗證 P = 0。

  1. Step 1　θv − θi = +90°。
  2. Step 2　P = ½VmIm cos(90°) = ½VmIm × 0 = 0
  3. Step 3　物理意義。此時 p(t) = ½VmImcos(2ωt + θv + θi)，只剩下純擺盪項。前半週電感把能量存進磁場（p > 0），後半週原封不動吐回電源（p < 0），正負面積完全相等，淨消耗為零。

P = 0 W（上面的動畫按「純電感」就能看到正負面積對稱）

這一節最常被扣分的地方

  • ✗ 忘記那個 ½。公式是 P = ½VmImcos θ，用的是振幅。若題目給的已經是 rms 值，才是 P = VrmsIrmscos θ（沒有 ½）。先看清楚題目給的是振幅還是 rms。
  • ✗ 題目給 sin 卻直接當成 cos 代入。要先轉成 cos：sin(x) = cos(x − 90°)轉完再讀相角。

11.3 · Maximum Average Power Transfer

最大平均功率轉移

直流時的結論是 RL = RTh。交流時要多考慮電抗：先用 XL 把 XTh 抵銷掉，再用 RL 去匹配 RTh。合起來就是共軛匹配conjugate matching。

ZL = ZTh*　（即 RL = RTh，XL = −XTh）　⟹　Pmax = |VTh|² / (8RTh)

為什麼是「共軛」而不是「相等」？

  1. I = VTh / (ZTh + ZL) = VTh / [(RTh+RL) + j(XTh+XL)]

    先寫出迴路電流：電源電壓除以總阻抗，電阻與電抗分開寫。

  2. P = ½|I|²RL = ½|VTh|²RL ÷ [(RTh+RL)² + (XTh+XL)²]
    負載吸收的平均功率。取 |I|² 時，分母的複數變成「實部平方 + 虛部平方」。現在 P 是 RL 和 XL 兩個變數的函數，要找它的極大值。
  3. 先看 XL：它只出現在分母的 (XTh+XL)² 裡

    分母越小、P 越大。而 (XTh+XL)² 是平方，最小值就是 0。所以不必真的微分也看得出來：

    XL = −XTh　（電抗互相抵銷，電路變成純電阻）
  4. ∂P/∂RL = 0　⟹　RL = √[ R²Th + (XTh+XL)² ]
    再對 RL 微分並令為零。這是通式，還沒代入上一步的結果。
  5. 把 XL = −XTh 代進去 → 括號歸零 → RL = √(R²Th) = RTh

    兩個條件合起來寫成一個：ZL = RTh − jXTh = ZTh*。這就是「共軛」的由來 —— 實部照抄、虛部變號。

  6. 匹配後：ZTh + ZL = (RTh+RTh) + j(XTh−XTh) = 2RTh
    ⟹ |I| = |VTh| / (2RTh)
    虛部完全消失，總阻抗只剩下 2RTh，是個純電阻。
  7. Pmax = ½|I|²RTh = ½ × |VTh|²/(4R²Th) × RTh = |VTh|² / (8RTh)

    那個 8 就是這樣來的：½（振幅轉平均）× 4（分母的 2 平方）= 8。若題目給的 VTh 是 rms 值，就沒有那個 ½，變成 |VTh|²/(4RTh)。

例題 · 標準共軛匹配

某電路的戴維寧等效為 VTh = 10∠0° V（振幅）、ZTh = 4 + j3 Ω。求可取得最大功率的 ZL 與該最大功率。

  1. Step 1　取共軛。實部不動、虛部變號： ZL = ZTh* = 4 − j3 Ω
  2. Step 2　確認虛部真的抵銷。 ZTh + ZL = (4+4) + j(3−3) = 8 Ω（純電阻）
  3. Step 3　套 Pmax 公式。 Pmax = |VTh|²/(8RTh) = 10²/(8×4) = 100/32

ZL = 4 − j3 Ω，Pmax = 3.125 W

例題 · 陷阱題：負載限定純電阻

同樣 ZTh = 4 + j3 Ω、VTh = 10 V（振幅），但題目規定負載只能是一個電阻 RL。求 RL 與此時的 P。

  1. Step 1　注意條件變了。XL 被強制為 0，虛部無法抵銷，所以不能用 RL = RTh。
  2. Step 2　回到通式。把 XL = 0 代入推導第 4 步： RL = √[R²Th + (XTh+0)²] = √(R²Th + X²Th) = |ZTh|
  3. Step 3　算出數值。 RL = √(4² + 3²) = √25 = 5 Ω
  4. Step 4　代回 P 的原式（不能用 Pmax 公式，因為沒有共軛匹配）： P = ½ × 10² × 5 ÷ [(4+5)² + 3²] = 250 ÷ (81+9) = 250/90

RL = 5 Ω，P = 2.78 W（比共軛匹配的 3.125 W 少，合理）

看到最大功率轉移題目

  1. 先問：負載可不可以有電抗？可以 → ZL = ZTh*；只能純電阻 → RL = |ZTh|。這一步決定整題走向。
  2. 再問：VTh 給的是振幅還是 rms？振幅 → Pmax = |VTh|²/(8RTh)；rms → Pmax = |VTh|²/(4RTh)。
  3. 若題目給的是原始電路而不是戴維寧等效，先把負載拿掉，求開路電壓 VTh 與從負載端看進去的 ZTh。
  4. 只有共軛匹配那一種情況才能用 Pmax 的簡化公式；其他情況一律回頭代 P = ½|I|²RL。

11.4 · Effective or RMS Value

（均方根值 rms）

為什麼台灣市電叫「110 V」但波峰其實有 155 V？因為那個 110 是有效值effective value：能對同一個電阻送出相同平均功率的那個等效直流值。名字 root-mean-square 就是它的算法，倒著唸即可。

Xrms = √( (1/T) ∫₀ᵀ x²(t) dt )　←　先平方 square、再平均 mean、最後開根號 root

有效值是怎麼被「定義」出來的

  1. 先設定情境。兩個電路：一個接交流 i(t)、一個接直流 Ieff，負載都是同一個電阻 R。問：Ieff 要多大，才能讓兩邊發出一樣多的熱？

  2. 交流側：P = (1/T)∫₀ᵀ i²R dt = (R/T)∫₀ᵀ i² dt
    電阻的瞬時功率是 i²R，取一週期平均。R 是常數可以提到積分外面。
  3. 直流側：P = I²eff R
    直流不隨時間變，功率就是 I²R，不用積分。
  4. 令兩者相等：I²eff R = (R/T)∫₀ᵀ i² dt

    R 兩邊消掉，剩下 I²eff = (1/T)∫i² dt，再開根號：

    Ieff = √( (1/T)∫₀ᵀ i² dt ) ≡ Irms

    倒著唸就是這條式子的英文名字：root（根號）→ mean（1/T 積分取平均）→ square（i²）。

弦波的 √2 是怎麼掉出來的

  1. i(t) = Im cos ωt　⟹　Irms = √( (1/T)∫₀ᵀ I²mcos²ωt dt )

    直接把弦波代進定義式。卡住的地方是 cos² 不好積。

  2. cos²x = ½(1 + cos 2x)
    用半角（降冪）公式把平方拆掉。這一步是關鍵：cos² 積不動，但 ½ + ½cos2x 就很好積。
  3. Irms = √( (I²m/T)∫₀ᵀ ½(1 + cos 2ωt) dt )

    括號裡有兩塊：常數 ½ 的平均還是 ½；cos2ωt 是弦波，一週期平均為 0（跟 11.2 用的是同一個道理）。

  4. Irms = √( I²m × ½ ) = Im/√2 ≈ 0.707 Im

    所以 √2 的來源就是那個 ½，而 ½ 來自 cos² 的降冪公式。換一種波形，這個 ½ 就會變成別的數，√2 自然不成立。

有了 rms，功率公式為什麼變乾淨了

  1. P = ½VmImcos(θv−θi)
    這是 11.2 推出來的結果，用的是振幅，前面拖著一個礙眼的 ½。
  2. 把 ½ 拆成 (1/√2)(1/√2)，各自配給 Vm 和 Im：
    P = (Vm/√2)(Im/√2)cos(θv−θi)
  3. P = Vrms Irms cos(θv − θi)

    ½ 消失了，長得跟直流的 P = VI 幾乎一樣 —— 這正是當初發明有效值的目的。後面 11.5、11.6 的所有公式都是建立在 rms 上，所以電力工程講電壓電流時，預設就是 rms（台電的 110 V、220 V 都是 rms）。

例題 · 非弦波的 rms（方波）

一個振幅 Vm = 10 V 的方波，求它的 rms 值。

  1. Step 1　千萬別套 √2。先回到定義式，不要背公式。
  2. Step 2　平方看看。方波的值只有 +10 和 −10 兩種，平方後全部都是 100，變成一條水平線。
  3. Step 3　取平均。常數 100 的平均還是 100。 (1/T)∫₀ᵀ 100 dt = 100
  4. Step 4　開根號。 Vrms = √100 = 10 = Vm

Vrms = 10 V = Vm（方波的 rms 就是振幅本身，沒有任何折扣）

例題 · 三角波 / 鋸齒波

振幅 Vm 的鋸齒波，求 Vrms。

  1. Step 1　在一個週期內寫成 v(t) = Vm·(2t/T − 1)，或更簡單地取上升段 v = Vmt/T（t: 0→T）做單邊計算。
  2. Step 2　平方再積分。 (1/T)∫₀ᵀ (Vmt/T)² dt = (V²m/T³)∫₀ᵀ t² dt = (V²m/T³)(T³/3) = V²m/3 關鍵在 ∫t² dt = t³/3，那個 3 就是 √3 的來源。
  3. Step 3　開根號。 Vrms = √(V²m/3) = Vm/√3 ≈ 0.577 Vm

Vrms = Vm/√3 ≈ 0.577 Vm（三角波同理，也是 √3）

看到 rms 題目

  1. 先判斷波形。是純弦波嗎？是 → 直接用 Vm/√2。不是 → 回定義式老實做三步驟。
  2. 波形是分段的（例如半波整流、脈衝），把一個週期切成幾段分別積分再相加，分母的 T 是完整週期，不是那一段的長度。
  3. 含直流偏壓的波形（VDC + 弦波）用：Vrms = √(V²DC + V²ac,rms)，兩部分的「平方」可以相加，但 rms 本身不能直接相加。
  4. 算完永遠檢查一下：rms 一定介於 0 和波峰值之間。算出比振幅還大就是錯了。

11.5 · Apparent Power and Power Factor

視在功率與功率因數

把 Vrms 乘上 Irms「看起來」就該是功率，所以叫視在功率apparent power S，單位是 VA。但真正被消耗的只有 S 的一部分，那個折扣率就是功率因數power factor。

S = VrmsIrms (VA)　　pf = P/S = cos(θv − θi)　　P = S·pf (W)

S 和 pf 是怎麼被「拆」出來的

  1. P = Vrms Irms cos(θv − θi)
    從 11.4 的結果出發。注意這是兩個東西的乘積：一個是 VrmsIrms、一個是 cos(θv−θi)。
  2. S ≡ Vrms Irms　　pf ≡ cos(θv − θi)

    把它們各自取名字：前者叫視在功率、後者叫功率因數。於是 P = S × pf，也就是 pf = P/S。

  3. 為什麼叫「視在」？因為在直流電路，功率就是電壓乘電流。到了交流，VrmsIrms「看起來」也該是功率 —— 但實際上不是，真正被消耗的只有 P。所以它叫 apparent（表面上的），而且刻意用 VA 而不是 W當單位，就是為了提醒你「這不是真的瓦特」。

  4. Z = V/I = (Vm∠θv)/(Im∠θi) = (Vm/Im)∠(θv − θi)
    複數相除：大小相除、角度相減。而相減出來的角度，剛好就是功因角。
  5. 阻抗 Z 的角度　＝　功率因數角 (θv − θi)

    這條在解題時超好用：題目只給你 Z，你就已經知道 pf 了，不必真的去算 v(t) 和 i(t) 的相位。例如 Z = 20 + j20 → 角度 45° → pf = cos45° = 0.707 落後。

例題 · 從阻抗直接讀出功率因數

負載 Z = 20 − j20 Ω，接上 Vrms = 120 V。求 pf、S、P。

  1. Step 1　算阻抗角。 θ = arctan(X/R) = arctan(−20/20) = arctan(−1) = −45°
  2. Step 2　pf 就是它的 cos。 pf = cos(−45°) = 0.707 X 是負的 → 電容性 → 電流超前電壓 → leading。
  3. Step 3　算電流。 |Z| = √(20² + 20²) = 28.28 Ω　⟹　Irms = 120/28.28 = 4.243 A
  4. Step 4　視在功率與。 S = 120 × 4.243 = 509.1 VA
    P = S × pf = 509.1 × 0.707 = 360 W     也可以直接驗算：P = I²rmsR = 4.243² × 20 = 360 W ✓

pf = 0.707 超前（leading），S = 509.1 VA，P = 360 W

落後 / 超前最容易搞混

  • 記憶口訣：看電流相對於電壓。電流落在後面 → lagging（電感性，X > 0，Q > 0）；電流跑在前面 → leading（電容性，X < 0，Q < 0）。
  • ✗ 只寫「pf = 0.8」。一定要註明 lagging 或 leading，因為 cos(+36.87°) 和 cos(−36.87°) 都是 0.8，但一個是電感性、一個是電容性，後面算 Q 和做功因校正時會完全相反。
  • ✗ 把 pf 算成大於 1。pf = cos(角度)，範圍永遠是 0 到 1。算出 1.2 就是 P 和 S 弄反了。
  • 電感「ELI」、電容「ICE」：ELI → 電感(L)中電壓(E)領先電流(I)；ICE → 電容(C)中電流(I)領先電壓(E)。這是英文系教科書的標準口訣，考卷上很好用。

11.6 · Complex Power

複功率與功率三角形

複功率complex power S 把這章所有資訊包成一個複數：實部是 P、虛部是 Q、大小是視在功率、相角的餘弦是功率因數。一個 S 在手，四個量全有。

S = Vrms·I*rms = P + jQ　　|S| = √(P² + Q²)　　S = I²rmsZ = V²rms/Z*

為什麼是 V·I*（而不是 V·I）

  1. 我們想要一個複數，它的實部剛好是 P。
    因為 P = VrmsIrmscos(θv−θi)，而複數的實部長得就是「大小 × cos(角度)」。所以只要湊出一個「大小 = VrmsIrms、角度 = θv−θi」的複數就行。
  2. 若用 V·I：　Vrms∠θv × Irms∠θi = VrmsIrms∠(θv + θi)　✗

    複數相乘是角度相加，得到 θv + θi —— 這不是我們要的角度，實部也就不是 P。

  3. 若用 V·I*：　I* = Irms∠(−θi)
    Vrms∠θv × Irms∠(−θi) = VrmsIrms∠(θv − θi)　✓

    取共軛就是把角度變號，於是相乘時「加上一個負角度」＝「相減」。這就是那個星號存在的唯一理由。

  4. S = VrmsI*rms = VrmsIrmscos(θv−θi) + j·VrmsIrmssin(θv−θi)

    把極座標展開成直角座標（歐拉公式）。實部正是 P，虛部則是一個新東西。

  5. S = P + jQ　，其中 Q ≡ VrmsIrmssin(θv−θi)

    虛部取名叫虛功率（reactive power）Q，單位 VAR。它衡量的是「能量在電源與電感電容之間來回搬運的規模」—— 不被消耗，但真實存在、真的會佔用線路容量。

另外兩條常用型：S = I²Z 與 S = V²/Z*

  1. 由 Z = Vrms/Irms 得 Vrms = Z·Irms
    歐姆定律的相量版本，把 V 用 Z 和 I 表示。
  2. S = VrmsI*rms = (Z Irms)(I*rms) = Z·|Irms|²

    因為 I·I* = |I|²（複數乘自己的共軛 = 大小平方，必為實數）。

  3. S = I²rms(R + jX) = I²rmsR + j·I²rmsX

    對照 S = P + jQ 立刻得到兩條超實用的公式：

    P = I²rmsR　（只跟電阻有關）
    Q = I²rmsX　（只跟電抗有關）
    這解釋了為什麼電阻決定 P、電抗決定 Q。也直接證明純電感（R = 0）的 P = 0。
  4. 同理，由 Irms = Vrms/Z 代入：
    S = Vrms(Vrms/Z)* = V²rms/Z*

    分母要取 Z*，不是 Z —— 又是共軛，理由同上。

四個量一次到手。拿到 S = P + jQ 之後：實部 = P、虛部 = Q、大小 |S| = √(P²+Q²) = 視在功率、相角的 cos = 功率因數。這就是課本說「複功率包含了負載的所有功率資訊」的意思。

例題 · 完整走一遍複功率

Vrms = 100∠30° V，Irms = 5∠−10° A。求 S、P、Q、|S|、pf，並判斷負載性質。

  1. Step 1　取電流共軛。角度變號： I*rms = 5∠+10° A
  2. Step 2　相乘（大小相乘、角度相加）。 S = 100∠30° × 5∠10° = 500∠40° VA 注意這個 40° 就是 θv − θi = 30° − (−10°) = 40° ✓
  3. Step 3　化成直角座標。 P = 500 cos40° = 500 × 0.766 = 383.0 W
    Q = 500 sin40° = 500 × 0.643 = 321.4 VAR
  4. Step 4　讀出其餘的量。 |S| = 500 VA（就是相量的大小）
    pf = cos40° = 0.766
  5. Step 5　判性質。Q > 0 且 θ > 0 → 電流落後電壓 → 電感性、pf 落後。

S = 383 + j321.4 VA = 500∠40° VA；pf = 0.766 落後（lagging）

複功率題目的通用流程

  1. 先統一成 rms。題目若給振幅，先除以 √2；給 v(t)/i(t) 時間式，先轉成相量。
  2. 看題目給什麼，選對公式：給 V 和 I → S = V·I*；給 I 和 Z → S = I²rms·Z；給 V 和 Z → S = V²rms/Z*。三條算出來一定一樣，挑最少步驟的那條。
  3. 算出 S 之後不要停。P、Q、|S|、pf、負載性質這五個量通常題目會一起問，而它們全都可以從 S 直接讀出來。
  4. 檢查符號：Q 的正負要跟負載性質一致（電感 +、電容 −）。不一致就是共軛取錯了。

複功率的三個坑

  • ✗ 忘記取共軛，算成 V·I。角度會從 θv−θi 變成 θv+θi，P 和 Q 全錯。
  • ✗ 用 S = V²/Z 而不是 V²/Z*。分母那個共軛一樣不能少。
  • ✗ 把振幅當 rms 直接乘。S = V·I* 這條式子的 V、I 必須是 rms。如果手上是振幅，要嘛先除 √2，要嘛用 S = ½VmI*m（補上那個 ½）。

11.7 · Conservation of AC Power

交流功率守恆

不管負載是串聯還是並聯，電源送出的複功率 = 各負載吸收的複功率總和。但這裡藏著這一章最常被扣分的地方。

S = S₁ + S₂ + ⋯ + SN　　P = ΣPi　　Q = ΣQi　　但 |S| ≠ Σ|Si|

並聯：為什麼複功率可以直接相加

  1. KCL：I = I₁ + I₂
    並聯的話，各負載電壓相同、電流相加。這是唯一用到的電路定律。
  2. 取共軛：I* = (I₁ + I₂)* = I₁* + I₂*

    共軛運算對加法是可分配的（(a+b)* = a* + b*），所以可以逐項取。

  3. S = V·I* = V(I₁* + I₂*) = V·I₁* + V·I₂*
    把 V 乘進去分配。而 V·I₁* 正是負載 1 的複功率 S₁（因為並聯時它兩端的電壓就是 V）。
  4. S = S₁ + S₂

    證畢。推廣到 N 個負載完全一樣。

串聯：換一個定律，結論一樣

  1. KVL：V = V₁ + V₂
    串聯的話，各負載電流相同、電壓相加。
  2. S = V·I* = (V₁ + V₂)I* = V₁I* + V₂I*
  3. S = S₁ + S₂

    所以不管串聯並聯，複功率永遠可以直接相加。這就是「交流功率守恆」：電源送出的，等於所有負載吸收的總和。

那為什麼視在功率 S 不能直接加？

  1. 因為 S（複功率）是向量，|S|（視在功率）是長度。可以相加的是向量，不是長度。

  2. S = S₁ + S₂ = (P₁ + jQ₁) + (P₂ + jQ₂) = (P₁+P₂) + j(Q₁+Q₂)

    向量相加 = 實部各自加、虛部各自加。所以 P 可以加、Q 可以加（它們是分量）。

  3. |S| = √[ (ΣP)² + (ΣQ)² ]　　≠　　Σ√(Pi² + Qi²)
    這就像三角形的兩邊之和大於第三邊：把兩個方向不同的向量接起來，合成向量的長度會短於兩段長度相加。只有當所有 Si 方向完全相同（功因角都一樣）時，兩者才會相等。
例題 · 親手算一次這個陷阱

兩個負載並聯：負載 1：P₁ = 600 W、Q₁ = +800 VAR（電感性）；負載 2：P₂ = 900 W、Q₂ = −400 VAR（電容性）。求總視在功率與總功因數。

  1. Step 1　P 直接加。 P總 = 600 + 900 = 1500 W
  2. Step 2　Q 直接加（連符號一起加）。 Q總 = (+800) + (−400) = +400 VAR 電容的 −400 把電感的 +800 抵銷掉一部分 —— 這其實就是功因校正的原理。
  3. Step 3　最後才取大小。 |S總| = √(1500² + 400²) = √(2,250,000 + 160,000) = √2,410,000 = 1552.4 VA
  4. Step 4　對照錯誤做法。 |S₁| = √(600²+800²) = 1000 VA　|S₂| = √(900²+400²) = 985.0 VA
    Σ|Si| = 1985.0 VA　✗ 差了 432.6 VA
  5. Step 5　總功因數。 pf = P總/|S總| = 1500/1552.4 = 0.966（Q總 > 0 → 落後）

|S總| = 1552.4 VA，pf = 0.966 落後（不是 1985 VA！）

多負載題目的標準流程

  1. 把每個負載都換算成 Pi 和 Qi。題目可能給 pf、給阻抗、給 S 和角度 —— 通通先轉成一對 (P, Q)。
    給 P 和 pf → Q = P·tanθ；給 S 和 pf → P = S·pf、Q = S·sinθ。
  2. Q 的符號一定要對。電感性（lagging）取 +，電容性（leading）取 −。符號錯了整題就錯。
  3. 分別加總得到 P總、Q總。
  4. 最後才合成：|S| = √(P總² + Q總²)、pf = P總/|S|、I = |S|/Vrms。

11.8 · Power Factor Correction

功率因數校正

工廠的馬達幾乎都是電感性、功因偏低。功因校正power factor correction就是在負載旁並聯一顆電容，用電容的 −Q 去抵銷電感的 +Q，讓功因接近 1。P 完全不變，但線電流會變小。

QC = Q₁ − Q₂ = P(tan θ₁ − tan θ₂)　　C = QC / (ω·V²rms)

電容值的公式是怎麼推出來的

  1. 校正前：P = S₁cos θ₁　⟹　Q₁ = S₁ sin θ₁ = P·tan θ₁
    從功率三角形。把 S₁ = P/cos θ₁ 代入 Q₁ = S₁ sin θ₁，得 Q₁ = P·(sinθ₁/cosθ₁) = P tan θ₁。用 tan 的好處是只需要 P，不必先算 S。
  2. 校正後：P 不變　⟹　Q₂ = P·tan θ₂

    關鍵前提：理想電容的平均功率為零，所以加電容不會改變 P。功率三角形的底邊固定，只有高度（Q）變矮。

  3. QC = Q₁ − Q₂ = P(tan θ₁ − tan θ₂)

    電容需要「吃掉」的那一段虛功率，就是兩者之差。因為 θ₁ > θ₂，所以這個值是正的。

  4. 另一邊，電容自己能提供多少 Q？
    QC = V²rms/XC　，而 XC = 1/(ωC)
    用 11.6 推的 Q = V²rms/X。電容的電抗是 1/(ωC)，代進去：
    QC = V²rms ÷ [1/(ωC)] = ω C V²rms

  5. 兩邊都是 QC，令它們相等：

    ω C V²rms = P(tan θ₁ − tan θ₂)
    ⟹　C = P(tan θ₁ − tan θ₂) / (ω V²rms)

    注意 ω = 2πf，台灣市電 f = 60 Hz → ω = 377 rad/s。

課本例題 11.15 · 完整計算

一個負載接在 120 V (rms)、60 Hz 電源上，吸收 4 kW，功因為 0.8 落後。求要把 pf 提升到 0.95 所需的並聯電容值。

  1. Step 1　求校正前的角度。 cos θ₁ = 0.8　⟹　θ₁ = cos⁻¹(0.8) = 36.87°
  2. Step 2　求校正前的 S₁ 和 Q₁。 S₁ = P/cos θ₁ = 4000/0.8 = 5000 VA
    Q₁ = S₁ sin θ₁ = 5000 × sin(36.87°) = 5000 × 0.6 = 3000 VAR     （也可以直接用 Q₁ = P tanθ₁ = 4000 × 0.75 = 3000 VAR，同樣答案。）
  3. Step 3　求目標角度與目標 Q₂。 cos θ₂ = 0.95　⟹　θ₂ = 18.19°
    Q₂ = P tan θ₂ = 4000 × tan(18.19°) = 4000 × 0.3287 = 1314.4 VAR
  4. Step 4　電容要提供的虛功率。 QC = Q₁ − Q₂ = 3000 − 1314.4 = 1685.6 VAR
  5. Step 5　換算成電容值。 ω = 2π × 60 = 377 rad/s　，V²rms = 120² = 14400
    C = 1685.6 / (377 × 14400) = 1685.6 / 5,428,800

C = 3.105×10⁻⁴ F = 310.5 µF

順便看看線電流少了多少（這才是省錢的地方）

  1. 校正前：I₁ = S₁/Vrms = 5000/120 = 41.7 A
  2. 校正後：S₂ = P/cos θ₂ = 4000/0.95 = 4210.5 VA
    I₂ = 4210.5/120 = 35.1 A
  3. 電流減少 15.8%，而線損 I²R 減少 1 − (35.1/41.7)² = 29.1%

    做了功因校正之後，負載拿到的有用功率 P 一點都沒變（still 4 kW），但輸電線上白白損失的熱能少了將近三成。這就是電力公司要求工廠維持高功因、否則加收費用的原因。

功因校正題目的四個步驟

  1. θ₁ = cos⁻¹(pf₁)，θ₂ = cos⁻¹(pf₂)。兩個角度先算出來放旁邊。
  2. Q₁ = P tan θ₁，Q₂ = P tan θ₂。記住 P 全程不變，這是整題的支點。
  3. QC = Q₁ − Q₂。順序是「舊減新」，因為要變小。
  4. C = QC/(ωV²rms)。ω 記得是 2πf，V 一定要用 rms。

功因校正的常見錯誤

  • ✗ tan 的順序寫反成 (tan θ₂ − tan θ₁)，算出負的電容值。θ₁ 是比較差的功因、角度比較大，所以是θ₁ 減 θ₂。
  • ✗ 以為 P 會變。加電容只改變 Q、S 和線電流，P 永遠不變。很多人會去重算 P，白做工還算錯。
  • ✗ 公式裡的 V 用成振幅。必須是 Vrms，而且要平方。
  • ✗ 忘記 ω = 2πf。直接把 60 代進去當 ω，答案會差 6.28 倍。
  • 反向情況：若負載本來就是電容性（超前），要並聯的是電感，公式變成 L = V²rms/(ω·QL)。
