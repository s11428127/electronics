課本 CH1313.4 · Linear Transformers

線性變壓器LINEAR TRANSFORMERS

接電源的是一次側、接負載的是二次側，R1、R2 是線圈的損失。從電源看進去的阻抗 = 一次側自己 + 二次側「反射」過來的部分。要整個電路解，也可以把耦合線圈換成沒有互感的 T 或 Π 等效電路。

Zin = R1 + jωL1 + ω2M2/(R2 + jωL2 + ZL)　·　T：La = L1 − M、Lb = L2 − M、Lc = M　·　Π：LA = (L1L2 − M2)/(L2 − M)、LB = (L1L2 − M2)/(L1 − M)、LC = (L1L2 − M2)/M

反射阻抗怎麼來

  1. V = (R1 + jωL1)I1 − jωM I2
    課本圖 13.19 網目 1。I2 順時針從二次側的點流出 → 互感取負。
  2. 0 = −jωM I1 + (R2 + jωL2 + ZL)I2
    網目 2：二次側沒有電源。
  3. I2 = jωM I1/(R2 + jωL2 + ZL)
    從網目 2 解出 I2。
  4. V = [R1 + jωL1 + ω2M2/(R2 + jωL2 + ZL)] I1
    代回網目 1：(−jωM)(jωM) = ω2M2。
  5. ZR = ω2M2/(R2 + jωL2 + ZL)

    反射阻抗（reflected／coupled impedance）。M 是平方，所以點的位置不影響 Zin。

T 型等效怎麼來

  1. V1 = jωL1I1 + jωM I2、V2 = jωM I1 + jωL2I2
    標準圖 13.21：兩個電流都流進點。
  2. T 網路：V1 = jω(La + Lc)I1 + jωLcI2、V2 = jωLcI1 + jω(Lb + Lc)I2
    兩個網目共用中間那支 Lc。
  3. 係數對齊 ⟹ Lc = M、La = L1 − M、Lb = L2 − M

    Π 型用節點分析對齊導納矩陣，得到式 13.48。點或電流方向不同時把 M 換成 −M。

線性變壓器題的標準流程

  1. 只問 Zin、I1：算 Z22 = R2 + jωL2 + ZL，套 Zin = Z11 + ω2M2/Z22，不用管點。
  2. 要 I2、Vo：網目分析（照 PART 1 判斷正負），或先換 T 等效。
  3. 換 T 等效前：對照標準圖 13.21 的電流方向和點；不一樣就把 M 換成 −M。
  4. T、Π 互換：T 用 L1 − M、L2 − M、M；Π 的分子都是 L1L2 − M2。

線性變壓器的坑

  • ✗ 反射阻抗寫成 ωM/Z22。✓ 是 ω2M2/Z22（M 平方）。
  • ✗ Z22 忘了加二次側自己的 jωL2。✓ Z22 = R2 + jωL2 + ZL（Example 13.4 是 j40 + Z2 + ZL）。
  • ✗ 把線性變壓器當理想的用 ZL/n2。✓ 那只適用理想變壓器（k = 1、L → ∞）。
  • ✗ 點反了還照套 T 等效。✓ 換成 −M（Example 13.6：Lc = −1）。

課本 CH1313.5 · Ideal Transformers

理想變壓器IDEAL TRANSFORMERS

理想變壓器：k = 1、電感無限大、沒有損失。兩個線圈穿過同一個磁通，所以電壓比 = 匝數比 n；自己不吃功率，所以電流比 = 1/n。負載反射到一次側是 ZL/n2。

V2/V1 = N2/N1 = n　·　I2/I1 = 1/n　·　S1 = V1I1* = V2I2* = S2　·　Zin = ZL/n2

電壓比、電流比

  1. v1 = N1 dφ/dt、v2 = N2 dφ/dt
    k = 1：同一個磁通 φ 穿過兩個線圈（法拉第定律）。
  2. V2/V1 = N2/N1 = n
    兩式相除，dφ/dt 消掉。
  3. v1i1 = v2i2
    沒有損失：一次側送進來的功率 = 二次側送出去的功率。
  4. I2/I1 = V1/V2 = 1/n

    電流跟電壓反比。n > 1 升壓、n < 1 降壓、n = 1 隔離。

正負號的兩條規則

  1. V1、V2 在點那端同正（或同負）⟹ +n，否則 −n
    課本規則 1，用在 V2 = ±nV1。
  2. I1、I2 都流進點（或都流出）⟹ −n，否則 +n
    課本規則 2，用在 I2 = ±I1/n。跟電壓那條相反。
  3. 檢查：V1I1* = V2I2*（照標準方向）

    兩個正負號配對錯，功率就對不上。

反射阻抗與消去變壓器

  1. Zin = V1/I1 = (V2/n)/(nI2) = (1/n2)(V2/I2)
    代入電壓比、電流比。
  2. Zin = ZL/n2
    V2/I2 = ZL。
  3. 二次側 → 一次側：阻抗 ÷ n2、電壓源 ÷ n、電流源 × n

    一次側 → 二次側全部反過來。只有一、二次側之間沒有其他導線相連時才能這樣做。

理想變壓器題的標準流程

  1. 先看兩邊有沒有其他導線相連：沒有 → 用反射；有（Example 13.9）→ 網目／節點，把 V1、V2（或 I1、I2）當未知數，再補兩條變壓器關係式。
  2. 反射：二次側阻抗 ÷ n2（電壓源 ÷ n），解出一次側電流。
  3. 看點決定正負號：電壓同正 +n；電流同進同出 −n。
  4. 回到二次側：I2 = ±I1/n，再求 Vo、功率。
  5. 檢查：一次側反射電阻吃的功率 = 負載吃的功率。

理想變壓器的坑

  • ✗ Zin = n2ZL。✓ 從一次側看是 ZL/n2（n = N2/N1）。
  • ✗ 電流的正負號跟電壓用同一條規則。✓ 電流：都進點反而是 −n。
  • ✗ 額定 2400/120 V 寫成 n = 20。✓ n = V2/V1 = 0.05（降壓）。
  • ✗ 兩邊有電阻相連還硬做反射。✓ 改用網目分析（Example 13.9）。
