CH6 電容與電感

電阻只看「現在」。這一章的兩個元件會把能量存起來：電容管電壓、電感管電流，兩個都不能瞬間改變。CH7、CH8 的開關暫態，主角就是它們。

    這章帶走三件事THREE TAKEAWAYS

    1. 電容：q = Cv、i = C dv/dt → 電壓不能瞬間改變；直流穩定時像斷路。電感：v = L di/dt → 電流不能瞬間改變；直流穩定時像導線。
    2. 儲存能量：wC = ½Cv2（電場，看電壓）、wL = ½Li2（磁場，看電流）。理想的 L、C 不消耗能量。Example 6.10：50 J、4 J。
    3. 串並聯：電感跟電阻一樣；電容剛好反過來 —— 並聯直接相加，串聯才是積/和。
    i = C dv/dtv = L di/dtw = ½Cv2、½Li2電容電壓、電感電流不能瞬間改變 —— CH7、CH8 的起點
