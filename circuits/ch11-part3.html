先複習 PART 2（這一頁從這裡接下去）

  1. S = VrmsIrms（VA）　pf = P/S = cos(θv − θi)　P = S·pf（W）
    啤酒杯：杯子 S 是電線要扛的，酒 P 是真的被用掉的。
  2. θv − θi > 0 落後（電感性）；< 0 超前（電容性）
    阻抗角 = 功因角，只給 Z 就能讀 pf。

這一頁的核心只有一條：S = P + jQ。其他公式都是它的變形 —— 先把功率三角形畫熟，計算題就解了一半。

拿到任何一題交流功率，先做這三件事

  1. 統一單位：振幅還是 rms？看到 v(t) = Vmcos(…) 就是振幅，要除 √2；電力題目講「120 V 電源」預設就是 rms。
  2. 把每個負載化成一對 (P, Q)。不管題目給的是 pf、阻抗、還是 S 和角度，先轉成 P 和 Q。
    Q = P·tanθ　P = S·cosθ　Q = S·sinθ　P = I²rms·R　Q = I²rms·X
  3. 確認 Q 的符號。電感性（落後）+、電容性（超前）−。符號一錯，後面全錯。
原講義 CH1111.6 · Complex Power

複功率與功率三角形COMPLEX POWER · POWER TRIANGLE

PART 2 的啤酒杯裡，「泡沫」是在電源與電感電容之間來回搬、沒被用掉的那部分，它的名字叫虛功率reactive power Q，單位 VAR。把 P 畫成橫的、Q 畫成直的，斜邊就是 |S| —— 這叫。再把三角形寫成一個複數，就是複功率complex power：實部 P、虛部 Q、大小 |S|、角度的 cos 是 pf，一個數在手，四個量全有。

S = Vrms·I*rms = P + jQ　　|S| = √(P² + Q²)　　S = I2rmsZ = V2rms/Z*

為什麼是 V·I*（而不是 V·I）

  1. 我們想要一個複數，它的實部剛好是 P。
    P = VrmsIrmscos(θv−θi)，而複數的實部長得就是「大小 × cos(角度)」。所以只要湊出一個「大小 = VrmsIrms、角度 = θv−θi」的複數就行。
  2. 若用 V·I：　Vrms∠θv × Irms∠θi = VrmsIrms∠(θv + θi)　✗

    複數相乘是角度相加，得到 θv + θi —— 不是我們要的角度。

  3. 若用 V·I*：　I* = Irms∠(−θi)
    Vrms∠θv × Irms∠(−θi) = VrmsIrms∠(θv − θi)　✓

    取就是把角度變號，相乘時「加上一個負角度」＝「相減」。這就是那個星號存在的唯一理由。

  4. S = VrmsI*rms = VrmsIrmscos(θv−θi) + j·VrmsIrmssin(θv−θi)

    把極座標展開成直角座標（歐拉公式）。實部正是 P，虛部則是一個新東西。

  5. S = P + jQ　，其中 Q ≡ VrmsIrmssin(θv−θi)

    虛部就是虛功率 Q，單位 VAR。θ > 0（電感性）→ sin > 0 → Q > 0；θ < 0（電容性）→ Q < 0。它不被消耗，但真實存在、真的會佔用電線容量。

另外兩條常用型：S = I²Z 與 S = V²/Z*

  1. 由 Z = Vrms/Irms 得 Vrms = Z·Irms
    歐姆定律的相量版本，把 V 用 Z 和 I 表示。
  2. S = VrmsI*rms = (Z Irms)(I*rms) = Z·|Irms|²

    因為 I·I* = |I|²（複數乘自己的共軛 = 大小平方，必為實數）。

  3. S = Irms2(R + jX)　⟹　P = Irms2R、Q = Irms2X
    這解釋了為什麼電阻決定 P、電抗決定 Q，也直接證明純電感（R = 0）的 P = 0。功率三角形跟三角形（|Z|, R, X）長得一模一樣，只差一個 I²。
  4. 由 Irms = Vrms/Z 代入：S = Vrms(Vrms/Z)* = Vrms2/Z*

    分母要取 Z*，不是 Z —— 又是共軛，理由同上。並聯負載（電壓相同）用這條最快。

四個量一次到手。拿到 S = P + jQ 之後：實部 = P、虛部 = Q、大小 |S| = √(P²+Q²) = 視在功率、相角的 cos = 功率因數。這就是課本說「複功率包含了負載的所有功率資訊」的意思。

Q 的三種情況：Q = 0 純電阻（單位功因）；Q < 0 電容性（超前）；Q > 0 電感性（落後）。

複功率題目的通用流程

  1. 先統一成 rms。題目若給振幅，先除以 √2；給 v(t)/i(t) 時間式，先轉成相量。
  2. 看題目給什麼，選對公式：給 V 和 I → S = V·I*；給 I 和 Z → S = I²rms·Z；給 V 和 Z → S = V²rms/Z*；給 |S| 和 pf → P = |S|·pf、Q = ±|S|·sinθ。
  3. 算出 S 之後不要停。P、Q、|S|、pf、負載性質通常會一起問，全都可以從 S 直接讀出來。
  4. 反推電流：I* = S/V 拿到的是共軛，角度要再變號一次。
  5. 檢查符號：Q 的正負要跟負載性質一致（電感 +、電容 −）。不一致就是共軛取錯了。

複功率的坑

  • ✗ 忘記取共軛，算成 V·I。✓ S = V·I*，角度才會是 θv − θi。
  • ✗ 用 S = V²/Z。✓ 分母要共軛：S = V²/Z*。
  • ✗ 把振幅當 rms 直接乘。✓ S = V·I* 的 V、I 必須是 rms；手上是振幅就用 S = ½VmIm*。
  • ✗ 由 I* = S/V 算出來就直接當 I。✓ 那是 I 的共軛，角度要再變號。
  • ✗ Q 的單位寫 VA 或 W。✓ Q 用 VAR（課本 Example 11.12 自己也寫成 kVA，是筆誤）。
原講義 CH1111.7 · Conservation of AC Power

交流功率守恆CONSERVATION OF AC POWER

一個電源接好幾個負載，就像一本帳：電源送出的複功率 = 每個負載吸收的複功率加起來，不管串聯還是並聯。P 加 P、Q 加 Q 都沒問題 —— 但視在功率 |S| 不能直接加，這是這一章最常被扣分的地方。

S = S₁ + S₂ + ⋯ + SN　　P = ΣPi　　Q = ΣQi　　但 |S| ≠ Σ|Si|

並聯：為什麼複功率可以直接相加

  1. KCL：I = I₁ + I₂
    並聯的話，各負載電壓相同、電流相加。這是唯一用到的電路定律。
  2. 取共軛：I* = (I₁ + I₂)* = I₁* + I₂*

    共軛運算對加法是可分配的（(a+b)* = a* + b*），所以可以逐項取。

  3. S = V·I* = V(I₁* + I₂*) = V·I₁* + V·I₂*
    把 V 乘進去分配。而 V·I₁* 正是負載 1 的複功率 S₁（並聯時它兩端的電壓就是 V）。
  4. S = S₁ + S₂

    證畢。推廣到 N 個負載完全一樣。

串聯：換一個定律，結論一樣

  1. KVL：V = V₁ + V₂
    串聯的話，各負載電流相同、電壓相加。
  2. S = V·I* = (V₁ + V₂)I* = V₁I* + V₂I*
  3. S = S₁ + S₂

    所以不管串聯並聯，複功率永遠可以直接相加。電源送出的，等於所有負載（包括傳輸線）吸收的總和。

那為什麼視在功率 |S| 不能直接加？

  1. 因為 S（複功率）是向量，|S|（視在功率）是長度。可以相加的是向量，不是長度。

  2. S = (P₁ + jQ₁) + (P₂ + jQ₂) = (P₁+P₂) + j(Q₁+Q₂)

    向量相加 = 實部各自加、虛部各自加。所以 P 可以加、Q 可以加（它們是分量）。

  3. |S| = √[ (ΣP)² + (ΣQ)² ]　　≠　　Σ√(Pi2 + Qi2)
    像走路：先往東北走 5 步、再往東南走 5 步，離起點不是 10 步。只有所有 Si 方向完全相同（功因角都一樣）時，兩者才相等。電感的 +Q 和電容的 −Q 還會互相抵銷 —— 這正是下一節功因校正的原理。

多負載題目的標準流程

  1. 把每個負載都換算成 Pi 和 Qi。給 P 和 pf → Q = P·tanθ；給 |S| 和 pf → P = |S|·pf、Q = |S|·sinθ；給阻抗（並聯）→ S = V²/Z*；給阻抗（串聯）→ S = |I|²Z。
  2. Q 的符號一定要對。電感性（lagging）取 +，電容性（leading）取 −。
  3. 分別加總得到 P總、Q總。
  4. 最後才合成：|S| = √(P總² + Q總²)、pf = P總/|S|（Q總的正負決定落後或超前）、I = |S|/Vrms。
  5. 有傳輸線的題目：線路也是一個負載，S電源 = S線路 + S負載，可以拿來驗算。

守恆題最常錯的地方

  • ✗ 視在功率直接相加：|S| = |S₁| + |S₂|。✓ 先 P 加 P、Q 加 Q，最後才取大小。
  • ✗ pf 直接平均：(0.8 + 0.95)/2。✓ 合併 pf = P總/|S總|，要重算。
  • ✗ 超前負載的 Q 也取正。✓ 超前（電容性）的 Q 是負的，相加時會抵銷電感的 Q。
  • ✗ 並聯負載用 S = V²/Z。✓ 分母要 Z*。
原講義 CH1111.8 · Power Factor Correction

功率因數校正POWER FACTOR CORRECTION

工廠的馬達幾乎都是電感性、功因偏低：杯子（S）很大，電線要扛很大的電流。功因校正power factor correction就是在負載旁並聯一顆電容：電容的 Q 是負的，剛好抵銷馬達的 +Q。Q 由旁邊的電容就近供應，不必再從發電廠一路送過來 —— P 完全不變，但線電流變小、變小。

QC = Q₁ − Q₂ = P(tan θ₁ − tan θ₂)　　C = QC / (ω·V2rms)

電容值的公式是怎麼推出來的

  1. 校正前：P = S₁cos θ₁　⟹　Q₁ = S₁ sin θ₁ = P·tan θ₁
    從功率三角形。把 S₁ = P/cos θ₁ 代入 Q₁ = S₁ sin θ₁，得 Q₁ = P tan θ₁。用 tan 的好處是只需要 P，不必先算 S。
  2. 校正後：P 不變　⟹　Q₂ = P·tan θ₂

    理想電容的平均功率為零，所以加電容不會改變 P。功率三角形的底邊固定，只有高度（Q）變矮。

  3. QC = Q₁ − Q₂ = P(tan θ₁ − tan θ₂)

    電容需要「吃掉」的那一段虛功率，就是兩者之差。θ₁ > θ₂，所以這個值是正的。

  4. 電容自己能提供多少 Q？　QC = Vrms2/|XC|，而 |XC| = 1/(ωC)
    用 11.6 的 S = V²/Z*（電容並聯，電壓就是 Vrms）。代進去：
    QC = Vrms2 ÷ [1/(ωC)] = ω C Vrms2

  5. 兩邊都是 QC，令它們相等：

    C = QC / (ω Vrms2) = P(tan θ₁ − tan θ₂) / (ω Vrms2)

    注意 ω = 2πf，台灣市電 f = 60 Hz → ω = 377 rad/s。

線電流少了多少（這才是省錢的地方）

  1. I = |S|/Vrms = P/(Vrms cos θ)
    P 和 V 都不變，pf 變大 → 電流變小。
  2. 課本 11.15：校正前 I₁ = 5000/120 = 41.7 A；校正後 I₂ = 4210.5/120 = 35.1 A
  3. 電流減少 15.8%，線損 I²R 減少 1 − (35.1/41.7)² ≈ 29%

    負載拿到的 P 一點都沒變（還是 4 kW），但輸電線上白白損失的熱少了將近三成。這就是電力公司要求工廠維持高功因、否則加收費用的原因。

功因校正題目的四個步驟

  1. θ₁ = cos⁻¹(pf₁)，θ₂ = cos⁻¹(pf₂)。兩個角度先算出來放旁邊。
  2. Q₁ = P tan θ₁，Q₂ = P tan θ₂。記住 P 全程不變，這是整題的支點。（題目若直接給 Q₁，就不用算 P。）
  3. QC = Q₁ − Q₂。順序是「舊減新」，因為要變小；校正到 pf = 1 就是 Q₂ = 0。
  4. C = QC/(ωVrms2)。ω 記得是 2πf，V 一定要用 rms。

功因校正的常見錯誤

  • ✗ tan 的順序寫反成 (tan θ₂ − tan θ₁)，算出負的電容。✓ θ₁ 是比較差的功因、角度比較大，所以是 θ₁ 減 θ₂。
  • ✗ 以為 P 會變，去重算 P。✓ 加電容只改變 Q、S 和線電流，P 永遠不變。
  • ✗ 公式裡的 V 用振幅。✓ 必須是 Vrms，而且要平方。
  • ✗ 直接把 60 代進去當 ω。✓ ω = 2π × 60 = 377，否則答案差 6.28 倍。
  • ✗ 電容越大越好。✓ 電容太大會「校正過頭」，Q 變負、變成超前功因，電流又變大。
  • 反向情況：負載本來就是電容性（超前），要並聯的是電感：L = Vrms2/(ω·QL)。
原講義 CH1111.9 · Applications

應用：功率量測與電費POWER MEASUREMENT & ELECTRICITY COST

學了這麼多功率，實際上怎麼量、怎麼收錢？瓦特計wattmeter量 P、乏計varmeter量 Q、電表kilowatt-hour meter量用掉多少度電。電費按「度」收，但功因太低的大用戶會被加收罰款 —— 因為他們讓電線扛了太多泡沫。

瓦特計讀數 P = |Vrms||Irms| cos(θv − θi)　　電費 = 固定（需量）費 + 電能費（kWh × 單價）

瓦特計為什麼量得到 P

  1. 電流線圈：阻抗極低（理想 0）→ 串聯在負載上 → 感應負載電流 i(t)
    串進去像一條導線，不會改變電路。
  2. 電壓線圈：阻抗極高（理想 ∞）→ 並聯在負載兩端 → 感應負載電壓 v(t)
    並上去像斷路，幾乎不分走電流。所以接上瓦特計不會干擾原電路。
  3. 指針偏轉 ∝ v(t)·i(t) 的平均值 = P = VrmsIrmscos(θv − θi)

    指針有慣性，跟不上 2ω 的擺盪，只會停在平均值 —— 剛好就是 PART 1 的平均功率。讀的是「電流線圈串在哪、電壓線圈並在哪」那個元件的 P。

  4. 兩個線圈各有一個 ± 端：電流線圈的 ± 端朝電源，電壓線圈的 ± 端接在電流線圈那條線上
    兩個都反接還是正常讀數；只反接一個，指針會往反方向偏、讀不到。

電費怎麼算：兩段式費率

  1. 固定費：依「最大需量」（kW 或 kVA）收，例：每 kW 每月 $5
    電力公司要準備足夠的發電、輸電設備應付你的尖峰，所以按尖峰收。用 kVA 收的話，pf 低的人 kVA 大、付比較多。
  2. 電能費：用掉幾度（kWh）× 單價，常常分級（前 50,000 度一個價、其餘另一個價）
  3. 總電費 = 固定費 + 電能費
  4. 功因罰款／減免：pf 每低於門檻（例 0.85）0.01，加收電能費的 0.1%；每高 0.01，減免 0.1%
    pf 低 → 同樣的 P 要更大的電流 → 線損 I²R 更大。電力公司把這筆損失轉嫁給功因低的用戶 —— 這就是工廠要做 11.8 功因校正的現實理由。

瓦特計與電費題

  1. 瓦特計：先找「電流線圈串在哪、電壓線圈並在哪」→ 決定它量的是哪個元件（或哪一整段電路）的 P。
  2. 算那一段的電流 I 與電壓 V（或直接 P = |I|²R，R 是那一段的實部）。
  3. 電費：MWh 先換 kWh（× 1000）；固定費 = 需量 × 單價；電能費分級算再相加。
  4. 功因罰款：差幾個 0.01 → 乘 0.1% → 罰款（或減免）= 電能費 × 比例。

應用題的坑

  • ✗ 瓦特計讀成整個電路的功率。✓ 只讀線圈接的那一段；Example 11.16 讀的只有 (8 − j6) Ω 負載，不含 12 + j10 的線路。
  • ✗ 瓦特計讀數用 |S|。✓ 讀的是實部 P = Re(S)。
  • ✗ MWh 沒換 kWh 就乘單價。✓ 200 MWh = 200,000 kWh。
  • ✗ pf 高於門檻也罰。✓ 高於門檻是減免（credit）。

課本 Example 11.16 把 S 寫成 423.7 − j324.6 VA，實部應為 432.7（22500 × 8 ÷ 416 = 432.69），讀數 432.7 W 是對的 —— 課本筆誤。
