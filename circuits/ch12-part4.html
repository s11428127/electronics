原講義 CH1212.9 · PSpice for Three-Phase Circuits

用 PSpice 解三相PSPICE FOR THREE-PHASE CIRCUITS

PSpice 解三相跟解單相交流一樣：VAC 電源設大小（ACMAG）和相角（ACPHASE），IPRINT 量電流、VPRINT2 量兩點電壓，AC Sweep 只算一個頻率。麻煩的只有 Δ 電源：(1) 三顆電壓源接成一圈，PSpice 不接受 → 每顆串一個 1 μΩ；(2) 沒有接地點 → 加三個 1 MΩ 接成 Y，中心點當地。題目只給阻抗不給頻率時，設 ω = 1 rad/s，L、C 的數字就很好算。

Δ 電源：每相串 1 μΩ ＋ 三個 1 MΩ 接 Y 當地　　ω = 1 rad/s（f = 0.159155 Hz）：L = XL、C = 1/XC

為什麼一圈電壓源不行

  1. 迴路 a → b → c → a 的 KVL：Vab + Vbc + Vca = 0
    迴路上只有電壓源，沒有任何電阻。
  2. 理想平衡時剛好 = 0 → 迴路電流可以是任何值（方程式不唯一）
    數值上只要差 10−9，就變成「0 = 一個數」，矛盾。
  3. 串一個 r = 1 μΩ：I環 = ΣV/(3r)，方程式有唯一解

    1 μΩ 小到不影響答案，但讓矩陣可解。真實發電機的繞組電阻就是這個 r —— 所以真實的 Δ 電源不平衡時會有很大的環流。

ω = 1 的技巧

  1. PSpice 要填 L（H）和 C（F），題目給的卻是 jX
  2. XL = ωL → L = XL/ω；XC = 1/(ωC) → C = 1/(ωXC)
  3. 取 ω = 1：j5 Ω → 5 H、j30 Ω → 30 H、−j40 Ω → 0.025 F

    頻率 f = ω/2π = 0.159155 Hz，AC Sweep 起點、終點都填它。

Δ 電源的環流：電壓差一點點，電流爆表

把內阻拉到 1 μΩ（PSpice 加的那個）：只要電壓差一點點，環流就是幾百萬安培。所以 PSpice 裡的 Δ 電源一定要「完美平衡」，真實世界則乾脆少用 Δ 電源。

PSpice 解三相的步驟

  1. 電源：三顆 VAC，ACMAG = 大小、ACPHASE = 0、−120、120（照相序）。Δ 電源每顆串 1 μΩ，再加三個 1 MΩ 接成 Y、中心接地。
  2. 元件值：有頻率 → L、C 直接填；只給阻抗 → 設 ω = 1，L = XL、C = 1/XC。
  3. 量測：IPRINT 串在要量的支路（注意方向）、VPRINT2 跨兩點；屬性 AC = yes、MAG = yes、PHASE = yes。
  4. 分析：AC Sweep，Total Pts = 1，Start = Final = 頻率。
  5. 驗算：平衡用單相等效、不平衡用網目分析，手算對一次。

PSpice 的坑

  • ✗ Δ 電源直接三顆接成一圈。✓ 每顆串 1 μΩ。
  • ✗ 忘了接地。✓ 加 Y 接的 1 MΩ，中心當 0 節點。
  • ✗ 只給阻抗就隨便填 60 Hz，L 卻填 X 的數字。✓ 頻率要跟換算一致：ω = 1 時 L = X。
  • ✗ IPRINT 方向放反，相角差 180°。✓ 對照題目要的電流方向（例：IAC = −ICA）。
  • ✗ 課本 Example 12.12 寫 Iab = 5.595 A。✓ 輸出與驗算都是 5.959 A（數字印反）。

原講義 CH1212.10.1 · Three-Phase Power Measurement

三相功率量測THREE-PHASE POWER MEASUREMENT

平衡時一個瓦特計讀數 × 3 就是總功率；不平衡就要多個。三瓦特計法：三條線各串一個瓦特計，電壓線圈都接到同一個參考點 o，讀數相加 = 總功率，Y、Δ、平衡、不平衡都適用。把 o 選在其中一條線上（例如 b），那個瓦特計讀 0、可以拿掉 —— 這就是最常用的兩瓦特計法：PT = P1 + P2。平衡時兩個讀數的差還能算出 Q 和 pf。

三瓦特計：PT = P1 + P2 + P3　　兩瓦特計：P1 = VLILcos(θ + 30°)、P2 = VLILcos(θ − 30°)　PT = P1 + P2　QT = √3(P2 − P1)　tan θ = √3(P2 − P1)/(P2 + P1)

兩個讀數各是多少（平衡 Y 負載、abc）

  1. W1：電流 Ia、電壓 Vab（a 對 b）
    電流線圈在 a 線，電壓線圈接 a 和第三條線 b。
  2. Vab 超前 Van 30°；Ia 落後 Van θ → 兩者夾角 θ + 30°
  3. P1 = Re(VabIa*) = VLILcos(θ + 30°)
  4. 同理 W2（Ic、Vcb）：P2 = VLILcos(θ − 30°)
    Vcb = −Vbc 在 Vcn 後面 30°。

相加、相減

  1. cos(θ ± 30°) = cos θ cos 30° ∓ sin θ sin 30°
    和角公式。
  2. P1 + P2 = VLIL · 2cos 30° cos θ = √3VLILcos θ = PT

    就是 PART 3 的總功率。

  3. P2 − P1 = VLIL · 2sin 30° sin θ = VLILsin θ　⟹　QT = √3(P2 − P1)
  4. P2 = P1 → 純電阻；P2 > P1 → 電感性；P2 < P1 → 電容性

    θ > 60° 時 P1 會變負（瓦特計反打），照樣代數相加。兩瓦特計法不能用在中性線有電流的四線式系統。

量測題的流程

  1. 預測讀數：先找每個瓦特計的電壓線圈接哪兩點、電流線圈在哪條線，P = Re(V I*)。平衡兩瓦特計直接用 VLILcos(θ ± 30°)。
  2. 由讀數反推：PT = P1 + P2、QT = √3(P2 − P1)、θ = tan−1(QT/PT)。
  3. 每相：總數 ÷ 3；Δ 負載 Vp = VL，Y 負載 Ip = IL；|Zp| = Vp/Ip、角度 = θ。
  4. 不平衡：三瓦特計各自 Re(V I*) 相加；驗算 Σ|I|²R。

量測的坑

  • ✗ 讀數是負的就取絕對值。✓ 照符號代數相加（Practice 12.14：−560 + 800 = 240 W）。
  • ✗ QT = P2 − P1。✓ 要乘 √3。
  • ✗ 把 P1、P2 當成某一相的功率。✓ 單獨一個讀數沒有物理意義，只有相加（和相減）才有。
  • ✗ 四線式有中性線電流還用兩瓦特計。✓ 要用三瓦特計法。
原講義 CH1212.10.2 · Residential Wiring

家用配電與用電安全RESIDENTIAL WIRING

電力公司送到家門口的是高壓（例如 12,000 V），變壓器降成 120/240 V 的單相三線制：二次側兩個 120 V 線圈串聯，中間抽頭接地當中性線（白），兩端是兩條火線（黑、紅）。黑、紅兩條的電壓相位相反，所以兩條之間是 240 V。燈和插座接 120 V，冷氣、烤箱、洗衣機接 240 V。安全上有第三條接地線，以及在浴室、戶外用的漏電斷路器（GFCI）：出去和回來的電流對不上就跳脫。

VW = 0、VB = 120∠0°、VR = 120∠180° = −VB　⟹　VBR = VB − VR = 2VB = 240∠0° V　　GFCI：iR + iW + iB ≠ 0 → 跳脫

為什麼兩條 120 V 的火線之間是 240 V

  1. 中性線（白）接地：VW = 0
    兩個線圈中間的抽頭當參考點。
  2. 黑線 VB = 120∠0°；紅線 VR = 120∠180°
    兩個線圈串聯，從中點往兩邊看，方向相反 —— 兩個 120 V 剛好相位相反。
  3. VBR = VB − VR = 120 − (−120) = 240∠0° V

    這不是三相（三相的兩條線之間是 √3 倍），是「一個 240 V 從中間剖半」。

中性線電流與 GFCI

  1. 黑側負載電流 I1、紅側 I2：中性線 = I1 − I2
    兩側相位相反，回到中性線時互相抵消一部分。兩側平均時中性線幾乎沒電流。
  2. 正常時：iB + iW + iR = 0
    從變壓器出去多少就回來多少（KCL）。
  3. 有電流經過人體流到大地 → 總和 ≠ 0 → GFCI 跳脫

    人體像一個電阻 R：I = V/R。1 mA 以下通常無害；超過 10 mA 會嚴重電擊。

把黑側、紅側調成一樣，白線電流就是 0（兩側互相抵消）。240 V 電器只走黑、紅兩條線，不經過中性線。

家用配電題的想法

  1. 先分清楚接在哪兩條線：黑-白、紅-白是 120 V；黑-紅是 240 V。
  2. 各負載電流：I = P/V（電阻性），240 V 電器只走火線。
  3. 中性線電流：黑側 − 紅側（120 V 那兩群的差）。
  4. 觸電電流：I = V/Rbody，跟 1 mA、10 mA 比。

家用配電的坑

  • ✗ 家裡是三相，240 V 是 √3 倍。✓ 是單相三線制，兩個 120 V 相位相反，240 = 2 × 120。
  • ✗ 中性線就是接地線。✓ 中性線平常有電流（負載回路）；接地線平常沒電流，只在故障時導走電流。
  • ✗ 關掉開關就一定沒電。✓ 永遠先量過再碰；大電容斷電後還有電。
  • ✗ 用兩隻手量高壓。✓ 一手到另一手的電流會經過心臟。
