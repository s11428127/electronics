課本 CH1313.6 · Ideal Autotransformers

理想自耦變壓器IDEAL AUTOTRANSFORMERS

自耦變壓器只有一個連續的繞組，中間拉一個抽頭。一、二次側不只磁耦合、還用導線直接相連，所以能傳更大的視在功率、體積更小，但失去電氣隔離。

降壓：V1/V2 = (N1 + N2)/N2　·　升壓：V1/V2 = N1/(N1 + N2)　·　I1/I2 = V2/V1　·　抽頭：I1 + Io = I2

電壓比、電流比

  1. V1/(N1 + N2) = V2/N2
    降壓接法（圖 13.42a）：輸入跨全部匝數、輸出跨 N2，每一匝的電壓一樣。
  2. V1/V2 = (N1 + N2)/N2 = 1 + N1/N2
    式 13.63。
  3. S1 = V1I1* = V2I2* = S2 ⟹ I1/I2 = V2/V1
    理想 → 沒有損失（式 13.64、13.65）。
  4. 升壓（圖 13.42b）：V1/V2 = N1/(N1 + N2)、I1/I2 = 1 + N2/N1

    輸入跨 N1、輸出跨全部。共用那段的電流用抽頭 KCL 求。

V1 = 400 V（Problem 13.67 的數字）。抽頭比例越接近 100%（輸出越接近輸入），經過磁通的功率越少 —— 這就是自耦變壓器能傳大功率的原因。紅色那條就是「真正需要變壓器出力」的部分。

自耦變壓器題的標準流程

  1. 看接法：輸出跨一段 → 降壓；輸入跨一段 → 升壓。標出 N1、N2。
  2. 電壓：每一匝電壓一樣，直接比匝數。
  3. 電流：理想 → I1/I2 = V2/V1（或功率 ÷ 電壓）。
  4. 共用段：抽頭 KCL：Io = I2 − I1（照圖上的方向）。

自耦變壓器的坑

  • ✗ 升壓、降壓用同一個式子。✓ 先看輸入、輸出各跨在哪幾匝。
  • ✗ 共用段的電流當成 I1 或 I2。✓ 用抽頭 KCL，是兩個的差。
  • ✗ 以為自耦變壓器也有隔離。✓ 兩邊有導線相連，沒有隔離。

課本 CH1313.7 · Three-Phase Transformers

三相變壓器THREE-PHASE TRANSFORMERS

三相升降壓用三個單相變壓器（變壓器組）或一個三相變壓器。一次、二次側各自接 Y 或 Δ：四種接法。接法相同時線電壓比就是 n；Y、Δ 混接時多一個 √3。不管哪一種，ST = √3 VLIL，一次側 = 二次側。

ST = √3 VLIL　·　Y-Y、Δ-Δ：VLs = nVLp、ILs = ILp/n　·　Y-Δ：VLs = nVLp/√3、ILs = √3 ILp/n　·　Δ-Y：VLs = √3 nVLp、ILs = ILp/(√3 n)

為什麼 Y-Δ 會多一個 √3

  1. 每個單相變壓器：線圈電壓比 = n
    三個變壓器的 n 一樣。
  2. 一次側 Y：每個線圈的電壓 = VLp/√3
    CH12：Y 接的相電壓是線電壓的 1/√3。
  3. 二次側 Δ：每個線圈的電壓 = n VLp/√3 = VLs
    Δ 接的相電壓就是線電壓。
  4. VLs = nVLp/√3；功率守恆 ⟹ ILs = √3 ILp/n

    Δ-Y 反過來：VLs = √3 nVLp。Δ-Δ 還有一個特點：拆掉一個變壓器，剩兩個成為「開三角」還能供電。

負載固定 42 kVA（Example 13.12）。切換接法看二次側線電壓怎麼變；不管哪一種，√3 VLpILp = √3 VLsILs。

三相變壓器題的標準流程

  1. 判斷接法：看一次、二次側的線圈是接成 Y（一端接在一起）還是 Δ（接在兩條線之間）。
  2. 總功率：ST = √3 VLIL（P = S cos θ）先求出已知那一側的線電流。
  3. 換到另一側：套這種接法的 VL、IL 關係式。
  4. 每個變壓器：ST/3，或「相電壓 × 相電流」檢查。

三相變壓器的坑

  • ✗ Y-Δ 也直接 VLs = nVLp。✓ Y、Δ 混接要多一個 √3。
  • ✗ 匝數比用線電壓比。✓ 匝數比是「每個線圈」的電壓比（Problem 13.75）。
  • ✗ 每個變壓器的額定用 ST。✓ 平衡時三個平分：ST/3。

課本 CH1313.9 · Applications

變壓器的應用APPLICATIONS

三個應用：隔離（兩邊沒導線，只讓交流過、擋掉直流、量高壓時保護電錶）、匹配（讓反射回來的負載等於電源內阻，拿到最大功率）、配電（升壓輸電讓電流變小、線損 I2R 變小，到家門口再降壓）。

匹配：Rs = RL/n2　·　Rs > RL 用降壓（n < 1）　·　同功率 S = VI：V 大 10 倍 → I 小 10 倍 → I2R 小 100 倍

匹配的條件

  1. 最大功率：負載電阻 = 電源內阻
    CH4 的最大功率傳輸定理。
  2. 理想變壓器把負載反射成 RL/n2
    式 13.60。
  3. Rs = RL/n2 ⟹ n = √(RL/Rs)

    式 13.73。擴大機（幾 kΩ）接喇叭（幾 Ω）要降壓。

為什麼要高壓輸電

  1. I = S/V
    同樣送 100 kVA：1000 V 要 100 A、10000 V 只要 10 A。
  2. Ploss = I2R
    線路電阻固定時，損失跟電流平方成正比。
  3. 電壓 × 10 ⟹ 損失 ÷ 100

    電線也可以細一點。變壓器能方便地升降交流電壓，是發電用交流的主要原因之一。

輸電電壓與線損

輸電電壓
—
線損佔送出功率
—

送 100 kVA（課本 13.9.3 的例子），線路電阻自己調。把電壓從 1 kV 拉到 10 kV，線損剛好少 100 倍。

應用題的標準流程

  1. 隔離／直流＋交流：疊加，直流部分在二次側是 0，交流照 n 算。
  2. 匹配：n2 = RL/Rs；匹配後一次側電壓 = 電源電壓的一半。
  3. 額定、配電：S = V1I1 = V2I2；匝數 Np/Ns = Vp/Vs。

應用題的坑

  • ✗ 匹配時 n2 = Rs/RL。✓ n2 = RL/Rs（Example 13.16：12/192）。
  • ✗ 直流也乘 n 傳過去。✓ 直流在二次側是 0（Example 13.15）。
  • ✗ 以為高壓輸電是為了「電壓大比較有力」。✓ 是為了電流小、I2R 損失小。
