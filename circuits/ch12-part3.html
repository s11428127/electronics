三相功率與不平衡系統

CH11 的功率（P、Q、S、pf）搬到三相：平衡時總瞬時功率是常數，總功率 P = √3 VLIL cos θ，而且同樣功率用的銅線只要 75%（12.7）。負載不平衡時，三相電流不再對稱，上會有電流，只能一相一相算或用網目分析（12.8）。

先複習 CH11 的功率（這一頁直接拿來用）

  1. P = VrmsIrmscos θ、Q = VrmsIrmssin θ、S = VI* = P + jQ
    θ = 阻抗角 = 電壓與電流的夾角。
  2. S = |I|²Z = |V|²/Z*；複功率可以直接相加
    功率守恆：電源送出 = 線路 + 負載吸收。
  3. QC = P(tan θold − tan θnew)，C = QC/(ωV²)
    功因校正。

平衡三相的功率 = 一相的功率 × 3。用線值寫就是 √3 VLIL（Y、Δ 都一樣）。不平衡時就只能三相各算各的再加。

原講義 CH1212.7 · Power in a Balanced System

平衡三相的功率POWER IN A BALANCED SYSTEM

每一相的瞬時功率都跟 CH11 一樣以 2ω 起伏，但三相的起伏錯開 120°（在 2ω 上是 240°），加起來剛好互相抵消 —— 總瞬時功率 p = 3VpIpcos θ 是常數，馬達轉得很順。總功率就是一相乘 3，用線電壓、線電流寫成 √3 VLILcos θ，Y、Δ 通用。另外，同樣的功率、電壓和損失，三相需要的導線材料只有單相的 75%。

p = 3VpIpcos θ（常數）　P = √3 VLILcos θ　Q = √3 VLILsin θ　S = 3VpIp* = 3Ip2Zp = √3 VLIL∠θ

為什麼總瞬時功率是常數

  1. vAN = √2Vpcos ωt，ia = √2Ipcos(ωt − θ)，b、c 相各轉 ∓120°
    Vp、Ip 是 rms，所以振幅要乘 √2。θ 是負載阻抗角。
  2. p = vANia + vBNib + vCNic = 2VpIp[cos ωt cos(ωt − θ) + …]
    三相各自的瞬時功率相加。
  3. cos A cos B = ½[cos(A + B) + cos(A − B)]
    積化和差：每一項拆成「常數 cos θ」＋「2ω 的起伏」。
  4. p = VpIp[3cos θ + cos α + cos(α − 240°) + cos(α + 240°)]，α = 2ωt − θ
    三個常數項加成 3cos θ；三個起伏項在 2ωt 上差 240°。
  5. cos α + cos(α − 240°) + cos(α + 240°) = 0　⟹　p = 3VpIpcos θ

    三個一樣大、差 240°（= 差 120°）的弦波相加 = 0，跟 PART 1 三相電壓相加 = 0 同一件事。

P = √3 VLILcos θ 對 Y、Δ 都成立

  1. P = 3Pp = 3VpIpcos θ
    平衡 → 三相一樣。
  2. Y：Vp = VL/√3、Ip = IL；Δ：Vp = VL、Ip = IL/√3
    兩種接法各有一個量差 √3。
  3. 兩種都是 3 × VLIL/√3 = √3 VLILcos θ

    注意 θ 仍是負載阻抗角（相電壓與相電流的夾角），不是線電壓與線電流的夾角。

三相省導線：75%

  1. 單相兩條線：IL = PL/VL，Ploss = 2IL2R = 2R PL2/VL2
    同樣送 PL、電阻性負載。
  2. 三相三條線：I′L = PL/(√3VL)，P′loss = 3I′L2R′ = R′ PL2/VL2
  3. 損失一樣 → 2R = R′ → 2/r² = 1/r′² → r² = 2r′²
    R = ρℓ/(πr²)：單相的線要粗一點。
  4. 材料比 = 2πr²ℓ / 3πr′²ℓ = 2(2)/3 = 1.333

    單相多用 33%，等於三相只要單相的 75%。

每一相自己都在 cos θ − 1 和 cos θ + 1 之間起伏（θ 大時還會變負：那一瞬間功率往回送），但三相加起來永遠是 3cos θ。

三相功率題的標準流程

  1. 平衡 → 先拿一相：用單相等效算出 Vp、Ip（或直接用題目給的線值）。
  2. 選公式：給線值 → S = √3 VLIL、P = S cos θ；給阻抗 → S = 3|Ip|²Zp 或 3Vp²/Zp*。
  3. 多組負載：每組化成 (P, Q)，相加後再取 |S|、pf。
  4. 電源端：Ss = −3VpIp*（負號 = 送出），用守恆檢查。
  5. 功因校正：QC = P(tan θold − tan θnew)，三顆平分；Δ 接電容的電壓用線電壓，Y 接用相電壓。

三相功率的坑

  • ✗ P = 3VLILcos θ。✓ 用線值是 √3；用相值才是 3。
  • ✗ θ 用線電壓和線電流的夾角。✓ θ 是負載阻抗角（相電壓與相電流的夾角）。
  • ✗ pf 直接平均（0.6 和 0.8 → 0.7）。✓ 先 P 加 P、Q 加 Q，再算 pf（Example 12.8 是 0.727）。
  • ✗ Δ 接電容用相電壓 VL/√3 算 C。✓ Δ 接每顆跨在兩條線之間，用線電壓。

原講義 CH1212.8 · Unbalanced Three-Phase Systems

不平衡三相系統UNBALANCED SYSTEMS

電源不平衡、或三相負載不一樣，就叫。課本只討論「電源平衡、負載不平衡」。這時三相電流不再只是「同一個電流轉 120°」，不能只算一相：有中性線（四線式）時每相各用歐姆定律，中性線電流 In = −(Ia + Ib + Ic) 不再是 0；沒有中性線（三線式）時 N 點會浮動，要用網目或節點分析。功率也只能三相各算各的再相加。

四線式：Ia = VAN/ZA、Ib = VBN/ZB、Ic = VCN/ZC　　In = −(Ia + Ib + Ic)　　P = PA + PB + PC

四線式：為什麼可以各相單獨算

  1. 中性線把 N 接回 n（阻抗很小）→ VN = Vn
    有一條導線把兩點綁在一起。
  2. 所以每相負載兩端 = 自己那一相的電壓：VAN = Van…
  3. Ia = VAN/ZA，…；KCL at N：In = −(Ia + Ib + Ic)

    三個電流大小、角度都不同，加起來不再抵消。

三線式：為什麼不能各相單獨算

  1. 沒有中性線 → Ia + Ib + Ic = 0（KCL 強迫）
    電流沒有別的路回去。
  2. 為了滿足這個條件，N 點電壓會自己移動（VNn ≠ 0）
    平衡時是剛好 0；不平衡時不是。
  3. VAN ≠ Van → 改用網目分析（兩個網目）或節點分析（解 VN）

不平衡題目的流程

  1. 有中性線（四線式）？有 → 每相 I = V相/Z相，In = −(Ia+Ib+Ic)。
  2. 沒有中性線（三線式）：網目分析 —— 兩個網目，右邊放線電壓（例：120√3∠30°），克拉瑪公式解；線電流 = 網目電流的組合。
  3. 不平衡 Δ 負載：每格 IAB = VAB/ZAB，再節點 KCL（√3∠−30° 不能用）。
  4. 功率：每相 S = |I|²Z 分別算再加；用電源端 −V I* 驗算守恆。

不平衡的坑

  • ✗ 算 a 相再轉 120°。✓ 不平衡時三相各不相同，要各算各的。
  • ✗ 總功率 = 一相 × 3。✓ 三相分別算再加。
  • ✗ 三線式還用 Van/ZA。✓ N 點浮動，VAN ≠ Van，要網目分析。
  • ✗ 照題號猜相序。✓ 看清楚題目（Example 12.9 是 acb；Practice 12.10 的圖照極性也是負相序）。
