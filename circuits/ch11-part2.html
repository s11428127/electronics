先複習 PART 1（這一頁從這裡接下去）

  1. P = ½VmIm cos(θv − θi)
    Vm、Im 是；½ 來自取平均；cos(θv − θi) 是電壓電流錯開造成的打折。
  2. 電阻 cos 0° = 1　｜　電感、電容 cos(±90°) = 0
    只有電阻真的消耗平均功率；電感電容借了又還。

這一頁的主線：把 ½ 吃掉（rms）→ P = VrmsIrms cos θ → 拆成 S × pf。

原講義 CH1111.4 · Effective or RMS Value

（均方根值 rms）EFFECTIVE (RMS) VALUE

交流電一下正一下負，「平均」是 0，「最高點」又只有一瞬間 —— 那它到底多大？最公平的比法是比發熱：拿同一顆電阻，交流接上去發多少熱，就找一個能發一樣多熱的直流，那個直流值就叫有效值effective value。台灣插座的「110 V」就是它，最高點其實有 155 V。

Xrms = √( (1/T) ∫₀T x²(t) dt )　←　先平方 square、再平均 mean、最後開根號 root

有效值是怎麼被「定義」出來的

  1. 先設定情境。兩個電路：一個接交流 i(t)、一個接直流 Ieff，負載都是同一個電阻 R。問：Ieff 要多大，才能讓兩邊發出一樣多的熱？

  2. 交流側：P = (1/T)∫₀T i²R dt = (R/T)∫₀T i² dt
    電阻的瞬時功率是 i²R（電流是負的也照樣發熱，所以是平方），取一週期平均。R 是常數可以提到積分外面。
  3. 直流側：P = Ieff2 R
    直流不隨時間變，功率就是 I²R，不用積分。
  4. 令兩者相等：Ieff2 R = (R/T)∫₀T i² dt

    R 兩邊消掉，剩下 Ieff2 = (1/T)∫i² dt，再開根號：

    Ieff = √( (1/T)∫₀T i² dt ) ≡ Irms

    倒著唸就是這條式子的英文名字：root（根號）→ mean（1/T 積分取平均）→ square（i²）。

弦波的 √2 是怎麼掉出來的

  1. i(t) = Im cos ωt　⟹　Irms = √( (1/T)∫₀T Im2cos²ωt dt )

    直接把弦波代進定義式。卡住的地方是 cos² 不好積。

  2. cos²x = ½(1 + cos 2x)
    用半角（降冪）公式把平方拆掉：cos² 積不動，但 ½ + ½cos2x 就很好積。
  3. Irms = √( (Im2/T)∫₀T ½(1 + cos 2ωt) dt )

    括號裡有兩塊：常數 ½ 的平均還是 ½；cos2ωt 是弦波，一週期平均為 0（跟 PART 1 用的是同一個道理）。

  4. Irms = √( Im2 × ½ ) = Im/√2 ≈ 0.707 Im

    所以 √2 的來源就是那個 ½，而 ½ 來自 cos² 的降冪公式。換一種波形，這個 ½ 就會變成別的數，√2 自然不成立。

有了 rms，功率公式為什麼變乾淨了

  1. P = ½VmImcos(θv−θi)
    PART 1 推出來的結果，用的是振幅，前面拖著一個礙眼的 ½。
  2. 把 ½ 拆成 (1/√2)(1/√2)，各自配給 Vm 和 Im：
    P = (Vm/√2)(Im/√2)cos(θv−θi)
  3. P = Vrms Irms cos(θv − θi)　　P = Irms2R　　P = Vrms2/R（純電阻）

    ½ 消失了，長得跟直流的 P = VI 幾乎一樣 —— 這正是當初發明有效值的目的。電力工程講電壓電流時，預設就是 rms（台電的 110 V、220 V 都是 rms）。

Vm/√2 只對弦波成立。方波的 rms 就是 Vm、三角波與鋸齒波是 Vm/√3、半波整流是 Vm/2。考試若給非弦波卻照套 √2，就會錯。

看到 rms 題目

  1. 先判斷波形。純弦波（或全波整流）→ 直接 Vm/√2。其他波形 → 回定義式老實做「平方、平均、開根號」。
  2. 波形是分段的（半波整流、脈衝、斜坡＋平台），把一個週期切成幾段分別積分再相加；分母的 T 是完整週期，不是那一段的長度。
  3. 含直流偏壓的波形（VDC + 弦波）用 Vrms = √(V²DC + V²ac,rms)：兩部分的「平方」可以相加，rms 本身不能直接相加。
  4. 題目要功率時，用 rms 就不要再乘 ½：P = Irms²R、P = Vrms²/R。
  5. 算完檢查：rms 一定介於 0 和最高點之間。算出比振幅還大就是錯了。

有效值最常見的錯

  • ✗ 任何波形都除以 √2。✓ 只有弦波（和全波整流）是 √2；方波 = Vm、三角波 = Vm/√3、半波整流 = Vm/2。
  • ✗ 先平均再平方（「平均的平方」）。✓ 順序是先平方再平均（「平方的平均」）；弦波的平均是 0，先平均就全毀了。
  • ✗ 分段積分時除以那一段的長度。✓ 永遠除以整個週期 T。
  • ✗ 用了 rms 還乘 ½：P = ½VrmsIrmscos θ。✓ ½ 已經被 rms 吃掉了，P = VrmsIrmscos θ。
  • ✗ 把插座的 110 V 當成振幅，再除一次 √2。✓ 電力系統講的電壓預設就是 rms。
原講義 CH1111.5 · Apparent Power and Power Factor

視在功率與功率因數APPARENT POWER & POWER FACTOR

P = VrmsIrmscos θ 是兩個東西相乘：VrmsIrms「看起來」就該是功率，所以叫視在功率apparent power S，它是電線、發電機真正要扛的量，單位 VA。cos θ 則是打折率，叫功率因數power factor。像一杯啤酒：杯子是 S，酒是 P，泡沫是來回搬、沒被用掉的那部分。

S = VrmsIrms (VA)　　pf = P/S = cos(θv − θi)　　P = S·pf (W)

S 和 pf 是怎麼被「拆」出來的

  1. P = Vrms Irms cos(θv − θi)
    從 11.4 的結果出發。注意這是兩個東西的乘積：一個是 VrmsIrms、一個是 cos(θv−θi)。
  2. S ≡ Vrms Irms　　pf ≡ cos(θv − θi)

    把它們各自取名字：前者叫視在功率、後者叫功率因數。於是 P = S × pf，也就是 pf = P/S。

  3. 為什麼叫「視在」？在直流電路，功率就是電壓乘電流。到了交流，VrmsIrms「看起來」也該是功率 —— 但實際上不是，真正被消耗的只有 P。所以它叫 apparent（表面上的），而且刻意用 VA 而不是 W當單位，就是為了提醒你「這不是真的瓦特」。

  4. pf = cos θ，而 0° ≤ |θ| ≤ 90°　⟹　0 ≤ pf ≤ 1
    純電阻 θ = 0 → pf = 1（杯子裡全是酒）；純電感、純電容 θ = ±90° → pf = 0（全是泡沫）。
  5. Z = V/I = (Vm∠θv)/(Im∠θi) = (Vm/Im)∠(θv − θi)
    複數相除：大小相除、角度相減。而相減出來的角度，剛好就是功因角。
  6. 阻抗 Z 的角度　＝　功率因數角 (θv − θi)

    解題超好用：題目只給你 Z，你就已經知道 pf 了。例如 Z = 20 + j20 → 角度 45° → pf = cos45° = 0.707 落後。

落後（lagging）還是超前（leading）？

  1. cos(+36.87°) = cos(−36.87°) = 0.8

    cos 是偶函數，光寫「pf = 0.8」分不出是電感還是電容 —— 所以一定要加註或。

  2. θv − θi > 0 → 電流比電壓晚 → lagging → 電感性（X > 0）
    馬達、冷氣、變壓器裡都是線圈，所以工業負載幾乎都是落後功因。
  3. θv − θi < 0 → 電流比電壓早 → leading → 電容性（X < 0）
    口訣「ELI the ICE man」：電感 L 中 E（電壓）在 I 前面；電容 C 中 I 在 E 前面。

求 S、pf、P 的標準流程

  1. 統一成 rms。給 v(t)、i(t)（振幅）就先除以 √2；給「120 V 電源」預設已經是 rms。
  2. S = VrmsIrms（VA）。只看大小，不管相位。
  3. pf = cos(θv − θi)；只給阻抗時，θ = arctan(X/R) 就是功因角。
  4. 標落後／超前：θ > 0（X > 0）→ lagging；θ < 0（X < 0）→ leading。
  5. P = S × pf（W），再用 P = Irms²R 驗算（R 是阻抗實部）。
  6. 題目要反推元件：Z = V/I → 實部是電阻；虛部 X > 0 → L = X/ω，X < 0 → C = 1/(ω|X|)。

落後 / 超前最容易搞混

  • ✗ 只寫「pf = 0.8」。✓ 一定要註明 lagging 或 leading：cos(+36.87°) 和 cos(−36.87°) 都是 0.8，一個電感性、一個電容性，後面算 Q 和功因校正會完全相反。
  • ✗ 把 pf 算成大於 1。✓ pf = cos(角度)，範圍永遠是 0 到 1；算出 1.2 就是 P 和 S 弄反了。
  • ✗ S 的單位寫 W。✓ S 用 VA、P 用 W、Q 用 VAR，三個單位不能混。
  • ✗ 用 S = VmIm（振幅直接乘）。✓ S = VrmsIrms = ½VmIm。
  • ✗ 看到電流角度比較大就說「落後」。✓ 電流角度大 = 電流早到 = 超前（leading）。例：θv = −20°、θi = +10° → 超前。
